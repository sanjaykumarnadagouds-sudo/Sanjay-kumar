Source Code

fi

18. C Program to Display Parent and Child Process IDs

Aim: To create a child process and display the process IDs of parent and child using fork().

Source Code – process.c

#include <stdio.h>
#include <unistd.h>
#include <sys/types.h>

int main()
{
    pid_t pid;

    pid = fork();

    if (pid < 0)
    {
        printf("Fork failed");
    }
    else if (pid == 0)
    {
        printf("Child Process\\n");
        printf("Child PID = %d\\n", getpid());
        printf("Parent PID = %d\\n", getppid());
    }
    else
    {
        printf("Parent Process\\n");
        printf("Parent PID = %d\\n", getpid());
        printf("Child PID = %d\\n", pid);
    }

    return 0;
}

Compile and Execute

gcc process.c -o process
./process

Output – Example

Parent Process
Parent PID = 2500
Child PID = 2501
Child Process
Child PID = 2501
Parent PID = 2500

Process IDs and the order of printed lines can vary each time the program runs.

19. Compare Two Files and Delete the Second if They Are Same

Aim: To compare the contents of two files and delete the second file if both contents are identical.

Source Code

#!/bin/bash

if [ $# -ne 2 ]
then
    echo "Usage: ./compare.sh file1 file2"
    exit 1
fi

if [ ! -f "$1" ] || [ ! -f "$2" ]
then
    echo "One or both files do not exist"
    exit 1
fi

if cmp -s "$1" "$2"
then
    echo "Both files have same contents"
    rm "$2"
    echo "Second file deleted"
else
    echo "Files have different contents"
fi

Execute

chmod +x compare.sh
./compare.sh file1.txt file2.txt

Output – Same File Contents

Both files have same contents
Second file deleted

Note: This program permanently deletes the second file when the contents match. Use test files while practising.

20. Sort First Name, Middle Name and Age from a File

Aim: To sort first names and middle names alphabetically and ages in ascending and descending order.

Sample Input File – students.txt

Ravi Kumar 22
Anil Sharma 20
Manoj Reddy 24
Kiran Kumar 21

Source Code

#!/bin/bash

file="students.txt"

if [ ! -f "$file" ]
then
    echo "File does not exist"
    exit 1
fi

echo "First names in alphabetical order:"
sort -k1,1 "$file" | awk '{print $1}'

echo
echo "Age in ascending order:"
sort -k3,3n "$file" | awk '{print $3}'

echo
echo "Age in descending order:"
sort -k3,3nr "$file" | awk '{print $3}'

echo
echo "Middle names in alphabetical order:"
sort -k2,2 "$file" | awk '{print $2}'

OS Practical Viva Questions

1. What is Shell?
Shell is a command interpreter that acts as an interface between the user and the operating system.

2. What is Shell Scripting?
Writing a series of shell commands in a file to perform tasks automatically.

3. What is the shebang line?
#!/bin/bash specifies the interpreter used to execute a shell script.

4. What is the read command?
It accepts input from the user.

5. What is the echo command?
It displays text or values on the terminal.

6. What is chmod?
It changes file permissions.

7. What is a variable in Shell?
A variable stores a value that can be used in a script.

8. What is the purpose of the if statement?
It executes commands based on a condition.

9. What is a loop?
A loop repeatedly executes a set of statements.

10. What is the for loop?
It repeats commands for a sequence of values.

11. What is the case statement?
It selects commands based on matching patterns.

12. What is grep?
It searches for matching text in files.

13. What is the wc command?
It counts lines, words and characters or bytes.

14. What is the fork() system call?
It creates a new child process.

15. What is a process ID?
PID is a unique identification number assigned to a process.

16. What is the difference between cp and mv?
cp copies a file, while mv moves or renames a file.

17. What is the purpose of the date command?
It displays the system date and time.

18. What is the purpose of the HOME variable?
It stores the path of the current user's home directory.

19. What is the purpose of the test command?
It checks conditions such as file existence, string comparison and numeric comparison.

20. What is the purpose of the ps command?
It displays information about running processes.
