1. Introduction to PHP

What is PHP?

PHP stands for PHP: Hypertext Preprocessor. It is a server-side scripting language mainly used for developing dynamic and interactive websites.

PHP code is executed on the web server. The generated output is sent to the user's browser, usually as HTML.

History of PHP

PHP was originally created by Rasmus Lerdorf in 1994. It developed into a popular server-side programming language used for web applications.

Features of PHP

  • Open-source and free to use.
  • Easy to learn and understand.
  • Server-side scripting language.
  • Can be embedded inside HTML.
  • Supports many databases, including MySQL.
  • Platform independent.
  • Supports object-oriented programming.
  • Can handle forms, sessions and cookies.

Applications of PHP

  • Dynamic website development.
  • Online shopping websites.
  • Content management systems.
  • Login and registration systems.
  • Database-driven web applications.
  • Web portals and dashboards.

Client-Side vs Server-Side Scripting

  • Client-side scripting: Code runs in the user's browser. Example: JavaScript.
  • Server-side scripting: Code runs on the web server. Example: PHP.

Requirements for Running PHP

  • Web server such as Apache.
  • PHP interpreter.
  • Web browser.
  • Database server such as MySQL, when database connectivity is required.
  • Local development package such as XAMPP or WAMP.

What is XAMPP?

XAMPP is a local web development package containing Apache, MariaDB, PHP and Perl. It helps developers run PHP applications on their computers.

Installing and Configuring PHP

  1. Download XAMPP from its official website.
  2. Install XAMPP on the computer.
  3. Open the XAMPP Control Panel.
  4. Start the Apache server.
  5. Place PHP files inside the htdocs folder.
  6. Open a browser and visit localhost followed by the PHP filename.

First PHP Program

<?php
echo "Hello World";
?>

Output:

Hello World

2. PHP Syntax and Embedding PHP in HTML

PHP Tags

PHP code is written between PHP opening and closing tags.

<?php
    // PHP code
?>

Embedding PHP in HTML

PHP code can be written inside an HTML document to create dynamic web pages.

<!DOCTYPE html>
<html>
<body>

<h1>My Website</h1>

<?php
echo "Welcome to PHP";
?>

</body>
</html>

PHP Comments

Comments are statements written for explanation. They are not executed by PHP.

// Single-line comment

# Another single-line comment

/*
Multi-line
comment
*/

PHP Statements

A statement is an instruction executed by PHP. Most PHP statements end with a semicolon.

<?php
$name = "Sanju";
echo $name;
?>

PHP and Whitespace

Whitespace includes spaces, tabs and new lines. PHP generally ignores unnecessary whitespace outside strings, which makes code easier to format and read.

Sending Data to the Browser

PHP uses echo and print to display information in the browser.

<?php
echo "Welcome";
print " to STUDENTVERSE";
?>

Difference Between echo and print

  • echo can display one or more strings.
  • print displays one string.
  • echo does not return a value.
  • print returns the value 1.

3. Variables and Data Types in PHP

Variables

A variable is a named storage location used to hold data. In PHP, a variable begins with the dollar ($) symbol.

<?php
$name = "Sanju";
$age = 20;

echo $name;
echo $age;
?>

Rules for Naming Variables

  • A variable must start with the $ symbol.
  • The name must begin with a letter or underscore after $.
  • A variable name cannot begin with a number.
  • Variable names are case-sensitive.
  • Spaces are not allowed in variable names.

Data Types

PHP supports different types of data.

  • Integer: Whole numbers such as 10 and 100.
  • Float: Decimal numbers such as 10.5.
  • String: Collection of characters such as "Hello".
  • Boolean: True or false values.
  • Array: Stores multiple values in one variable.
  • Object: Instance of a class.
  • NULL: Represents a variable with no value.
  • Resource: Holds a reference to an external resource.

Example of Data Types

<?php
$name = "Sanju";
$age = 20;
$price = 99.50;
$isStudent = true;
$marks = array(80, 85, 90);
$value = NULL;

var_dump($name);
var_dump($age);
var_dump($price);
var_dump($isStudent);
var_dump($marks);
var_dump($value);
?>

Constants

A constant is a name that stores a value that cannot be changed during normal execution.

<?php
define("COLLEGE", "University of Mysore");

echo COLLEGE;
?>

Scope of Variables

  • Local variable: Declared inside a function and normally accessible only there.
  • Global variable: Declared outside a function. It can be accessed inside a function using the global keyword or the $GLOBALS array.
  • Static variable: Retains its value between function calls.

Example of Global Variable

<?php
$x = 100;

function display() {
    global $x;
    echo $x;
}

display();
?>

What are Operators?

Operators are symbols used to perform operations on variables and values.

Arithmetic Operators

  • + Addition
  • - Subtraction
  • * Multiplication
  • / Division
  • % Modulus
  • ** Exponentiation
<?php
$a = 10;

Assignment Operators

Comparison Operators

  • == Equal value.

  • < Less than.

  • <= Less than or equal to.

Logical Operators

Increment and Decrement Operators

5. Conditional Statements in PHP

if Statement

Executes a block of code when the condition is true.

<?php
$age = 20;

if ($age >= 18) {
    echo "Eligible to vote";
}
?>

if-else Statement

<?php
$number = 7;

if ($number % 2 == 0) {
    echo "Even Number";
} else {
    echo "Odd Number";
}
?>

if-elseif-else Statement

<?php
$marks = 75;

if ($marks >= 90) {
    echo "A Grade";
} elseif ($marks >= 60) {
    echo "B Grade";
} elseif ($marks >= 35) {
    echo "C Grade";
} else {
    echo "Fail";
}
?>

Nested if Statement

An if statement placed inside another if statement is called a nested if statement.

<?php
$age = 20;
$citizen = true;

if ($age >= 18) {
    if ($citizen) {
        echo "Eligible to vote";
    }
}
?>

switch Statement

The switch statement selects one block of code from several alternatives.

<?php
$day = 2;

switch ($day) {
    case 1:
        echo "Monday";
        break;

    case 2:
        echo "Tuesday";
        break;

    case 3:
        echo "Wednesday";
        break;

    default:
        echo "Invalid day";
}
?>
Tuesday

6. Looping Statements in PHP

What is a Loop?

A loop is used to execute a block of code repeatedly until a condition is satisfied or becomes false.

for Loop

The for loop is used when the number of iterations is known or controlled by an expression.

<?php
for ($i = 1; $i <= 5; $i++) {
    echo $i . "<br>";
}
?>

while Loop

The while loop executes as long as the condition is true.

<?php
$i = 1;

while ($i <= 5) {
    echo $i . "<br>";
    $i++;
}
?>

do-while Loop

The do-while loop executes the code at least once before checking the condition.

<?php
$i = 1;

do {
    echo $i . "<br>";
    $i++;
} while ($i <= 5);
?>

foreach Loop

The foreach loop is used to access elements of an array.

<?php
$colors = array("Red", "Green", "Blue");

foreach ($colors as $color) {
    echo $color . "<br>";
}
?>

break Statement

The break statement terminates the current loop or switch statement.

<?php
for ($i = 1; $i <= 10; $i++) {
    if ($i == 5) {
        break;
    }
    echo $i . " ";
}
?>

continue Statement

The continue statement skips the current iteration and moves to the next iteration.

<?php
for ($i = 1; $i <= 5; $i++) {
    if ($i == 3) {
        continue;
    }
    echo $i . " ";
}
?>

7. Arrays in PHP

What is an Array?

An array is a variable that can store multiple values under a single name.

Types of Arrays

  • Indexed array.
  • Associative array.
  • Multidimensional array.

Indexed Array

An indexed array uses numeric indexes to access its elements.

<?php
$colors = array("Red", "Green", "Blue");

echo $colors[0];
echo $colors[1];
echo $colors[2];
?>
Red Green Blue

Associative Array

An associative array uses named keys instead of numeric indexes.

<?php
$student = array(
    "name" => "Sanju",
    "age" => 20,
    "course" => "BCA"
);

echo $student["name"];
echo $student["course"];
?>

Multidimensional Array

A multidimensional array contains one or more arrays inside another array.

<?php
$students = array(
    array("Ravi", 80),
    array("Asha", 90),
    array("Sanju", 85)
);

echo $students[0][0];
echo $students[1][1];
?>

Important Array Functions

  • count() – Counts array elements.
  • array_push() – Adds elements at the end.
  • array_pop() – Removes the last element.
  • array_merge() – Combines arrays.
  • sort() – Sorts an array in ascending order.
  • rsort() – Sorts an array in descending order.
  • array_reverse() – Reverses an array.
  • in_array() – Checks whether a value exists.
  • array_keys() – Returns all keys.
  • array_values() – Returns all values.

Example of Array Functions

<?php
$numbers = array(30, 10, 20);

array_push($numbers, 40);

sort($numbers);

print_r($numbers);

echo "Total: " . count($numbers);
?>

8. Functions in PHP

What is a Function?

A function is a reusable block of code that performs a specific task. Functions reduce repetition and improve program organization.

Creating a Function

<?php
function greet() {
    echo "Welcome to PHP";
}

greet();
?>

Function with Parameters

<?php
function add($a, $b) {
    echo "Sum: " . ($a + $b);
}

add(10, 20);
?>

Function with Return Value

<?php
function square($number) {
    return $number * $number;
}

$result = square(5);

echo $result;
?>

Default Arguments

<?php
function welcome($name = "Student") {
    echo "Welcome " . $name;
}

welcome();
welcome("Sanju");
?>

Pass by Value

In pass by value, a copy of the argument is passed to the function. Changes to the parameter do not normally change the original variable.

<?php
function changeValue($x) {
    $x = 100;
}

$a = 10;
changeValue($a);

echo $a;
?>

Pass by Reference

In pass by reference, the function receives a reference to the original variable. Changes can affect the original variable.

<?php
function changeValue(&$x) {
    $x = 100;
}

$a = 10;
changeValue($a);

echo $a;
?>

Built-in Functions

PHP provides many predefined functions for working with strings, arrays, numbers, dates and files.

9. String Handling in PHP

What is a String?

A string is a sequence of characters used to represent text.

<?php
$name = "PHP Programming";
echo $name;
?>

Important String Functions

  • strlen() – Returns the length of a string.
  • str_word_count() – Counts words.

10. Object-Oriented Programming in PHP

What is OOP?

Object-Oriented Programming is a programming approach based on classes and objects. It helps organize code and supports reusability.

Class

A class is a blueprint used to create objects. It contains properties and methods.

Object

An object is an instance of a class. It can access the properties and methods defined in that class.

Class and Object Example

<?php
class Student {

    public $name = "Sanju";

    public function display() {
        echo "Student Name: " . $this->name;
    }
}

$obj = new Student();
$obj->display();
?>

Constructor

A constructor is a special method that is automatically called when an object is created. PHP uses the __construct() method.

<?php
class Student {

    public $name;

    function __construct($name) {
        $this->name = $name;
    }

    function display() {
        echo $this->name;
    }
}

$obj = new Student("Sanju");
$obj->display();
?>

Destructor

A destructor is a special method called when an object is destroyed or when the script ends. PHP uses __destruct().

<?php
class Demo {

    function __construct() {
        echo "Object created<br>";
    }

    function __destruct() {
        echo "Object destroyed";
    }
}

$obj = new Demo();
?>

Access Modifiers

  • public: Accessible from anywhere.
  • protected: Accessible inside the class and its child classes.
  • private: Accessible only inside the class where it is declared.

Inheritance

Inheritance allows a child class to acquire properties and methods of a parent class. PHP uses the extends keyword.

<?php
class Animal {
    public function eat() {
        echo "Animal eats";
    }
}

class Dog extends Animal {
    public function bark() {
        echo "Dog barks";
    }
}

$obj = new Dog();
$obj->eat();
echo "<br>";
$obj->bark();
?>

Method Overriding

Method overriding occurs when a child class provides its own implementation of a method defined in its parent class.

<?php
class ParentClass {
    public function display() {
        echo "Parent class";
    }
}

class ChildClass extends ParentClass {
    public function display() {
        echo "Child class";
    }
}

$obj = new ChildClass();
$obj->display();
?>

Polymorphism

Polymorphism means one interface can represent different forms of behavior. In PHP, it can be achieved through inheritance, method overriding and interfaces.

Abstraction

Abstraction hides implementation details and exposes only essential features. PHP supports abstraction using abstract classes and methods.

<?php
abstract class Shape {
    abstract public function area();
}

class Square extends Shape {
    public function area() {
        return 5 * 5;
    }
}

$obj = new Square();
echo $obj->area();
?>

Encapsulation

Encapsulation means combining data and methods inside a class and controlling access to data using access modifiers.

11. Exception Handling in PHP

What is an Exception?

An exception is an event that interrupts the normal flow of a program. PHP provides exception handling to manage such situations.

try and catch

The try block contains code that may generate an exception. The catch block handles the exception.

<?php
try {
    throw new Exception("Something went wrong");
}
catch (Exception $e) {
    echo "Error: " . $e->getMessage();
}
?>

finally Block

The finally block executes after try and catch processing, whether an exception occurs or not.

<?php
try {
    echo "Try block<br>";
}
catch (Exception $e) {
    echo $e->getMessage();
}
finally {
    echo "Finally block";
}
?>

throw Keyword

The throw keyword is used to generate an exception manually.

<?php
$age = 15;

try {
    if ($age < 18) {
        throw new Exception("Age must be 18 or above");
    }

    echo "Eligible";
}
catch (Exception $e) {
    echo $e->getMessage();
}
?>

Benefits of Exception Handling

  • Prevents unexpected program termination.
  • Separates error-handling code from normal code.
  • Improves program reliability.
  • Provides meaningful error messages.

12. HTML Forms and PHP Form Handling

What is an HTML Form?

An HTML form is used to collect information from users. The form data can be sent to a PHP script for processing.

Important Form Attributes

  • action – Specifies the PHP file that processes the form.
  • method – Specifies how form data is sent.
  • name – Identifies a form field.
  • type – Defines the type of input.

GET Method

The GET method sends form data through the URL as query parameters. It is suitable for non-sensitive data and requests such as searching.

<form action="welcome.php" method="GET">
    Name:
    <input type="text" name="username">
    <input type="submit" value="Submit">
</form>

Processing GET Data

<?php
if (isset($_GET["username"])) {
    $name = htmlspecialchars($_GET["username"]);
    echo "Welcome " . $name;
}
?>

POST Method

The POST method sends form data in the HTTP request body rather than placing it in the URL. It is commonly used for registration and login forms. HTTPS should be used to protect sensitive information.

<form action="welcome.php" method="POST">
    Name:
    <input type="text" name="username">
    <input type="submit" value="Submit">
</form>

Processing POST Data

<?php
if (isset($_POST["username"])) {
    $name = htmlspecialchars($_POST["username"]);
    echo "Welcome " . $name;
}
?>

Difference Between GET and POST

  • GET sends data through URL parameters.
  • POST sends data in the request body.
  • GET is useful for search and retrieval operations.
  • POST is commonly used for submitting form data.
  • Neither method alone provides encryption. HTTPS is required for secure transmission.

Form Validation

Form validation checks whether the information entered by a user is valid before processing it.

<?php
if ($_SERVER["REQUEST_METHOD"] == "POST") {

    $name = trim($_POST["name"] ?? "");

    if ($name == "") {
        echo "Name is required";
    } else {
        echo "Welcome " . htmlspecialchars($name);
    }
}
?>

Include Statement

The include statement inserts the content of another PHP file into the current file. If the file is missing, PHP normally produces a warning and continues execution.

<?php
include "header.php";
echo "Welcome to my website";
?>

Require Statement

The require statement also inserts another PHP file. If the required file is missing, PHP produces an error that stops normal execution.

<?php
require "config.php";
echo "Website loaded";
?>

Difference Between include and require

  • include produces a warning when the file cannot be included and generally continues execution.
  • require produces an error and stops execution when the required file cannot be loaded.
  • include_once and require_once prevent the same file from being included more than once.

13. Session Handling in PHP

What is a Session?

A session is used to store user information across multiple pages during a visit to a website. Session data is stored on the server.

Starting a Session

The session_start() function starts a new session or resumes an existing session. It should normally be called before sending output to the browser.

<?php
session_start();

$_SESSION["username"] = "Sanju";

echo "Session started";
?>

Accessing Session Variables

<?php
session_start();

echo $_SESSION["username"] ?? "No username";
?>

session_id()

The session_id() function returns the current session identifier.

<?php
session_start();

echo session_id();
?>

session_destroy()

The session_destroy() function destroys the current session data on the server.

<?php
session_start();

session_unset();
session_destroy();

echo "Session destroyed";
?>

Removing a Session Variable

<?php
session_start();

unset($_SESSION["username"]);
?>

Applications of Sessions

  • User login systems.
  • Shopping carts.
  • User dashboards.
  • Maintaining user information across pages.
  • Access control in web applications.

14. Introduction to MySQL

What is MySQL?

MySQL is a relational database management system used to store and manage data in tables. It uses SQL (Structured Query Language) to create, retrieve and modify data.

Features of MySQL

  • Open-source community edition.
  • Uses relational tables.
  • Supports SQL queries.
  • Supports multiple users.
  • Provides security and access control.
  • Can be connected with PHP applications.

Database

A database is an organized collection of related data.

Table

A table stores data in rows and columns.

Row

A row represents one record in a table.

Column

A column represents a particular field or attribute in a table.

Primary Key

A primary key uniquely identifies each record in a table. It cannot contain NULL values.

Foreign Key

A foreign key is a field that refers to a key in another table and helps establish a relationship between tables.

MySQL Data Types

  • INT – Integer values.
  • VARCHAR – Variable-length text.
  • CHAR – Fixed-length text.
  • TEXT – Large text data.
  • DATE – Date values.
  • DATETIME – Date and time values.
  • DECIMAL – Exact decimal numbers.
  • FLOAT – Approximate floating-point values.
  • BOOLEAN – Boolean-like values, represented using a numeric type in MySQL.

15. MySQL Commands

What is SQL?

SQL stands for Structured Query Language. It is used to communicate with relational databases.

Creating a Database

CREATE DATABASE college;

Selecting a Database

USE college;

Creating a Table

CREATE TABLE student (
    id INT PRIMARY KEY,
    name VARCHAR(50),
    marks INT
);

Inserting Records

INSERT INTO student
VALUES (1, 'Sanju', 85);

Displaying Records

SELECT * FROM student;

Updating Records

UPDATE student
SET marks = 90
WHERE id = 1;

Deleting Records

DELETE FROM student
WHERE id = 1;

Adding a Column

ALTER TABLE student
ADD email VARCHAR(100);

Deleting a Table

DROP TABLE student;

Deleting a Database

DROP DATABASE college;

Types of SQL Commands

  • DDL: Data Definition Language – CREATE, ALTER, DROP.
  • DML: Data Manipulation Language – INSERT, UPDATE, DELETE.
  • DQL: Data Query Language – SELECT.
  • DCL: Data Control Language – GRANT, REVOKE.
  • TCL: Transaction Control Language – COMMIT, ROLLBACK, SAVEPOINT.

16. Accessing MySQL Using phpMyAdmin

What is phpMyAdmin?

phpMyAdmin is a web-based tool used to manage MySQL-compatible databases through a graphical interface.

Features of phpMyAdmin

  • Create and delete databases.
  • Create and modify tables.
  • Insert, update and delete records.
  • Execute SQL queries.
  • Import and export database files.
  • Manage table structures and indexes.

Steps to Open phpMyAdmin

  1. Install and open XAMPP.
  2. Start Apache and MySQL services.
  3. Open a web browser.
  4. Enter localhost/phpmyadmin.
  5. Create or select a database.
  6. Use the interface to manage tables and records.

MySQL Client

A MySQL client is a program used to connect to a MySQL server and execute SQL statements. Examples include the MySQL command-line client and MySQL Workbench.

17. Connecting PHP with MySQL

Why Connect PHP with MySQL?

PHP is used to process application logic, while MySQL stores application data. Connecting them allows a website to save and retrieve information.

PHP MySQLi Extension

MySQLi stands for MySQL Improved. It provides procedural and object-oriented methods for connecting PHP applications to MySQL databases.

Connecting to MySQL Using MySQLi

<?php
$connection = new mysqli(
    "localhost",
    "root",
    "",
    "college"
);

if ($connection->connect_error) {
    die("Connection failed");
}

echo "Database connected successfully";

$connection->close();
?>

Creating a Database Connection

The mysqli() constructor accepts the server name, username, password and database name.

Executing a Query

<?php
$conn = new mysqli(
    "localhost",
    "root",
    "",
    "college"
);

if ($conn->connect_error) {
    die("Connection failed");
}

$sql = "SELECT * FROM student";

$result = $conn->query($sql);

if ($result) {
    while ($row = $result->fetch_assoc()) {
        echo $row["name"] . "<br>";
    }
}

$conn->close();
?>

Inserting Data Using PHP

<?php
$conn = new mysqli(
    "localhost",
    "root",
    "",
    "college"
);

if ($conn->connect_error) {
    die("Connection failed");
}

$stmt = $conn->prepare(
    "INSERT INTO student(id, name, marks) VALUES (?, ?, ?)"
);

$id = 1;
$name = "Sanju";
$marks = 85;

$stmt->bind_param("isi", $id, $name, $marks);

if ($stmt->execute()) {
    echo "Record inserted successfully";
}

$stmt->close();
$conn->close();
?>

Retrieving Records

<?php
$conn = new mysqli(
    "localhost",
    "root",
    "",
    "college"
);

$result = $conn->query("SELECT * FROM student");

if ($result) {
    while ($row = $result->fetch_assoc()) {
        echo "ID: " . $row["id"] . "<br>";
        echo "Name: " . htmlspecialchars($row["name"]) . "<br>";
        echo "Marks: " . $row["marks"] . "<br>";
    }
}

$conn->close();
?>

Updating Records Using PHP

<?php
$conn = new mysqli(
    "localhost",
    "root",
    "",
    "college"
);

$stmt = $conn->prepare(
    "UPDATE student SET marks=? WHERE id=?"
);

$marks = 95;
$id = 1;

$stmt->bind_param("ii", $marks, $id);
$stmt->execute();

echo "Record updated";

$stmt->close();
$conn->close();
?>

Deleting Records Using PHP

<?php
$conn = new mysqli(
    "localhost",
    "root",
    "",
    "college"
);

$stmt = $conn->prepare(
    "DELETE FROM student WHERE id=?"
);

$id = 1;

$stmt->bind_param("i", $id);
$stmt->execute();

echo "Record deleted";

$stmt->close();
$conn->close();
?>

Counting Records

<?php
$conn = new mysqli(
    "localhost",
    "root",
    "",
    "college"
);

$result = $conn->query(
    "SELECT COUNT(*) AS total FROM student"
);

$row = $result->fetch_assoc();

echo "Total records: " . $row["total"];

$conn->close();

18. Important PHP and MySQL Differences

PHP vs HTML

  • HTML is a markup language used to structure web pages.
  • PHP is a server-side scripting language used to create dynamic web pages.
  • HTML is interpreted by the browser.
  • PHP is executed on the server.

PHP vs JavaScript

  • PHP commonly executes on the server.
  • JavaScript commonly executes in the browser, but can also run on servers.
  • PHP can directly interact with server-side databases.
  • JavaScript is widely used for browser interactivity.

MySQL vs phpMyAdmin

  • MySQL is a relational database management system.
  • phpMyAdmin is a web-based administration tool for managing MySQL-compatible databases.

Session vs Cookie

  • Session data is stored on the server.
  • Cookies are stored in the user's browser.
  • Sessions are commonly used to maintain login information.
  • Cookies can store preferences and other small pieces of information.
