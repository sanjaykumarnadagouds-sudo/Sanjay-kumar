1. Introduction to the Internet

What is the Internet?

The Internet is a worldwide network of interconnected computers and devices. It allows people to communicate, share information and access online services.

Uses of the Internet

  • Online education and learning.
  • Email and instant messaging.
  • Online banking and shopping.
  • Video conferencing.
  • Entertainment and social networking.
  • Sharing files and information.

Internet Protocol Address (IP Address)

An IP address is a unique numerical address used to identify a device on a network.

Types of IP Addresses

  • IPv4 – Uses a 32-bit address.
  • IPv6 – Uses a 128-bit address.
IPv4 Example:
192.168.1.1

IPv6 Example:
2001:db8::1

Domain Name

A domain name is a human-readable address used to access a website. It is easier to remember than an IP address.

Example: google.com, wikipedia.org

World Wide Web (WWW)

The World Wide Web is a collection of interconnected web pages and resources that can be accessed through the Internet using a web browser.

Web Browser

A web browser is software used to access and display websites.

  • Google Chrome
  • Mozilla Firefox
  • Microsoft Edge
  • Safari
  • Opera

Web Server

A web server is a computer or software that stores website files and sends web pages to users when requested.

General Characteristics of a Web Server

  • Accepts requests from clients.
  • Processes HTTP requests.
  • Delivers web pages and files.
  • Handles multiple users.
  • Provides security and access control.

2. URL, MIME, HTTP and WWW Security

Uniform Resource Locator (URL)

A URL is the complete address used to locate a resource on the Internet.

https://www.example.com/about.html

Parts of a URL

  • Protocol – https
  • Domain name – www.example.com
  • Path – /about.html

MIME

MIME stands for Multipurpose Internet Mail Extensions. It identifies the type of content being transferred over the Internet.

Examples:

  • text/html – HTML document
  • text/plain – Plain text
  • image/jpeg – JPEG image
  • application/pdf – PDF document
  • application/json – JSON data

HTTP

HTTP stands for Hypertext Transfer Protocol. It is used for communication between web browsers and web servers.

HTTP Request Phase

The browser sends a request to the web server to access a particular resource.

GET /index.html HTTP/1.1
Host: example.com

HTTP Response Phase

The server processes the request and sends a response containing a status code, headers and sometimes the requested content.

HTTP/1.1 200 OK
Content-Type: text/html




Welcome

Common HTTP Methods

  • GET – Retrieves information.
  • POST – Sends information to the server.
  • PUT – Creates or replaces a resource.
  • PATCH – Partially updates a resource.
  • DELETE – Deletes a resource.

Common HTTP Status Codes

  • 200 – OK.
  • 301 – Moved Permanently.
  • 400 – Bad Request.
  • 401 – Unauthorized.
  • 403 – Forbidden.
  • 404 – Not Found.
  • 500 – Internal Server Error.

Security Issues in WWW

  • Phishing attacks.
  • Malware and malicious downloads.
  • Cross-Site Scripting (XSS).
  • SQL Injection.
  • Data theft.
  • Unauthorized access.
HTTPS uses TLS to protect communication between a browser and a server. It helps protect data from being read or modified during transmission.

5. Introduction to CSS

What is CSS?

CSS stands for Cascading Style Sheets. It is used to control the appearance and layout of HTML webpages.

Advantages of CSS

  • Improves webpage appearance.
  • Separates content from design.
  • Reduces repeated styling.
  • Supports responsive design.
  • Makes website maintenance easier.

CSS Syntax

selector {
    property: value;
}

Example

h1 {
    color: blue;
    font-size: 30px;
}

CSS Comments

/* This is a CSS comment */

body {
    background-color: lightblue;
}

Types of CSS

  • Inline CSS – Written inside an HTML element using the style attribute.
  • Internal CSS – Written inside a style element in the HTML document.
  • External CSS – Written in a separate .css file.

CSS Selectors

/* Element selector */

/* Group selector */

    font-family: Arial;
}

6. CSS Positioning, Transforms and Effects

CSS Position

  • Static – Default positioning.
  • Relative – Positioned relative to its normal position.
  • Absolute – Positioned relative to its nearest positioned ancestor.
  • Fixed – Positioned relative to the viewport.
  • Sticky – Behaves like relative until a scroll threshold is reached.
.box {
    position: relative;
    top: 20px;
    left: 30px;
}

Z-Index

The z-index property controls the stacking order of positioned elements.

CSS 2D Transforms

2D transforms change an element's position, size or rotation in two dimensions.

.box {
    transform: rotate(20deg);
}

/* Other examples */
transform: translate(20px, 10px);
transform: scale(1.2);
transform: skew(10deg);

CSS 3D Transforms

3D transforms allow elements to rotate and move in three-dimensional space.

.card {
    transform: rotateY(180deg);
    transform-style: preserve-3d;
    perspective: 800px;
}

CSS Transitions

Transitions make changes in CSS properties happen smoothly over a specified time.

button {
    background: blue;
    transition: background 0.5s;
}

button:hover {
    background: red;
}

CSS Animations

Animations allow elements to change styles through keyframes.

@keyframes move {
    from {
        transform: translateX(0);
    }

    to {
        transform: translateX(100px);
    }
}

.box {
    animation: move 2s infinite alternate;
}

CSS Masking

CSS masking controls which parts of an element are visible using a mask image or gradient.

.box {
    -webkit-mask-image:
    linear-gradient(black, transparent);
    mask-image:
    linear-gradient(black, transparent);

11. Regular Expressions (RegExp)

What is a Regular Expression?

A regular expression is a sequence of characters used to search, match and validate patterns in strings.

Creating a Regular Expression

// Using literal notation
let pattern = /hello/i;

// Using RegExp constructor
let pattern2 = new RegExp("hello", "i");

Common Regular Expression Symbols

  • ^ – Matches the beginning of a string.
  • $ – Matches the end of a string.
  • . – Matches any character except line terminators by default.
  • * – Matches zero or more repetitions.
  • + – Matches one or more repetitions.
  • ? – Matches zero or one repetition.
  • [abc] – Matches a, b or c.
  • [0-9] – Matches a digit.
  • \d – Matches a digit.
  • \w – Matches a word character.
  • \s – Matches whitespace.

Regular Expression Methods

let text = "Welcome to JavaScript";

let pattern = /JavaScript/i;

console.log(pattern.test(text));

console.log(text.match(pattern));

console.log(text.search(pattern));

Example: Validate Mobile Number

let mobile = "9876543210";

let pattern = /^[0-9]{10}$/;

if(pattern.test(mobile)) {
    console.log("Valid Mobile Number");
} else {
    console.log("Invalid Mobile Number");
}

Example: Validate Email Format

let email = "student@example.com";

let pattern = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;

if(pattern.test(email)) {
    console.log("Valid Email Format");
} else {
    console.log("Invalid Email Format");
}
Regular expressions can check the format of input data, but they cannot guarantee that a mobile number or email address actually belongs to a particular person.
