UNIT 1 – COMPUTER FUNDAMENTALS

1. What is a Computer?

A computer is an electronic device that accepts data as input, processes the data according to instructions, stores information and produces meaningful results as output.

Example: When we enter two numbers into a calculator, the computer processes them and displays their sum.

2. Basic Functions of a Computer

  1. Input: Accepts data from the user.
  2. Processing: Performs calculations and operations.
  3. Storage: Saves data and information.
  4. Output: Displays the final result.
Example:
Input: 10 + 20
Processing: Addition
Output: 30

3. Characteristics of a Computer

  • Speed: Performs millions of operations quickly.
  • Accuracy: Produces accurate results when correct data and instructions are given.
  • Diligence: Can work continuously without getting tired.
  • Storage: Stores large amounts of data.
  • Versatility: Performs different types of tasks.
  • Automation: Works automatically when instructions are provided.

4. Basic Components of a Computer

A computer system has four major functional units:

Component Function
Input Unit Accepts data and instructions.
CPU Processes data and controls operations.
Memory Unit Stores data and instructions.
Output Unit Displays the processed results.

Central Processing Unit (CPU)

The CPU is called the brain of the computer. Its main parts include:

  • ALU: Arithmetic Logic Unit performs mathematical and logical operations.
  • CU: Control Unit controls and coordinates computer activities.
  • Registers: Small, fast storage locations inside the CPU.

5. Input Devices

Input devices are used to enter data and instructions into a computer.

  • Keyboard – enters text and numbers.
  • Mouse – selects and controls items.
  • Scanner – converts paper documents into digital form.
  • Microphone – inputs sound.
  • Webcam – captures images and video.

6. Output Devices

Output devices display the results produced by a computer.

  • Monitor – displays information on a screen.
  • Printer – produces printed documents.
  • Speaker – produces sound.
  • Projector – displays images on a large screen.

7. Memory of a Computer

Memory is used to store data, instructions and results.

Primary Memory Secondary Memory
Directly accessible by the CPU. Used for long-term storage.
Examples: RAM and ROM. Examples: Hard disk, SSD and pen drive.
Generally faster. Generally slower than primary memory.

RAM: Random Access Memory is temporary memory. Its contents are normally lost when power is switched off.

ROM: Read Only Memory is non-volatile memory. It retains its contents without power.

8. Types of Software

Software is a collection of programs and instructions that tell a computer what to do.

  • System Software: Manages computer hardware and provides a platform for applications. Example: Windows and Linux.
  • Application Software: Helps users perform specific tasks. Example: MS Word and web browsers.

9. Computer Languages

  • Machine Language: Uses binary digits (0 and 1). It is directly understood by the computer.
  • Assembly Language: Uses symbolic instructions such as ADD and SUB.
  • High-Level Language: Uses human-readable instructions. Examples: C, C++ and Java.

10. Types of Computers

  • Supercomputer: Used for complex scientific calculations and weather forecasting.
  • Mainframe Computer: Handles large amounts of data and many users.
  • Minicomputer: A mid-range multi-user computer category.
  • Microcomputer: A personal computer such as a desktop or laptop.

UNIT 2 – NUMBER SYSTEMS AND BINARY ARITHMETIC

1. What is a Number System?

A number system is a method of representing numbers using a set of symbols or digits. Computers use different number systems to represent and process data.

Number SystemBaseDigits Used
Decimal100 to 9
Binary20 and 1
Octal80 to 7
Hexadecimal160 to 9 and A to F

2. Decimal Number System

The decimal number system has base 10. It uses ten digits from 0 to 9. It is commonly used in everyday calculations.

Example: 245
= 2 × 100 + 4 × 10 + 5 × 1
= 200 + 40 + 5

3. Binary Number System

The binary number system has base 2. It uses only two digits, 0 and 1. Computers use binary because digital electronic circuits can represent two states.

Example: (1011)₂
= 1 × 8 + 0 × 4 + 1 × 2 + 1 × 1
= 8 + 0 + 2 + 1
= (11)₁₀

4. Octal Number System

The octal number system has base 8. It uses digits from 0 to 7.

Example: (157)₈
= 1 × 64 + 5 × 8 + 7 × 1
= 64 + 40 + 7
= (111)₁₀

The hexadecimal number system has base 16. It uses digits 0 to 9 and letters A to F.

6. Decimal to Binary Conversion

Divide the decimal number repeatedly by 2. Write down the remainders and read them from bottom to top.

Convert (13)₁₀ into binary:

13 ÷ 2 = 6 remainder 1
6 ÷ 2 = 3 remainder 0
3 ÷ 2 = 1 remainder 1
1 ÷ 2 = 0 remainder 1

Answer: (1101)₂

7. Binary to Decimal Conversion

Multiply each binary digit by its corresponding power of 2, starting from the right with 2⁰.

Convert (1101)₂ into decimal:

= 1 × 2³ + 1 × 2² + 0 × 2¹ + 1 × 2⁰
= 8 + 4 + 0 + 1
= (13)₁₀

10. BCD (Binary Coded Decimal)

BCD is a coding system in which each decimal digit is represented separately using four binary bits.

11. Gray Code

Gray code is a binary code in which two consecutive values differ by only one bit. It helps reduce errors during certain digital transitions.

Binary: 000, 001, 010, 011

UNIT 3 – BOOLEAN ALGEBRA AND LOGIC GATES

1. What is Boolean Algebra?

Boolean algebra is a branch of mathematics used in digital electronics and computer systems. It works with only two values: 0 (False) and 1 (True).

Example:
A = 1
B = 0
A AND B = 0

2. Basic Boolean Operations

  • AND: Gives 1 only when all inputs are 1.
  • OR: Gives 1 when at least one input is 1.
  • NOT: Changes 1 to 0 and 0 to 1.

11. De Morgan's Theorems

There are two important De Morgan's theorems:

First theorem:
(A · B)' = A' + B'

Second theorem:
(A + B)' = A' · B'

These theorems are used to simplify Boolean expressions and digital circuits.

12. Karnaugh Map (K-Map)

A Karnaugh Map is a graphical method used to simplify Boolean expressions. It helps reduce the number of logic gates required in a digital circuit.

For two variables, the K-map has four cells representing the combinations 00, 01, 10 and 11.

UNIT 4 – COMBINATIONAL AND SEQUENTIAL LOGIC CIRCUITS

1. Combinational Logic Circuits

A combinational logic circuit is a digital circuit in which the output depends only on the present inputs. It does not store previous information.

Examples: Adders, subtractors, encoders, decoders and multiplexers.

2. Half Adder

A half adder is a combinational circuit used to add two binary bits. It produces Sum and Carry.

Equations:

Sum = A ⊕ B
Carry = A · B
ABSumCarry
0000
0110
1010
1101

3. Full Adder

A full adder adds three binary bits: A, B and Carry-in. It produces Sum and Carry-out.

Sum = A ⊕ B ⊕ Cin
Carry = AB + BCin + ACin

A full adder can be constructed using two half adders and one OR gate.

4. Half Subtractor

A half subtractor subtracts one binary bit from another. It produces Difference and Borrow.

Difference = A ⊕ B
Borrow = A' · B
ABDifferenceBorrow
0000
0111
1010
1100

5. Full Subtractor

A full subtractor subtracts two bits and a borrow-in. It produces Difference and Borrow-out.

Difference = A ⊕ B ⊕ Bin
Borrow = A'B + A'Bin + BBin

It can be constructed using two half subtractors and one OR gate.

6. Sequential Logic Circuits

A sequential logic circuit is a digital circuit whose output depends on present inputs and previous states. It uses memory elements to store information.

Examples: Flip-flops, counters and shift registers.

7. Flip-Flops

A flip-flop is a basic memory element used to store one bit of binary information.

Types of flip-flops:

  • SR Flip-Flop
  • JK Flip-Flop
  • Master-Slave JK Flip-Flop
  • T Flip-Flop

8. SR Flip-Flop

SR stands for Set-Reset. It has two inputs: S and R.

SROutput
00No Change
01Reset (0)
10Set (1)
11Invalid

9. JK Flip-Flop

JK flip-flop is an improved version of the SR flip-flop. It has two inputs J and K.

JKOutput
00No Change
01Reset (0)
10Set (1)
11Toggle

10. Master-Slave JK Flip-Flop

It consists of two JK flip-flops connected together: Master and Slave.

The Master receives the input first, and the Slave updates the output at the opposite clock phase. It helps prevent the race-around condition.

11. T Flip-Flop

T stands for Toggle. It changes its output when T = 1.

TOutput
0No Change
1Toggle

12. Decoder – 3 to 8 Lines

A decoder is a combinational circuit that converts binary input information into one of several output lines.

A 3-to-8 decoder has 3 input lines and 8 output lines. For each valid input combination, one output becomes active.

Applications: Memory selection and digital systems.

13. Encoder – Octal to Binary

An encoder converts an active input line into a binary code.

An octal-to-binary encoder has 8 input lines and 3 output lines.

Example: If input line 5 is active, the binary output is 101.

14. Multiplexer – 4 to 1 Line

A multiplexer (MUX) is a digital circuit that selects one input from multiple inputs and sends it to a single output.

A 4-to-1 multiplexer has:

  • 4 data inputs (I0, I1, I2, I3)
  • 2 selection lines (S1, S0)
  • 1 output (Y)

15. 3-Bit Binary Ripple Counter

A counter is a sequential circuit used to count clock pulses.

A 3-bit binary ripple counter uses 3 flip-flops and counts from 000 to 111 (0 to 7). It then repeats the sequence.

000 → 001 → 010 → 011 → 100 → 101 → 110 → 111

16. Shift Registers

A shift register is a sequential circuit used to store and move binary data from one flip-flop to another.

Types in this syllabus:

  • SIPO: Serial-In-Parallel-Out. Data enters one bit at a time and is available together at the outputs.
  • PISO: Parallel-In-Serial-Out. Data enters together and is sent out one bit at a time.

Applications: Data storage and data transfer.
