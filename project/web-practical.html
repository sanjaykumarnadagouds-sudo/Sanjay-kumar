Program 7: Create a Circle and Animate Bouncing for 10 Seconds

Aim

To create a circle and animate it to bounce for 10 seconds using CSS animation.

Program Code

<!DOCTYPE html>
<html>
<head>
    <title>Bouncing Circle</title>

    <style>
        .container {
            width: 400px;
            height: 200px;
            border-bottom: 3px solid black;
            position: relative;
        }

        .circle {
            width: 50px;
            height: 50px;
            background-color: blue;
            border-radius: 50%;
            position: absolute;
            left: 20px;
            animation: bounce 1s infinite alternate;
        }

        @keyframes bounce {
            from {
                top: 0;
            }

            to {
                top: 140px;
            }
        }
    </style>
</head>
<body>

    <h2>Bouncing Circle</h2>

    <div class="container">
        <div class="circle" id="ball"></div>
    </div>

    <script>
        setTimeout(function() {
            document.getElementById("ball")
            .style.animation = "none";
        }, 10000);
    </script>

</body>
</html>

Expected Output

A blue circle bounces vertically for 10 seconds and then stops.

Result

Thus, a bouncing circle animation is created using CSS keyframes and JavaScript timing.

Program 9: Factorial of a Number Using JavaScript Prompt

Aim

To find the factorial of a number entered by the user using JavaScript.

Program Code

<!DOCTYPE html>
<html>
<head>
    <title>Factorial</title>
</head>
<body>

<h2>Factorial Program</h2>

<script>
    let n = Number(prompt("Enter a number"));

    if (!Number.isInteger(n) || n < 0) {
        document.write("Enter a non-negative integer.");
    } else {
        let fact = 1;

        for(let i = 1; i <= n; i++) {
            fact = fact * i;
        }

        document.write("Factorial = " + fact);
    }
</script>

</body>
</html>

Expected Output

Input: 5
Output: Factorial = 120

Result

Thus, the factorial of a number is calculated using JavaScript.

Program 10: Simple Calculator

Aim

To create a simple calculator using JavaScript.

Program Code

<!DOCTYPE html>
<html>
<head>
    <title>Simple Calculator</title>
</head>
<body>

<h2>Simple Calculator</h2>

<input type="number" id="a"
placeholder="First Number">

<input type="number" id="b"
placeholder="Second Number">

<br><br>

<button onclick="calculate('+')">Add</button>
<button onclick="calculate('-')">Subtract</button>
<button onclick="calculate('*')">Multiply</button>
<button onclick="calculate('/')">Divide</button>

<h3 id="result">Result:</h3>

<script>
function calculate(operator) {

    let a = Number(document.getElementById("a").value);
    let b = Number(document.getElementById("b").value);

    let result;

    if (operator === '+') {
        result = a + b;
    }
    else if (operator === '-') {
        result = a - b;
    }
    else if (operator === '*') {
        result = a * b;
    }
    else if (operator === '/') {
        result = b === 0
            ? "Cannot divide by zero"
            : a / b;
    }

    document.getElementById("result").innerHTML =
        "Result: " + result;
}
</script>

</body>
</html>

Expected Output

Enter first number: 20
Enter second number: 10
Addition: 30
Subtraction: 10
Multiplication: 200
Division: 2

Result

Thus, a simple calculator is created using JavaScript.

    event.preventDefault();

    let username =
    document.getElementById("username").value;

    let password =

Program 15: Validate University Register Number Using RegExp

Aim

To validate a university register number using JavaScript regular expressions.

Program Code

<!DOCTYPE html>
<html>
<head>
    <title>Register Number Validation</title>
</head>
<body>

<h2>University Register Number</h2>

<input type="text" id="regno"
placeholder="Enter Register Number">

<button onclick="validate()">Check</button>

<p id="result"></p>

<script>
function validate() {

    let regno =
    document.getElementById("regno").value.trim();

    let pattern = /^[A-Za-z0-9]{10,15}$/;

    if(pattern.test(regno)) {

        document.getElementById("result")
        .innerHTML = "Valid Register Number";

    } else {

        document.getElementById("result")
        .innerHTML = "Invalid Register Number";
    }
}
</script>

</body>
</html>

Expected Output

Input: ABC1234567
Output: Valid Register Number

Input: ABC123
Output: Invalid Register Number

Result

Thus, a register number is checked using a regular expression.

Note: The 10–15 character alphanumeric pattern is a demonstration pattern. Replace it with the exact university register-number format if your college specifies one.
