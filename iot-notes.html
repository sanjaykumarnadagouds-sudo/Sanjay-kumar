UNIT 1 – Introduction to IoT

1. Introduction to Internet of Things

Internet of Things (IoT) is a technology that connects physical objects to the internet. These objects contain sensors, software and communication devices that allow them to collect and exchange data.

IoT allows devices to communicate with each other and perform tasks with little or no human involvement.

Examples

  • Smart watches that monitor health and activity.
  • Smart bulbs controlled using mobile phones.
  • Smart refrigerators that monitor food storage.
  • Smart agriculture systems that monitor soil moisture.
  • Connected vehicles that share information.
Example: A smart irrigation system checks soil moisture. If the soil becomes dry, the system automatically switches on the water pump.

2. IoT and Digitization

Digitization means converting information or physical activities into digital form so that computers can process them.

IoT extends digitization by connecting physical devices to networks. These devices collect real-time information and send it to applications or cloud platforms.

Difference between Digitization and IoT

3. Impact of IoT

IoT has changed the way people, businesses and industries operate. It provides automation, real-time monitoring and better decision-making.

Major impacts

  • Automation: Devices perform tasks automatically.
  • Efficiency: Reduces unnecessary work and saves time.
  • Cost reduction: Helps reduce operational expenses.
  • Real-time monitoring: Provides current information about devices and systems.
  • Better decisions: Data helps users make informed decisions.
  • Improved safety: Sensors can detect dangerous conditions.

4. Convergence of IT and OT

Information Technology (IT) deals with computers, software, networks and information management.

Operational Technology (OT) deals with hardware and software used to monitor and control physical devices, machines and industrial processes.

Examples of IT

  • Database systems
  • Cloud computing
  • Computer networks
  • Business applications

Examples of OT

  • Industrial machines
  • Factory control systems
  • Robotics
  • Temperature control equipment

IT and OT convergence means combining information systems with operational systems to improve monitoring, automation and industrial performance.

Example: In a smart factory, machine sensors collect production data. IT systems analyse the data and help managers monitor factory performance.

5. Challenges of IoT

Although IoT provides many advantages, it also faces several challenges.

  • Security: Connected devices may be attacked by hackers.
  • Privacy: Devices may collect personal information.
  • Connectivity: Internet interruptions can affect device communication.
  • Compatibility: Devices from different manufacturers may not work together.
  • Data management: IoT systems generate large amounts of data.
  • Power consumption: Some devices require frequent battery replacement.
  • Cost: Installation and maintenance can be expensive.
  • Scalability: Managing a large number of connected devices is difficult.

Three-layer architecture

  1. Perception Layer: Collects information using sensors and devices.
  2. Network Layer: Transfers data between devices and processing systems.
  3. Application Layer: Provides services to users.

7. Core IoT Functional Stack

The IoT functional stack describes the main functions required for an IoT system to operate.

  • Things: Physical devices, sensors and actuators.
  • Connectivity: Transfers information between devices and systems.
  • Edge Computing: Processes data near the device to reduce delay.
  • Data Accumulation: Stores incoming data for future use.
  • Data Abstraction: Organises and prepares data for applications.
  • Application: Provides user services and controls.
  • Collaboration and Processes: Helps people and systems use information to perform actions.

8. IoT Data Management and Compute Stack

IoT devices produce large amounts of data. Data management and computing systems are used to collect, store, process and analyse this information.

Data management

  • Data collection from sensors.
  • Data storage in databases or cloud platforms.
  • Data organisation and filtering.
  • Data security and backup.
  • Data analysis and reporting.

Computing methods

  • Device Computing: Processing performed directly by IoT devices.
  • Edge Computing: Processing performed close to the devices.
  • Fog Computing: Processing distributed across local network nodes between devices and cloud.
  • Cloud Computing: Processing and storage provided through remote internet servers.
Example: A security camera may detect movement locally using edge computing and send selected video information to cloud storage.

UNIT 2 – IoT Networks

9. Sensors, Actuators and Smart Objects

Sensor

A sensor is an electronic device that detects changes in the physical environment and converts them into signals or data.

Examples: Temperature sensor, humidity sensor, light sensor, motion sensor and pressure sensor.

Actuator

An actuator is a device that converts a control signal into a physical action.

Examples: Electric motor, relay, buzzer, valve and water pump.

Smart Object

A smart object is a physical object containing processing, sensing and communication capabilities that allow it to interact with other devices.

SensorActuator
Collects information.Performs an action.

10. Sensor Networks

A sensor network is a group of connected sensors that collect information from an environment and communicate it to a central system.

Components

  • Sensor nodes
  • Communication links
  • Gateway or base station
  • Data processing system
  • Power supply

Applications

  • Environmental monitoring
  • Agriculture
  • Industrial automation
  • Healthcare monitoring
  • Smart buildings

11. Communication Criteria

Communication criteria are the factors considered when selecting a communication technology for IoT devices.

  • Range: Distance over which devices can communicate.
  • Bandwidth: Amount of data that can be transferred.
  • Power consumption: Energy required for communication.
  • Latency: Time taken for data to travel.
  • Reliability: Ability to transfer data correctly.
  • Security: Protection of transmitted information.
  • Cost: Cost of devices, installation and communication.
  • Scalability: Ability to support more connected devices.

13. Need for Optimization in IoT

Optimization means improving the performance of an IoT system while reducing unnecessary resource usage.

Why optimization is required

  • To reduce battery consumption.
  • To reduce network traffic.
  • To improve communication speed.
  • To reduce operating costs.
  • To improve device performance.
  • To support a large number of devices.

Optimization methods

  • Use low-power communication technologies.
  • Send only necessary data.
  • Use data compression.
  • Process information near the device.
  • Use efficient routing methods.

14. Optimizing IP for IoT

Internet Protocol (IP) allows devices to communicate across networks. IoT devices often have limited memory, processing power and battery capacity.

Optimizing IP for IoT means making IP communication more suitable for resource-constrained devices.

Important approaches

  • IPv6: Provides a very large address space for connected devices.
  • 6LoWPAN: Enables IPv6 communication over low-power wireless personal area networks.
  • Header Compression: Reduces packet overhead.
  • Efficient Routing: Helps devices find suitable communication paths.
  • Low-power Communication: Reduces energy usage.

UNIT 3 – Protocols and Data Analytics

15. Transport Layer

The transport layer provides communication between applications running on different devices. It manages how data is delivered between communicating systems.

Main transport protocols

TCP – Transmission Control Protocol

  • Connection-oriented protocol.
  • Provides reliable data delivery.
  • Uses acknowledgements and retransmission.
  • Useful when reliable delivery is important.

UDP – User Datagram Protocol

  • Connectionless protocol.
  • Has lower communication overhead.
  • Does not guarantee delivery.
  • Useful for applications that need low delay.

16. IoT Application Transport Methods

IoT application transport methods describe how application data is exchanged between devices, gateways and servers.

Common methods and protocols

  • HTTP/HTTPS: Transfers data between clients and web servers.
  • MQTT: Lightweight publish-subscribe messaging protocol used in IoT.
  • CoAP: Lightweight web transfer protocol designed for constrained devices.
  • WebSocket: Supports two-way communication over a persistent connection.
  • AMQP: Messaging protocol used for reliable message exchange.

17. Data Analytics for IoT

IoT data analytics is the process of examining data collected from connected devices to discover patterns, identify problems and support decision-making.

Types of analytics

  • Descriptive Analytics: Explains what happened.
  • Diagnostic Analytics: Explains why something happened.
  • Predictive Analytics: Predicts what may happen in the future.
  • Prescriptive Analytics: Suggests actions to achieve a desired result.

Steps in IoT data analytics

  1. Collect data from sensors.
  2. Clean and prepare the data.
  3. Store the collected data.
  4. Analyse the data.
  5. Identify useful patterns.
  6. Display results and take action.

18. Machine Learning in IoT

Machine Learning (ML) is a branch of artificial intelligence that allows computer systems to learn patterns from data and make predictions or decisions.

In IoT, machine learning analyses sensor data to identify patterns and automate actions.

Applications

  • Predictive maintenance in factories.
  • Smart home automation.
  • Health monitoring.
  • Traffic prediction.
  • Crop disease detection.
  • Energy consumption prediction.

Types of Machine Learning

  • Supervised Learning: Learns from labelled data.
  • Unsupervised Learning: Finds patterns in unlabelled data.
  • Reinforcement Learning: Learns through rewards and penalties.

19. Big Data Analytics Tools and Technology

Big Data refers to extremely large and complex datasets that require special technologies for storage, processing and analysis.

Characteristics of Big Data – 5 Vs

  • Volume: Large amount of data.
  • Velocity: Speed at which data is generated.
  • Variety: Different types of data.
  • Veracity: Accuracy and reliability of data.
  • Value: Useful information obtained from data.

Tools and technologies

  • Apache Hadoop: Distributed storage and processing.
  • Apache Spark: Fast data processing and analytics.
  • Python: Data analysis and machine learning.
  • Apache Kafka: Real-time data streaming.
  • Cloud Platforms: Scalable storage and computing services.

20. Network Analytics

Network analytics is the process of collecting and analysing network data to understand network performance, identify problems and improve communication.

Important measurements

  • Latency: Delay in data transmission.
  • Throughput: Amount of data successfully transferred.
  • Packet Loss: Percentage of packets that fail to reach their destination.
  • Bandwidth: Maximum data-carrying capacity of a network.
  • Network Availability: Time during which a network is operational.

Uses

  • Detect network failures.
  • Monitor connected devices.
  • Identify unusual network activity.
  • Improve network performance.
  • Support network security.

UNIT 4 – IoT in Industry and Smart Cities

21. IoT in Industry

Industrial IoT (IIoT) refers to the use of connected devices, sensors, communication networks and data analytics in industrial environments.

Applications

  • Smart Manufacturing: Monitors production machines.
  • Predictive Maintenance: Predicts machine failures before they happen.
  • Supply Chain: Tracks goods and materials.
  • Energy Management: Monitors electricity consumption.
  • Quality Control: Detects defects during production.
  • Worker Safety: Monitors dangerous conditions.

22. Smart and Connected Cities

A smart city uses digital technologies, IoT devices and data analytics to improve public services, infrastructure and quality of life.

Examples of smart city services

  • Smart Traffic: Uses sensors to monitor traffic and manage signals.
  • Smart Parking: Detects available parking spaces.
  • Smart Lighting: Adjusts street lights according to conditions.
  • Smart Waste Management: Monitors waste-bin levels.
  • Smart Water Supply: Detects leaks and monitors water usage.
  • Smart Environment: Monitors air quality and pollution.

23. IoT Strategy for Smarter Cities

An IoT strategy for smart cities is a planned approach to using connected technologies to solve urban problems and improve city services.

Important steps

  1. Identify the city's major problems.
  2. Set clear goals for improvement.
  3. Select suitable sensors and IoT devices.
  4. Build communication infrastructure.
  5. Collect and analyse data.
  6. Protect devices and information.
  7. Monitor performance and improve the system.
Example: A city may install smart traffic sensors to monitor congestion and adjust traffic signals to improve vehicle movement.

24. Smart City IoT Architecture

Smart city IoT architecture describes how devices, communication networks, data platforms and applications work together to provide city services.

Main components

  1. Device Layer: Sensors, cameras, meters and smart devices.
  2. Communication Layer: Transfers data using Wi-Fi, cellular, LPWAN and other technologies.
  3. Platform Layer: Stores, processes and analyses information.
  4. Application Layer: Provides smart traffic, parking, water and lighting services.
  5. Management and Security: Controls access, monitors devices and protects information across the system.

25. Smart City Security Architecture

Smart city security architecture protects connected devices, networks, applications and data from unauthorised access and cyberattacks.

Important security measures

  • Authentication: Verifies the identity of users and devices.
  • Authorization: Controls what users and devices are allowed to do.
  • Encryption: Protects data during storage and transmission.
  • Access Control: Limits access to authorised people and systems.
  • Network Security: Protects communication networks.
  • Software Updates: Fixes security weaknesses.
  • Monitoring: Detects unusual activities and attacks.
  • Backup: Helps recover important information after failures.

26. Smart City Use-Case Examples

Smart Traffic Management

Traffic sensors collect information about vehicles. The system analyses traffic conditions and can adjust traffic signals to reduce congestion.

Smart Parking

Parking sensors detect whether a space is occupied. Drivers can use an application to find available parking spaces.

Smart Waste Management

Sensors installed in waste bins measure their filling levels. Collection teams can plan routes based on the information.

Smart Water Management

Connected meters and sensors monitor water consumption, detect leakage and help manage water distribution.

Smart Street Lighting

Light and motion sensors can control street lights according to surrounding conditions and activity.

Smart Environment Monitoring

Air-quality and environmental sensors collect information about pollution, temperature and other environmental conditions.
