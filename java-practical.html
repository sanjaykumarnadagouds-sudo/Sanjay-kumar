Aim

To check whether the given number is positive, negative or zero using Java.

Source Code – PositiveNegative.java

import java.util.Scanner;

class PositiveNegative {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Enter a number: ");
        int n = sc.nextInt();

        if (n > 0) {

6. Find Maximum and Minimum Elements in a One-Dimensional Array

Aim

To find the maximum and minimum elements in a one-dimensional array.

Source Code – ArrayMaxMin.java

import java.util.Scanner;

class ArrayMaxMin {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        int[] a = new int[100];

        System.out.print("Enter number of elements: ");
        int n = sc.nextInt();

        if (n <= 0 || n > 100) {
            System.out.println("Invalid array size");
            sc.close();
            return;
        }

        System.out.println("Enter array elements:");
        for (int i = 0; i < n; i++) {
            a[i] = sc.nextInt();
        }

        int max = a[0];
        int min = a[0];

        for (int i = 1; i < n; i++) {
            if (a[i] > max) {
                max = a[i];
            }

            if (a[i] < min) {
                min = a[i];
            }
        }

        System.out.println("Maximum element: " + max);
        System.out.println("Minimum element: " + min);

        sc.close();
    }
}

Sample Output

Enter number of elements: 5
Enter array elements:
10 50 20 5 40
Maximum element: 50
Minimum element: 5

Result

Thus, maximum and minimum elements are found successfully.

7. Check Whether a String is Palindrome

Aim

To check whether the given string is a palindrome or not.

Source Code – StringPalindrome.java

import java.util.Scanner;

class StringPalindrome {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Enter a string: ");
        String str = sc.nextLine();

        String reverse = "";

        for (int i = str.length() - 1; i >= 0; i--) {
            reverse = reverse + str.charAt(i);
        }

        if (str.equalsIgnoreCase(reverse)) {
            System.out.println("Palindrome string");
        } else {
            System.out.println("Not a palindrome string");
        }

        sc.close();
    }
}

Sample Output

Enter a string: madam
Palindrome string

Result

Thus, the given string is checked for palindrome.

8. Student Class Using an Array of Three Student Objects

Aim

To create a Student class with registration number, name and marks of three subjects, calculate total marks and display the results of three students.

Source Code – StudentArray.java

import java.util.Scanner;

class Student {
    String regNo;
    String name;
    int m1, m2, m3;
    int total;

    void accept(Scanner sc) {
        System.out.print("Enter registration number: ");
        regNo = sc.next();

        System.out.print("Enter name: ");
        name = sc.next();

        System.out.print("Enter three subject marks: ");
        m1 = sc.nextInt();
        m2 = sc.nextInt();
        m3 = sc.nextInt();

        total = m1 + m2 + m3;
    }

    void display() {
        System.out.println("\nRegistration Number: " + regNo);
        System.out.println("Name: " + name);
        System.out.println("Subject 1: " + m1);
        System.out.println("Subject 2: " + m2);
        System.out.println("Subject 3: " + m3);
        System.out.println("Total Marks: " + total);
    }
}

class StudentArray {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        Student[] s = new Student[3];

        for (int i = 0; i < 3; i++) {
            s[i] = new Student();
            System.out.println("\nEnter Student " + (i + 1) + " Details");
            s[i].accept(sc);
        }

        System.out.println("\n----- STUDENT RESULTS -----");

        for (int i = 0; i < 3; i++) {
            s[i].display();
        }

        sc.close();
    }
}

12. AWT Window with Morning, Afternoon, Evening and Close Buttons

Aim

To create an AWT window with four buttons M, A, E and Close to display greetings.

Source Code – GreetingWindow.java

import java.awt.*;
import java.awt.event.*;

class GreetingWindow extends Frame implements ActionListener {
    Label message;
    Button morning, afternoon, evening, close;

    GreetingWindow() {
        setTitle("Greeting Window");
        setSize(400, 250);
        setLayout(new FlowLayout());

        message = new Label("Click a button");
        morning = new Button("M");
        afternoon = new Button("A");
        evening = new Button("E");
        close = new Button("Close");

        add(message);
        add(morning);
        add(afternoon);
        add(evening);
        add(close);

        morning.addActionListener(this);
        afternoon.addActionListener(this);
        evening.addActionListener(this);
        close.addActionListener(this);

        addWindowListener(new WindowAdapter() {
            public void windowClosing(WindowEvent e) {
                dispose();
            }
        });

        setVisible(true);
    }

    public void actionPerformed(ActionEvent e) {
        String command = e.getActionCommand();

        if (command.equals("M")) {
            message.setText("Good Morning");
        } else if (command.equals("A")) {
            message.setText("Good Afternoon");
        } else if (command.equals("E")) {
            message.setText("Good Evening");
        } else if (command.equals("Close")) {
            dispose();
        }
    }

    public static void main(String[] args) {
        new GreetingWindow();
    }
}

Expected Output

An AWT window appears with:
[M] [A] [E] [Close]

Click M     → Good Morning
Click A     → Good Afternoon
Click E     → Good Evening
Click Close → Window closes

Result

Thus, an AWT greeting window is created with four buttons and event handling.

14. Read and Write Binary I/O File

Aim

To write data into a binary file and read the stored data using Java byte streams.

Source Code – BinaryFileDemo.java

import java.io.*;

class BinaryFileDemo {
    public static void main(String[] args) {
        String fileName = "student.dat";

        // Writing binary data
        try {
            DataOutputStream out =
                new DataOutputStream(
                    new FileOutputStream(fileName)
                );

            out.writeInt(101);
            out.writeUTF("Rahul");
            out.writeDouble(85.5);

            out.close();

            System.out.println("Data written successfully");
        }
        catch (IOException e) {
            System.out.println("Writing error: " + e.getMessage());
        }

        // Reading binary data
        try {
            DataInputStream in =
                new DataInputStream(
                    new FileInputStream(fileName)
                );

            int id = in.readInt();
            String name = in.readUTF();
            double marks = in.readDouble();

            System.out.println("Student ID: " + id);
            System.out.println("Student Name: " + name);
            System.out.println("Student Marks: " + marks);

            in.close();
        }
        catch (IOException e) {
            System.out.println("Reading error: " + e.getMessage());
        }
    }
}

Sample Output

Data written successfully
Student ID: 101
Student Name: Rahul
Student Marks: 85.5

Result

Thus, binary data is written into and read from a file successfully. The file student.dat is created in the program's working directory.

16. Create Menu Bar and Pull-Down Menus

Aim

To create an AWT window containing a menu bar and pull-down menus.

Source Code – MenuDemo.java

import java.awt.*;
import java.awt.event.*;

class MenuDemo extends Frame implements ActionListener {
    Label message;

    MenuDemo() {
        setTitle("Menu Bar Demo");
        setSize(400, 250);
        setLayout(new FlowLayout());

        message = new Label("Select an option from the menu");
        add(message);

        MenuBar menuBar = new MenuBar();

        Menu fileMenu = new Menu("File");
        Menu editMenu = new Menu("Edit");

        MenuItem newItem = new MenuItem("New");
        MenuItem openItem = new MenuItem("Open");
        MenuItem exitItem = new MenuItem("Exit");

        MenuItem copyItem = new MenuItem("Copy");
        MenuItem pasteItem = new MenuItem("Paste");

        fileMenu.add(newItem);
        fileMenu.add(openItem);
        fileMenu.addSeparator();
        fileMenu.add(exitItem);

        editMenu.add(copyItem);
        editMenu.add(pasteItem);

        menuBar.add(fileMenu);
        menuBar.add(editMenu);

        setMenuBar(menuBar);

        newItem.addActionListener(this);
        openItem.addActionListener(this);
        exitItem.addActionListener(this);
        copyItem.addActionListener(this);
        pasteItem.addActionListener(this);

        addWindowListener(new WindowAdapter() {
            public void windowClosing(WindowEvent e) {
                dispose();
            }
        });

        setVisible(true);
    }

    public void actionPerformed(ActionEvent e) {
        String command = e.getActionCommand();

        if (command.equals("Exit")) {
            dispose();
        } else {
            message.setText(command + " selected");
        }
    }

    public static void main(String[] args) {
        new MenuDemo();
    }
}

Expected Output

An AWT window appears.

New
Open
Exit

Edit menu:
Copy
Paste

Selecting New   → New selected
Selecting Open  → Open selected

Result

Thus, a menu bar and pull-down menus are created successfully using AWT.

Java Practical Viva Questions

Important Viva Questions and Answers

1. What is Java?
Java is a high-level, object-oriented programming language.

2. What is JVM?
JVM stands for Java Virtual Machine. It executes Java bytecode.

3. What is JDK?
JDK stands for Java Development Kit. It provides tools to develop Java programs.

4. What is JRE?
JRE stands for Java Runtime Environment. It provides the environment to run Java programs.

5. What is a class?
A class is a blueprint used to create objects.

6. What is an object?
An object is an instance of a class.

7. What is inheritance?
Inheritance allows one class to acquire the properties and methods of another class.

8. What is method overloading?
Defining multiple methods with the same name but different parameter lists.

9. What is an exception?
An exception is an event that interrupts the normal flow of program execution.

10. What is try-catch?
It is used to detect and handle exceptions.

11. What is AWT?
AWT stands for Abstract Window Toolkit. It is used to create graphical user interfaces in Java.

12. What is an event?
An event is an action such as a mouse click or button press.

13. What is a thread?
A thread is a lightweight unit of execution within a program.

14. What is file handling?
File handling is the process of reading data from and writing data to files.

15. What is an array?
An array stores multiple values of the same data type in a single variable.
