UNIT 1 – INTRODUCTION TO OPERATING SYSTEM

1. What is an Operating System?

An Operating System (OS) is system software that acts as an interface between the user and computer hardware. It manages all computer resources and provides an environment for executing programs.

Examples

  • Microsoft Windows
  • Linux
  • macOS
  • Android
  • UNIX

2. Objectives of Operating System

The main objectives of an operating system are:

  • Convenience: Makes the computer easy to use.
  • Efficiency: Uses hardware resources efficiently.
  • Resource Management: Manages CPU, memory and devices.
  • Security: Protects data and programs.
  • Performance: Improves overall system performance.

3. Functions of Operating System

An operating system performs the following functions:

  • Process management
  • Memory management
  • File management
  • Device management
  • Security management
  • User interface management
  • Error detection and handling

4. Types of Operating System

  • Batch OS: Executes a group of jobs in batches without direct user interaction.
  • Multiprogramming OS: Keeps multiple programs in memory to improve CPU utilization.
  • Multitasking OS: Allows multiple tasks to run seemingly at the same time.
  • Time Sharing OS: Gives each user or process a small amount of CPU time.
  • Multiprocessing OS: Uses two or more processors to execute tasks.
  • Real-Time OS: Responds to events within specified time limits.
  • Distributed OS: Manages multiple connected computers as a coordinated system.
  • Network OS: Provides services and resource sharing over a network.

5. Batch Operating System

A Batch Operating System collects similar jobs and executes them in groups called batches. There is no direct interaction between the user and the job during execution.

Advantages

  • Suitable for large repetitive tasks.
  • Reduces manual intervention.
  • Can process many jobs together.

Disadvantages

  • Long waiting time.
  • Debugging is difficult.
  • No immediate user interaction.

6. Multiprogramming Operating System

Multiprogramming is a technique in which multiple programs are kept in main memory at the same time. When one program waits for input or output, the CPU can execute another program.

Advantages

  • Improves CPU utilization.
  • Reduces CPU idle time.
  • Increases system efficiency.

7. Time Sharing Operating System

A Time Sharing Operating System allows multiple users or processes to share CPU time. Each process receives a small time interval called a time slice or time quantum.

Advantages

  • Provides quick response.
  • Supports multiple users.
  • Allows interactive computing.

8. Real-Time Operating System

A Real-Time Operating System (RTOS) processes data and responds to events within a specified time limit.

Types

  • Hard Real-Time OS: Missing a deadline is considered a system failure.
  • Soft Real-Time OS: Missing a deadline occasionally is undesirable but may be acceptable.

Examples

Air traffic control systems, industrial control systems and medical monitoring systems.

9. Kernel and Shell

Kernel: The kernel is the core part of an operating system. It manages CPU, memory and hardware resources.

Shell: The shell is a user interface that allows users to communicate with the operating system through commands or graphical tools.

Difference

  • Kernel manages system resources.
  • Shell accepts user commands.
  • Kernel works close to hardware.
  • Shell provides access to OS services.

10. System Calls

System calls are the interface through which application programs request services from the operating system kernel.

Types of System Calls

  • Process control
  • File management
  • Device management
  • Information maintenance
  • Communication
  • Protection

UNIT 2 – PROCESS MANAGEMENT AND CPU SCHEDULING

1. What is a Process?

A process is a program that is currently in execution. It includes program code, data, memory, CPU registers and other resources needed for execution.

Examples

  • Running a web browser.
  • Playing a video.
  • Running a calculator application.

2. Process States

A process passes through different states during its execution.

  • New: Process is being created.
  • Ready: Process is waiting for CPU allocation.
  • Running: Process is being executed by the CPU.
  • Waiting: Process is waiting for an event or I/O operation.
  • Terminated: Process has completed execution.

3. Process Control Block (PCB)

A Process Control Block is a data structure maintained by the operating system to store information about a process.

Information stored in PCB

  • Process ID
  • Process state
  • Program counter
  • CPU registers
  • CPU scheduling information
  • Memory management information
  • I/O status information

4. Process Scheduling

Process scheduling is the method used by the operating system to select a process from the ready queue and allocate the CPU to it.

Types of Schedulers

  • Long-Term Scheduler: Selects jobs to be brought into memory.
  • Short-Term Scheduler: Selects a ready process for CPU execution.
  • Medium-Term Scheduler: Temporarily removes processes from memory and later brings them back.

5. CPU Scheduling Algorithms

CPU scheduling algorithms decide which process gets the CPU next.

  • First Come First Served (FCFS)
  • Shortest Job First (SJF)
  • Priority Scheduling
  • Round Robin Scheduling

6. First Come First Served (FCFS)

FCFS is a non-preemptive scheduling algorithm. The process that arrives first gets the CPU first.

Advantages

  • Simple and easy to implement.
  • Fair according to arrival order.

Disadvantages

  • Can cause long waiting times.
  • May suffer from the convoy effect.

7. Shortest Job First (SJF)

SJF is a scheduling algorithm that selects the process with the smallest CPU burst time first.

Advantages

  • Can give minimum average waiting time when burst times are known.
  • Short processes finish quickly.

Disadvantages

  • CPU burst time is difficult to predict exactly.
  • Long processes may suffer starvation.

8. Priority Scheduling

Priority Scheduling assigns a priority value to every process. The CPU is allocated to the process with the highest priority according to the system's priority convention.

Advantages

  • Important processes can be executed first.
  • Useful in priority-based systems.

Disadvantages

  • Low-priority processes may suffer starvation.
  • Aging can be used to reduce starvation.

9. Round Robin Scheduling

Round Robin is a preemptive scheduling algorithm. Each process gets a fixed time quantum. If it does not finish within that time, it goes back to the ready queue.

Advantages

  • Suitable for time-sharing systems.
  • Provides regular CPU access to processes.

Disadvantages

  • Performance depends on time quantum.
  • Very small time quantum causes many context switches.

10. Context Switching

Context switching is the process of saving the state of one process and loading the state of another process so that the CPU can switch between them.

It allows multitasking but also introduces some overhead because the CPU spends time switching instead of executing user processes.

UNIT 3 – MEMORY MANAGEMENT AND DEADLOCKS

1. Memory Management

Memory management is the function of an operating system that controls and coordinates the use of main memory. It allocates and deallocates memory to processes.

Functions

  • Memory allocation.
  • Memory deallocation.
  • Memory protection.
  • Memory tracking.
  • Memory sharing.

2. Contiguous Memory Allocation

Contiguous memory allocation is a memory management technique in which each process is allocated a continuous block of memory.

Types

  • Fixed partitioning.
  • Variable partitioning.

3. Fragmentation

Fragmentation refers to the wastage of memory space during memory allocation.

Types

  • Internal Fragmentation: Wasted space inside an allocated memory block.
  • External Fragmentation: Free memory exists in small scattered blocks, making it difficult to allocate a large continuous block.

4. Paging

Paging is a memory management technique in which physical memory is divided into fixed-size blocks called frames and logical memory is divided into blocks called pages.

Advantages

  • Eliminates external fragmentation in basic paging.
  • Allows non-contiguous memory allocation.
  • Supports virtual memory.

5. Segmentation

Segmentation is a memory management technique in which a program is divided into variable-sized logical units called segments.

Examples of Segments

  • Code segment
  • Data segment
  • Stack segment

Segmentation supports logical program organization but can cause external fragmentation.

6. Virtual Memory

Virtual memory is a memory management technique that allows a program to execute even when the entire program is not loaded into main memory.

Advantages

  • Allows large programs to run.
  • Improves memory utilization.
  • Supports multiprogramming.

7. Demand Paging

Demand paging is a technique in which a page is loaded into main memory only when it is required by the executing process.

If the required page is not available in memory, a page fault occurs and the operating system brings the page from secondary storage.

8. Page Replacement Algorithms

Page replacement algorithms decide which page should be removed from memory when a new page must be loaded and no free frame is available.

  • FIFO: Replaces the page that entered memory first.
  • LRU: Replaces the page that has not been used for the longest time.
  • Optimal: Replaces the page that will not be used for the longest time in the future. It is mainly a theoretical benchmark.

9. What is Deadlock?

Deadlock is a situation in which two or more processes wait indefinitely for resources held by one another, so none of them can proceed.

Example

Process P1 holds Resource R1 and waits for R2, while Process P2 holds R2 and waits for R1.

10. Necessary Conditions for Deadlock

Four conditions must hold simultaneously for a deadlock to occur:

  • Mutual Exclusion: A resource can be used by only one process at a time.
  • Hold and Wait: A process holds resources while waiting for more resources.
  • No Preemption: Resources cannot be forcibly taken away.
  • Circular Wait: Processes form a circular chain of waiting.

11. Deadlock Handling Methods

  • Prevention: Ensure at least one necessary deadlock condition cannot hold.
  • Avoidance: Allocate resources only when the system remains in a safe state.
  • Detection: Identify deadlocks after they occur.
  • Recovery: Take action to break the deadlock, such as terminating processes or reclaiming resources.

12. Banker's Algorithm

Banker's Algorithm is a deadlock avoidance algorithm. It checks whether allocating resources will keep the system in a safe state.

Important Terms

  • Available: Resources currently available.
  • Maximum: Maximum resources a process may need.
  • Allocation: Resources currently allocated.
  • Need: Remaining resources required by a process.

Need = Maximum − Allocation.

UNIT 4 – FILE MANAGEMENT AND DEVICE MANAGEMENT

1. File System

A file system is a method used by an operating system to organize, store, retrieve and manage files on storage devices.

Functions

  • File creation and deletion.
  • File naming and organization.
  • File storage and retrieval.
  • File protection and access control.

2. File Attributes

File attributes are the properties associated with a file.

  • Name: Name of the file.
  • Identifier: Unique identification of the file.
  • Type: Type or format of the file.
  • Location: Storage location of the file.
  • Size: Size of the file.
  • Protection: Access permissions.
  • Time and Date: Creation and modification details.

3. File Operations

The operating system provides several operations to manage files.

  • Create a file.
  • Open a file.
  • Read a file.
  • Write to a file.
  • Close a file.
  • Delete a file.
  • Rename a file.

4. File Access Methods

File access methods describe how data is accessed from a file.

  • Sequential Access: Data is accessed one after another in sequence.
  • Direct Access: Any location in the file can be accessed directly.
  • Indexed Access: An index is used to locate records quickly.

5. Directory Structure

A directory is a structure used by an operating system to organize files and folders.

Types of Directory Structures

  • Single-level directory.
  • Two-level directory.
  • Tree-structured directory.
  • Acyclic-graph directory.
  • General graph directory.

6. File Allocation Methods

File allocation methods describe how disk blocks are assigned to files.

  • Contiguous Allocation: File blocks are stored next to each other.
  • Linked Allocation: File blocks are connected using pointers.
  • Indexed Allocation: An index block stores addresses of file blocks.

7. Device Management

Device management is the operating system function responsible for controlling and coordinating input and output devices.

Functions

  • Allocating and releasing devices.
  • Managing device drivers.
  • Handling input and output operations.
  • Monitoring device status.

8. Device Drivers

A device driver is system software that allows the operating system to communicate with a hardware device.

Examples

  • Printer driver.
  • Keyboard driver.
  • Graphics driver.
  • Audio driver.

9. Spooling

Spooling stands for Simultaneous Peripheral Operations On-Line. It stores data temporarily in a queue or buffer so that a device can process jobs one by one.

Example

When several documents are sent to a printer, they are placed in a print queue and printed one after another.

10. Disk Scheduling

Disk scheduling is the method used by the operating system to decide the order in which disk I/O requests are serviced.

Disk Scheduling Algorithms

  • FCFS: Services requests in arrival order.
  • SSTF: Selects the request closest to the current disk head position.
  • SCAN: Disk head moves in one direction servicing requests, then reverses.
  • C-SCAN: Disk head services requests in one direction and returns to the beginning.
  • LOOK: Similar to SCAN, but reverses at the last pending request.

11. Protection and Security

Protection and security help prevent unauthorized access to computer resources and data.

Security Methods

  • User authentication.
  • Password protection.
  • File permissions.
  • Access control.
  • Encryption.
  • Security updates.
