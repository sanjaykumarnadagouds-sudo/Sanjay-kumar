UNIT 1 – INTRODUCTION TO C# AND .NET FRAMEWORK

1. Introduction to C#

C# (C-Sharp) is a modern, object-oriented and type-safe programming language developed by Microsoft. It is mainly used to develop desktop applications, web applications, games and enterprise software.

Features of C#

  • Simple and easy to learn.
  • Object-oriented programming language.
  • Type-safe language.
  • Automatic memory management.
  • Supports exception handling.
  • Supports multithreading.
  • Rich .NET library support.
  • Cross-platform development through modern .NET.

2. History of C#

C# was developed by Microsoft under the leadership of Anders Hejlsberg. It was introduced in 2000 as part of Microsoft's .NET initiative. It was designed to combine the power of C++ with the simplicity of modern programming languages.

Important points

  • Developed by Microsoft.
  • Designed by Anders Hejlsberg and his team.
  • Introduced around 2000.
  • Used with the .NET platform.
  • Continues to evolve with new language versions.

3. .NET Framework

The .NET Framework is a software development platform created by Microsoft. It provides an environment and libraries for developing and executing applications, especially on Windows.

Main components

  • CLR: Common Language Runtime.
  • FCL: Framework Class Library.
  • CTS: Common Type System.
  • CLS: Common Language Specification.
  • MSIL: Microsoft Intermediate Language.

4. Common Language Runtime (CLR)

CLR is the execution engine of the .NET Framework. It manages the execution of .NET programs and provides services required during program execution.

Functions of CLR

  • Memory management.
  • Garbage collection.
  • Exception handling.
  • Security management.
  • Thread management.
  • Code execution.

5. CTS and CLS

Common Type System (CTS): Defines the data types and programming constructs supported by the .NET runtime.

Common Language Specification (CLS): Defines a set of rules that .NET languages follow to support language interoperability.

Difference

CTSCLS
Defines common data types.Defines common language rules.
Supports type compatibility.Supports language interoperability.

6. Intermediate Language and JIT Compiler

C# source code is compiled into Intermediate Language (IL) by the C# compiler. At runtime, the Just-In-Time (JIT) compiler converts the IL into native machine code for execution.

Compilation steps

  1. Write C# source code.
  2. Compile source code.
  3. Generate Intermediate Language.
  4. JIT compiler converts IL into machine code.
  5. Program executes.

7. Data Types in C#

Data types specify the kind of value a variable can store.

Main categories

  • Value types: int, float, double, char, bool, struct and enum.
  • Reference types: string, object, arrays, classes and interfaces.

Examples

  • int age = 20;
  • float marks = 85.5f;
  • char grade = 'A';
  • bool result = true;
  • string name = "Student";

8. Variables and Constants

A variable is a named memory location used to store data. Its value can change during program execution.

A constant is a fixed value that cannot be changed after declaration.

Example

  • int age = 20;
  • const double PI = 3.14;

9. Operators in C#

Operators are symbols used to perform operations on variables and values.

  • Arithmetic: +, -, *, /, %
  • Relational: ==, !=, greater than, less than
  • Logical: &&, ||, !
  • Assignment: =, +=, -=, *=
  • Unary: ++, --
  • Conditional: ?:

UNIT 2 – OBJECT ORIENTED PROGRAMMING CONCEPTS

10. Object-Oriented Programming

Object-Oriented Programming (OOP) is a programming approach based on classes and objects. It helps organize programs into reusable and manageable components.

Main principles

  • Class and Object.
  • Encapsulation.
  • Inheritance.
  • Polymorphism.
  • Abstraction.

11. Class and Object

Class: A class is a blueprint or template used to create objects. It contains data members and methods.

Object: An object is an instance of a class. It represents a real-world entity.

Example

  • Student is a class.
  • Sanju is an object of the Student class.

12. Methods in C#

A method is a block of code that performs a particular task. Methods help divide a program into smaller reusable parts.

Types of methods

  • Static methods.
  • Instance methods.
  • Methods with parameters.
  • Methods with return values.
  • Methods without return values.

13. Constructors

A constructor is a special member of a class that is automatically called when an object is created. It is commonly used to initialize objects.

Types of constructors

  • Default constructor.
  • Parameterized constructor.
  • Copy constructor (user-defined pattern in C#).
  • Static constructor.

Important features

  • Constructor name is the same as the class name.
  • It has no return type.
  • It can be overloaded.

14. Constructor Overloading

Constructor overloading means defining multiple constructors in the same class with different parameter lists.

It allows objects to be initialized in different ways.

15. Encapsulation

Encapsulation is the process of combining data and methods into a single unit called a class. It protects data from direct unwanted access.

Advantages

  • Data security.
  • Better code organization.
  • Controlled access to data.
  • Easy maintenance.

16. Inheritance

Inheritance is an OOP feature in which one class acquires the properties and methods of another class.

Types of inheritance

  • Single inheritance.
  • Multilevel inheritance.
  • Hierarchical inheritance.

C# supports multiple inheritance of class behavior through interfaces, but a class cannot directly inherit from multiple classes.

17. Polymorphism

Polymorphism means one name having many forms. It allows the same method or operation to behave differently in different situations.

Types

  • Compile-time polymorphism: Method overloading and operator overloading.
  • Runtime polymorphism: Method overriding using inheritance and virtual methods.

18. Method Overloading and Overriding

Method Overloading: Multiple methods have the same name but different parameter lists in the same class or scope.

Method Overriding: A derived class provides a new implementation of an inherited virtual or abstract method.

OverloadingOverriding
Different parameter lists.Same method signature in derived class.
Compile-time polymorphism.Runtime polymorphism.
Inheritance is not required.Inheritance is required.

19. Abstract Classes and Interfaces

Abstract class: A class declared using the abstract keyword. It cannot be directly instantiated and may contain abstract and implemented members.

Interface: A contract that specifies members a type must implement, subject to the language's interface rules.

Difference

Abstract ClassInterface
Can contain instance fields.Does not contain instance fields.
A class can inherit one base class.A class can implement multiple interfaces.
Can contain constructors.Cannot be instantiated or have ordinary instance constructors.

UNIT 3 – ADVANCED C# CONCEPTS

20. Arrays in C#

An array is a collection of elements of the same data type stored under one variable name. Each element is accessed using an index.

Types of arrays

  • Single-dimensional array.
  • Multidimensional array.
  • Jagged array.

21. Strings in C#

A string is a sequence of characters. In C#, string is a reference type and string objects are immutable, meaning their contents cannot be changed after creation.

Common string methods

  • Length
  • ToUpper()
  • ToLower()
  • Substring()
  • Replace()
  • Contains()
  • Trim()

22. Exception Handling

An exception is an unexpected event that occurs during program execution and interrupts the normal flow of the program.

Keywords

  • try: Contains code that may generate an exception.
  • catch: Handles the exception.
  • finally: Contains code that normally executes whether an exception occurs or not.
  • throw: Used to explicitly raise an exception.

23. Delegates

A delegate is a type-safe reference to a method. It allows methods to be passed as arguments and called through a delegate instance.

Uses

  • Callback methods.
  • Event handling.
  • Flexible method execution.
  • Connecting methods with events.

24. Events in C#

An event is a notification mechanism used by an object to inform other objects that something has happened. Events commonly use delegates.

Example

A button click in a Windows Forms application is an event. When the user clicks the button, the associated event handler runs.

25. Collections in C#

Collections are used to store and manage groups of objects or values. They provide flexible ways to add, remove and access elements.

Common collections

  • ArrayList.
  • List.
  • Stack.
  • Queue.
  • Dictionary.
  • HashSet.

26. File Handling

File handling is used to create, read, write, append and delete files. C# provides classes in the System.IO namespace for file operations.

Common classes

  • File.
  • FileInfo.
  • StreamReader.
  • StreamWriter.
  • FileStream.
  • Directory.

27. Multithreading

Multithreading is the process of executing multiple threads within a single program. It helps perform multiple tasks concurrently.

Advantages

  • Improves responsiveness.
  • Supports concurrent tasks.
  • Can improve resource utilization.
  • Useful for background operations.

UNIT 4 – .NET APPLICATIONS AND DATABASE CONNECTIVITY

28. Windows Forms

Windows Forms is a graphical user interface technology for building Windows desktop applications using .NET.

Common controls

  • Label.
  • TextBox.
  • Button.
  • CheckBox.
  • RadioButton.
  • ComboBox.
  • ListBox.
  • DataGridView.

29. Properties, Methods and Events of Controls

Windows Forms controls provide properties, methods and events to manage their behavior.

  • Properties: Describe the appearance and state of a control.
  • Methods: Perform actions on a control.
  • Events: Respond to user actions.

Examples

  • Text – property.
  • Show() – method.
  • Click – event.

30. ADO.NET

ADO.NET is a data access technology used by .NET applications to communicate with databases. It provides classes for connecting to databases, retrieving data and updating records.

Main components

  • Connection.
  • Command.
  • DataReader.
  • DataAdapter.
  • DataSet.
  • DataTable.

31. Connected and Disconnected Architecture

Connected architecture: Maintains a database connection while data is being accessed. DataReader is commonly used for fast, forward-only reading.

Disconnected architecture: Retrieves data into memory and allows it to be used without keeping the database connection continuously open. DataSet and DataAdapter are commonly used.

ConnectedDisconnected
Connection remains open during access.Connection can be closed after fetching data.
DataReader is commonly used.DataSet and DataAdapter are commonly used.
Forward-only reading is typical.Data can be manipulated in memory.

32. Database Connection

A database connection establishes communication between a .NET application and a database. A connection object uses a connection string containing information required to connect.

Common providers

  • SqlClient for SQL Server.
  • OleDb for OLE DB data sources.
  • Odbc for ODBC data sources.

33. DataReader and DataAdapter

DataReader: Reads data from a database in a forward-only, read-only manner while the connection is open.

DataAdapter: Acts as a bridge between a database and a DataSet or DataTable. It can retrieve and update data.

34. DataSet and DataTable

DataSet: An in-memory representation of data that can contain multiple DataTables and relationships.

DataTable: Represents one table of in-memory data containing rows and columns.

35. Advantages of ADO.NET

  • Provides database connectivity.
  • Supports connected and disconnected data access.
  • Supports multiple database providers.
  • Allows data retrieval and modification.
  • Supports XML integration.
  • Can work with DataSet and DataTable.
