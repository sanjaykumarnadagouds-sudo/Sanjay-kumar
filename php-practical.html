2. Factorial of a Number

    $fact = $fact * $i;

3. Check Palindrome Number

Program: Check whether a number reads the same forward and backward.

<?php
$n = 121;
$temp = $n;
$reverse = 0;

while ($temp > 0) {
    $digit = $temp % 10;
    $reverse = $reverse * 10 + $digit;
    $temp = (int)($temp / 10);
}

if ($n == $reverse) {
    echo "$n is a Palindrome";
} else {
    echo "$n is not a Palindrome";
}
?>

Output

121 is a Palindrome

4. Reverse a Number and Find Sum of Digits

Program: Reverse the number and calculate the sum of its digits.

<?php
$n = 1234;
$temp = $n;
$reverse = 0;
$sum = 0;

while ($temp > 0) {
    $digit = $temp % 10;
    $reverse = $reverse * 10 + $digit;
    $sum = $sum + $digit;
    $temp = (int)($temp / 10);
}

echo "Original Number: $n<br>";
echo "Reverse Number: $reverse<br>";
echo "Sum of Digits: $sum";
?>

Output

Original Number: 1234
Reverse Number: 4321
Sum of Digits: 10

5. Fibonacci Series Using Recursive Function

Program: Generate Fibonacci numbers using recursion.

<?php
function fibonacci($n) {
    if ($n == 0) {
        return 0;
    }
    if ($n == 1) {
        return 1;
    }
    return fibonacci($n - 1) + fibonacci($n - 2);
}

$count = 7;

for ($i = 0; $i < $count; $i++) {
    echo fibonacci($i) . " ";
}
?>

Output

0 1 1 2 3 5 8

15. Create a Table and Insert Data Using PHP

Program: Create a student table and insert a record into it.

<?php
$conn = new mysqli("localhost", "root", "", "studentverse");

if ($conn->connect_error) {
    die("Connection failed: " . $conn->connect_error);
}

$sql = "CREATE TABLE IF NOT EXISTS students (
    id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(100),
    course VARCHAR(50)
)";

if (!$conn->query($sql)) {
    die("Table error: " . $conn->error);
}

$stmt = $conn->prepare(
    "INSERT INTO students (name, course) VALUES (?, ?)"
);

$name = "Sanjay";
$course = "BCA";

$stmt->bind_param("ss", $name, $course);

if ($stmt->execute()) {
    echo "Student record inserted successfully";
} else {
    echo "Insert failed: " . $stmt->error;
}

$stmt->close();
$conn->close();
?>

Output

Student record inserted successfully

16. College Admission Form Using MySQL

Program: Create an admission form and store submitted details in a MySQL database.

Step 1 – Create Database and Table

CREATE DATABASE college;

USE college;

CREATE TABLE admission (
    id INT AUTO_INCREMENT PRIMARY KEY,
    student_name VARCHAR(100),
    email VARCHAR(100),
    course VARCHAR(50)
);

Step 2 – Save as admission.php

<?php
$conn = new mysqli("localhost", "root", "", "college");

if ($conn->connect_error) {
    die("Connection failed");
}

$message = "";

if ($_SERVER["REQUEST_METHOD"] == "POST") {
    $name = trim($_POST["name"]);
    $email = trim($_POST["email"]);
    $course = trim($_POST["course"]);

    $stmt = $conn->prepare(
        "INSERT INTO admission (student_name, email, course)
         VALUES (?, ?, ?)"
    );

    $stmt->bind_param("sss", $name, $email, $course);

    if ($stmt->execute()) {
        $message = "Admission submitted successfully";
    } else {
        $message = "Unable to submit admission";
    }

    $stmt->close();
}
?>

<h2>College Admission Form</h2>

<form method="POST" action="">
    Student Name:
    <input type="text" name="name" required>
    <br><br>

    Email:
    <input type="email" name="email" required>
    <br><br>

    Course:
    <select name="course" required>
        <option value="">Select Course</option>
        <option value="BCA">BCA</option>
        <option value="BCom">BCom</option>
        <option value="BSc">BSc</option>
    </select>
    <br><br>

    <button type="submit">Submit Admission</button>
</form>

<p><?php echo htmlspecialchars($message); ?></p>

<?php $conn->close(); ?>

Sample Output

College Admission Form

Student Name: Sanjay
Email: sanjay@example.com
Course: BCA

Admission submitted successfully

Save this file inside the XAMPP htdocs folder and open it through localhost. Create the college database and table first.
