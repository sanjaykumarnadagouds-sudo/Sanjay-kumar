UNIT 1 – MATHEMATICAL LOGIC AND SET THEORY

1. Mathematical Logic

Mathematical logic is the study of statements and their truth values. A statement is a sentence that is either True or False.

Example: 5 is greater than 3 – True.

2. Logical Connectives

  • Negation (NOT): Reverses the truth value.
  • Conjunction (AND): True only when both statements are true.
  • Disjunction (OR): True when at least one statement is true.
  • Conditional: If p, then q.
  • Biconditional: p if and only if q.

3. Truth Table

A truth table shows the truth values of logical expressions.

4. Tautology and Contradiction

Tautology: A statement that is always true.

Example: p OR NOT p.

Contradiction: A statement that is always false.

Example: p AND NOT p.

5. Set Theory

A set is a well-defined collection of distinct objects.

Example: A = {1, 2, 3, 4, 5}

Empty set: A set containing no elements.

Subset: A set whose elements are all contained in another set.

6. Set Operations

Let A = {1, 2, 3} and B = {3, 4, 5}.

  • Union (A ∪ B): {1, 2, 3, 4, 5}
  • Intersection (A ∩ B): {3}
  • Difference (A − B): {1, 2}

7. Laws of Set Theory

  • Commutative law: A ∪ B = B ∪ A
  • Associative law: (A ∪ B) ∪ C = A ∪ (B ∪ C)
  • Identity law: A ∪ ∅ = A
  • Idempotent law: A ∪ A = A
  • De Morgan's law: (A ∪ B)' = A' ∩ B'

8. Counting and Venn Diagrams

Venn diagrams represent sets using circles.

Formula for two sets:

n(A ∪ B) = n(A) + n(B) − n(A ∩ B)

Example: If n(A) = 20, n(B) = 15 and n(A ∩ B) = 5:

n(A ∪ B) = 20 + 15 − 5 = 30.

  3. Define tautology and contradiction.
  4. Explain sets and subsets.
  5. Explain different set operations.
  6. State the laws of set theory.
  7. Solve problems using Venn diagrams.

UNIT 2 – CARTESIAN PRODUCTS, RELATIONS AND FUNCTIONS

1. Cartesian Product

The Cartesian product of two sets A and B is the set of all ordered pairs (a, b), where a belongs to A and b belongs to B.

Example:

A = {1, 2} and B = {a, b}

A × B = {(1,a), (1,b), (2,a), (2,b)}

Formula: n(A × B) = n(A) × n(B)

2. Relation

A relation is a connection between elements of two sets. Mathematically, a relation from A to B is a subset of A × B.

Example:

A = {1, 2, 3}

R = {(1,2), (2,3)}

Here, R is a relation on A.

3. Types of Relations

  • Reflexive: Every element is related to itself.
  • Symmetric: If a is related to b, then b is related to a.
  • Transitive: If a is related to b and b to c, then a is related to c.
  • Antisymmetric: If a is related to b and b to a, then a = b.
  • Equivalence relation: A relation that is reflexive, symmetric and transitive.

4. Domain and Range

Domain: The set of all first elements in ordered pairs.

Range: The set of all second elements in ordered pairs.

Example: R = {(1,2), (2,3), (3,4)}

Domain = {1, 2, 3}

Range = {2, 3, 4}

5. Function

A function is a relation in which every input has exactly one output.

Example: f(x) = x + 2

If x = 3, then f(3) = 3 + 2 = 5.

6. Types of Functions

  • One-to-One (Injective): Different inputs have different outputs.
  • Many-to-One: Different inputs may have the same output.
  • Onto (Surjective): Every element of the codomain has a preimage.
  • Into: At least one element of the codomain is not an output.
  • Bijective: A function that is both one-to-one and onto.

7. Composition of Functions

Composition means applying one function after another.

Formula: (f ∘ g)(x) = f(g(x))

Example:

f(x) = x + 2 and g(x) = 3x

(f ∘ g)(x) = f(3x) = 3x + 2

8. Inverse Function

An inverse function reverses the operation of the original function.

Example:

f(x) = x + 5

Replace f(x) with y: y = x + 5

Interchange x and y: x = y + 5

Therefore, f⁻¹(x) = x − 5.

UNIT 3 – STATISTICS: MEAN, MEDIAN AND MODE

1. Meaning of Statistics

Statistics is the branch of mathematics that deals with collecting, organizing, presenting, analysing and interpreting data.

Types of Data

  • Primary Data: Data collected directly by the researcher.
  • Secondary Data: Data collected from existing sources such as books and websites.
  • Discrete Data: Data that can be counted, such as the number of students.
  • Continuous Data: Data that can be measured, such as height and weight.

2. Arithmetic Mean

Mean is the average value of a given set of observations.

Formula

Mean = Sum of all observations / Number of observations

x̄ = Σx / n

Example

Find the mean of 2, 4, 6, 8.

Sum = 2 + 4 + 6 + 8 = 20

Number of observations = 4

Mean = 20 / 4 = 5

Mean for Frequency Distribution

Mean = Σfx / Σf

Here, f = frequency and x = observation.

3. Median

Median is the middle value of a set of observations arranged in ascending or descending order.

For Odd Number of Observations

Median = Value of the (n + 1) / 2 th observation.

Example: 3, 5, 7, 9, 11

Middle value = 7

For Even Number of Observations

Median = Average of the two middle values.

Example: 2, 4, 6, 8

Median = (4 + 6) / 2 = 5

Median for Grouped Data

Median = L + [(N/2 - cf) / f] × h

  • L = Lower boundary of median class
  • N = Total frequency
  • cf = Cumulative frequency before median class
  • f = Frequency of median class
  • h = Class width

4. Mode

Mode is the value that occurs most frequently in a given set of observations.

Example

Find the mode of 2, 3, 3, 4, 5.

The number 3 occurs most frequently.

Mode = 3

Mode for Grouped Data

Mode = L + [(f₁ - f₀) / (2f₁ - f₀ - f₂)] × h

  • L = Lower boundary of modal class
  • f₁ = Frequency of modal class
  • f₀ = Frequency of preceding class
  • f₂ = Frequency of succeeding class
  • h = Class width

5. Difference Between Mean, Median and Mode

Mean Median Mode
Average value Middle value Most repeated value
Uses all values Uses middle position Uses frequency

UNIT 4 – STANDARD DEVIATION, COEFFICIENT OF VARIATION, CORRELATION AND REGRESSION

1. Standard Deviation

Standard deviation is a measure used to find how much the values are spread out from their mean.

Formula

SD (σ) = √[Σ(x - x̄)² / n]

  • x = Individual observation
  • x̄ = Arithmetic mean
  • n = Number of observations
  • Σ = Summation

Example

Find the standard deviation of 2, 4, 6.

Mean = (2 + 4 + 6) / 3 = 4

Squared deviations = (2 - 4)² + (4 - 4)² + (6 - 4)²

= 4 + 0 + 4 = 8

Variance = 8 / 3

SD = √(8 / 3) = 1.63 approximately

2. Coefficient of Variation (CV)

Coefficient of Variation is used to compare the variability of two or more data sets.

Formula

CV = (Standard Deviation / Mean) × 100

Example

Mean = 50 and Standard Deviation = 5.

CV = (5 / 50) × 100

CV = 10%

Uses

  • To compare consistency between data sets.
  • To measure relative variation.
  • Lower CV generally indicates greater consistency.

3. Correlation

Correlation is a statistical method used to measure the relationship between two variables.

Types of Correlation

  • Positive Correlation: Both variables move in the same direction.
  • Negative Correlation: Variables move in opposite directions.
  • Zero Correlation: No linear relationship between the variables.

Examples

  • Positive: More study time may be associated with higher marks.
  • Negative: More speed may be associated with less travel time for a fixed distance.
  • Zero: Two variables with no apparent linear relationship.

Correlation Coefficient

The correlation coefficient is represented by r.

-1 ≤ r ≤ +1

  • r = +1: Perfect positive correlation.
  • r = -1: Perfect negative correlation.
  • r = 0: No linear correlation.

4. Karl Pearson's Correlation Coefficient

Karl Pearson's method measures the degree and direction of a linear relationship between two variables.

Formula

r = Σ(x - x̄)(y - ȳ) / √[Σ(x - x̄)² × Σ(y - ȳ)²]

Here:

  • x and y = Two variables
  • x̄ = Mean of x values
  • ȳ = Mean of y values
  • r = Correlation coefficient

5. Regression

Regression is a statistical technique used to estimate or predict the value of one variable based on another variable.

Types of Regression

  • Simple Linear Regression: Uses one independent variable to predict a dependent variable.
  • Multiple Regression: Uses two or more independent variables to predict a dependent variable.

Regression Equation

y = a + bx

  • y = Predicted value
  • x = Independent variable
  • a = Intercept
  • b = Slope

Uses of Regression

  • Predicting sales.
  • Estimating future values.
  • Studying relationships between variables.

6. Difference Between Correlation and Regression

Correlation Regression
Measures relationship between variables. Predicts one variable using another.
Represented by r. Represented by a regression equation.
Does not identify dependent and independent variables. Uses dependent and independent variables.
