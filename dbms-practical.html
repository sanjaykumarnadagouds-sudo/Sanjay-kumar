Activity 1: Student Database – DDL and DML Statements

Aim

To create a Student database table and perform DDL and DML operations.

Procedure

  1. Create a Student table.
  2. Insert student records.
  3. Display all records.
  4. Modify table structure.
  5. Update and delete records.

SQL Program

CREATE TABLE Student (
    StudentID INT PRIMARY KEY,
    Name VARCHAR(50),
    Course VARCHAR(30),
    Marks INT
);

INSERT INTO Student
VALUES (101, 'Sanjay', 'BCA', 85);

INSERT INTO Student
VALUES (102, 'Ravi', 'BCA', 90);

INSERT INTO Student
VALUES (103, 'Kiran', 'BCA', 78);

SELECT * FROM Student;

ALTER TABLE Student
ADD City VARCHAR(30);

UPDATE Student
SET City = 'Mysuru'
WHERE StudentID = 101;

DELETE FROM Student
WHERE StudentID = 103;

SELECT * FROM Student;

Sample Output

StudentID  Name    Course  Marks
101        Sanjay  BCA     85
102        Ravi    BCA     90
103        Kiran   BCA     78

After DELETE:

StudentID  Name    Course  Marks
101        Sanjay  BCA     85
102        Ravi    BCA     90

Result

Thus, a Student table was created and DDL and DML operations were performed successfully.

Activity 2: Employee Database – SELECT and Arithmetic Operations

Aim

To create an Employee database and perform selection, arithmetic and sorting operations.

SQL Program

CREATE TABLE Employee (
    EmpID INT PRIMARY KEY,
    EmpName VARCHAR(50),
    Department VARCHAR(30),
    Salary DECIMAL(10,2)
);

INSERT INTO Employee VALUES
(1, 'Arun', 'IT', 25000);

INSERT INTO Employee VALUES
(2, 'Bharath', 'HR', 30000);

INSERT INTO Employee VALUES
(3, 'Charan', 'Sales', 22000);

INSERT INTO Employee VALUES
(4, 'Deepa', 'IT', 35000);

-- Display all employees
SELECT * FROM Employee;

-- Employees with salary above 25000
SELECT * FROM Employee
WHERE Salary > 25000;

-- Calculate annual salary
SELECT EmpName, Salary,
Salary * 12 AS AnnualSalary
FROM Employee;

-- Calculate salary after 10% increment
SELECT EmpName, Salary,
Salary * 1.10 AS IncreasedSalary
FROM Employee;

-- Sort salary in descending order
SELECT * FROM Employee
ORDER BY Salary DESC;

Sample Output

EmpName    Salary    AnnualSalary
Arun       25000     300000
Bharath    30000     360000
Charan     22000     264000
Deepa      35000     420000

Salary Slip Query

SELECT
EmpName,
Salary AS BasicSalary,
Salary * 0.10 AS Allowance,
Salary * 0.05 AS OtherAllowance,
Salary * 1.15 AS TotalSalary
FROM Employee;

Result

Thus, employee records were retrieved, calculated and sorted using SQL queries.

Activity 3: Library Database – Logical and Relational Operators

Aim

To create Books and Issued tables and perform queries using logical and relational operators.

SQL Program

CREATE TABLE Books (
    BookID INT PRIMARY KEY,
    BookName VARCHAR(60),
    Author VARCHAR(50),
    Price DECIMAL(8,2),
    Category VARCHAR(30)
);

INSERT INTO Books VALUES
(1, 'DBMS', 'Navathe', 450, 'Computer');

INSERT INTO Books VALUES
(2, 'C Programming', 'Balagurusamy', 350, 'Computer');

INSERT INTO Books VALUES
(3, 'English', 'Ravi', 200, 'Language');

INSERT INTO Books VALUES
(4, 'Java', 'Herbert', 500, 'Computer');

CREATE TABLE Issued (
    IssueID INT PRIMARY KEY,
    BookID INT,
    StudentName VARCHAR(50),
    IssueDate DATE,
    FOREIGN KEY (BookID) REFERENCES Books(BookID)
);

INSERT INTO Issued VALUES
(101, 1, 'Sanjay', '2026-01-10');

INSERT INTO Issued VALUES
(102, 2, 'Ravi', '2026-01-12');

SELECT * FROM Books;

-- AND operator
SELECT * FROM Books
WHERE Category = 'Computer'
AND Price > 400;

-- OR operator
SELECT * FROM Books
WHERE Category = 'Language'
OR Price > 400;

-- NOT operator
SELECT * FROM Books
WHERE NOT Category = 'Computer';

-- BETWEEN operator
SELECT * FROM Books
WHERE Price BETWEEN 200 AND 450;

-- IN operator
SELECT * FROM Books
WHERE Category IN ('Computer', 'Language');

-- LIKE operator
SELECT * FROM Books
WHERE BookName LIKE 'C%';

-- Greater than operator
SELECT * FROM Books
WHERE Price > 300;

-- Display issued books
SELECT * FROM Issued;

Sample Output

BookID  BookName       Price
1       DBMS           450
2       C Programming  350
3       English        200
4       Java           500

Computer books costing above 400:

1  DBMS  450
4  Java  500

Result

Thus, logical and relational operators were used to retrieve library records.

Activity 4: Equipment Database – Date Functions

Aim

To create an Equipment table and perform date calculations and date-related operations.

SQL Program

CREATE TABLE Equipment (
    EquipmentID INT PRIMARY KEY,
    EquipmentName VARCHAR(50),
    PurchaseDate DATE,
    WarrantyYears INT
);

INSERT INTO Equipment VALUES
(1, 'Computer', '2025-01-10', 3);

INSERT INTO Equipment VALUES
(2, 'Printer', '2024-06-15', 2);

INSERT INTO Equipment VALUES
(3, 'Projector', '2025-03-20', 5);

-- Display equipment
SELECT * FROM Equipment;

-- Extract year from purchase date
SELECT EquipmentName,
EXTRACT(YEAR FROM PurchaseDate) AS PurchaseYear
FROM Equipment;

-- Display current date
SELECT CURRENT_DATE;

-- Calculate warranty end date
SELECT EquipmentName,
PurchaseDate,
WarrantyYears,
PurchaseDate + INTERVAL '3' YEAR
AS WarrantyEnd
FROM Equipment;

Sample Output

EquipmentName  PurchaseDate  WarrantyYears
Computer       2025-01-10    3
Printer        2024-06-15    2
Projector      2025-03-20    5
Date functions and interval syntax differ between database systems. The warranty-end query above uses SQL interval syntax; adapt it to the database used in your lab.

Result

Thus, date values were stored, retrieved and used in date calculations.

Activity 6: Subject Database – Set Operations

Aim

To perform set operations such as UNION, UNION ALL, INTERSECT and MINUS.

SQL Program

CREATE TABLE SubjectA (
    StudentID INT,
    StudentName VARCHAR(50)
);

CREATE TABLE SubjectB (
    StudentID INT,
    StudentName VARCHAR(50)
);

INSERT INTO SubjectA VALUES
(1, 'Sanjay');

INSERT INTO SubjectA VALUES
(2, 'Ravi');

INSERT INTO SubjectA VALUES
(3, 'Kiran');

INSERT INTO SubjectB VALUES
(2, 'Ravi');

INSERT INTO SubjectB VALUES
(3, 'Kiran');

INSERT INTO SubjectB VALUES
(4, 'Arun');

-- UNION
SELECT * FROM SubjectA
UNION
SELECT * FROM SubjectB;

-- UNION ALL
SELECT * FROM SubjectA
UNION ALL
SELECT * FROM SubjectB;

-- INTERSECT
SELECT * FROM SubjectA
INTERSECT
SELECT * FROM SubjectB;

-- MINUS (Oracle)
SELECT * FROM SubjectA
MINUS
SELECT * FROM SubjectB;

Sample Output – UNION

1  Sanjay
2  Ravi
3  Kiran
4  Arun

Sample Output – INTERSECT

2  Ravi
3  Kiran

Sample Output – MINUS

1  Sanjay

Renaming a Table

ALTER TABLE SubjectA
RENAME TO SubjectDetails;
UNION, UNION ALL and INTERSECT are widely supported. Oracle uses MINUS, while PostgreSQL and some other systems use EXCEPT for set difference.

Result

Thus, set operations were performed to combine and compare records from two tables.

Activity 7: Railway Reservation Database – Views

Aim

To create and manage views in a Railway Reservation database.

SQL Program

CREATE TABLE Passenger (
    PassengerID INT PRIMARY KEY,
    PassengerName VARCHAR(50),
    TrainName VARCHAR(50),
    Fare DECIMAL(8,2)
);

INSERT INTO Passenger VALUES
(1, 'Sanjay', 'Mysuru Express', 250);

INSERT INTO Passenger VALUES
(2, 'Ravi', 'Bengaluru Express', 350);

INSERT INTO Passenger VALUES
(3, 'Kiran', 'Chennai Express', 450);

-- Create a view
CREATE VIEW PassengerView AS
SELECT PassengerID, PassengerName, TrainName
FROM Passenger;

-- Display view
SELECT * FROM PassengerView;

-- Create another view
CREATE VIEW HighFarePassengers AS
SELECT * FROM Passenger
WHERE Fare > 300;

-- Display second view
SELECT * FROM HighFarePassengers;

-- Update record through view
UPDATE PassengerView
SET PassengerName = 'Sanjay Kumar'
WHERE PassengerID = 1;

-- Display updated records
SELECT * FROM PassengerView;

-- Drop a view
DROP VIEW HighFarePassengers;

Sample Output

PassengerID  PassengerName  TrainName
1            Sanjay         Mysuru Express
2            Ravi           Bengaluru Express
3            Kiran          Chennai Express
Updating a view is possible only when the view is updatable. Complex views containing joins, grouping or aggregate functions may not allow direct updates.

Result

Thus, views were created, displayed, updated and deleted successfully.

Activity 8: Bank Database – GROUP BY and HAVING

Aim

To create a Bank database and perform aggregate functions, GROUP BY and HAVING operations.

SQL Program

CREATE TABLE Branch (
    BranchID INT PRIMARY KEY,
    BranchName VARCHAR(50),
    City VARCHAR(50)
);

CREATE TABLE Account (
    AccountNo INT PRIMARY KEY,
    CustomerName VARCHAR(50),
    BranchID INT,
    Balance DECIMAL(12,2),
    FOREIGN KEY (BranchID) REFERENCES Branch(BranchID)
);

INSERT INTO Branch VALUES
(1, 'Main Branch', 'Mysuru');

INSERT INTO Branch VALUES
(2, 'City Branch', 'Bengaluru');

INSERT INTO Branch VALUES
(3, 'Market Branch', 'Mandya');

INSERT INTO Account VALUES
(101, 'Sanjay', 1, 25000);

INSERT INTO Account VALUES
(102, 'Ravi', 1, 30000);

INSERT INTO Account VALUES
(103, 'Kiran', 2, 45000);

INSERT INTO Account VALUES
(104, 'Arun', 2, 20000);

INSERT INTO Account VALUES
(105, 'Deepa', 3, 50000);

-- Display all accounts
SELECT * FROM Account;

-- COUNT
SELECT COUNT(*) AS TotalAccounts
FROM Account;

-- SUM
SELECT SUM(Balance) AS TotalBalance
FROM Account;

-- AVG
SELECT AVG(Balance) AS AverageBalance
FROM Account;

-- MAX
SELECT MAX(Balance) AS HighestBalance
FROM Account;

-- MIN
SELECT MIN(Balance) AS LowestBalance
FROM Account;

-- GROUP BY
SELECT BranchID,
COUNT(*) AS TotalAccounts
FROM Account
GROUP BY BranchID;

-- HAVING
SELECT BranchID,
SUM(Balance) AS TotalBalance
FROM Account
GROUP BY BranchID
HAVING SUM(Balance) > 50000;

-- ORDER BY
SELECT * FROM Account
ORDER BY Balance DESC;

-- UPDATE
UPDATE Account
SET Balance = 35000
WHERE AccountNo = 101;

-- DELETE
DELETE FROM Account
WHERE AccountNo = 105;

Sample Output – GROUP BY

BranchID  TotalAccounts
1         2
2         2
3         1

Sample Output – Aggregate Functions

TotalAccounts   5
TotalBalance    170000
AverageBalance  34000
HighestBalance  50000
LowestBalance   20000

Result

Thus, aggregate functions, GROUP BY, HAVING, ORDER BY, UPDATE and DELETE operations were performed successfully on the Bank database.
