1. Introduction to Computer Networks

Meaning of Computer Network

A computer network is a collection of two or more computers and devices connected together to share information, resources and services.

Advantages of Computer Networks

  • Sharing files and information.
  • Sharing hardware such as printers.
  • Fast communication between users.
  • Centralized data management.
  • Internet and resource sharing.
  • Reduced communication cost.

Characteristics of Data Communication

  • Delivery: Data must reach the correct destination.
  • Accuracy: Data should arrive without errors.
  • Timeliness: Data must reach within the required time.
  • Jitter: Variation in the arrival time of packets.

Components of Data Communication

  1. Message: Information being transmitted.
  2. Sender: Device that sends information.
  3. Receiver: Device that receives information.
  4. Transmission Medium: Path through which data travels.
  5. Protocol: Rules governing communication.

Network Topologies

Topology is the physical or logical arrangement of devices in a network.

Mesh Topology

In mesh topology, devices are connected through multiple dedicated links. It provides high reliability but requires more cables.

A -------- B |\ /| | \ / | | \ / | | \ / | D -------- C

Star Topology

All computers are connected to a central hub or switch. If one cable fails, other computers can continue working. Failure of the central device affects the network.

PC1 | PC2 -- SWITCH -- PC3 | PC4

Bus Topology

All devices share a single main communication cable called the backbone. It is simple but failure of the backbone can stop the network.

PC1 ---- PC2 ---- PC3 ---- PC4

Ring Topology

Each device is connected to two neighbouring devices, forming a closed loop.

PC1 ------ PC2 | | PC4 ------ PC3

Tree Topology

Tree topology has a hierarchical structure that combines multiple star networks.

Hybrid Topology

Hybrid topology combines two or more different network topologies.

Categories of Networks

  • LAN: Local Area Network covers a small area such as a home, office or college.
  • MAN: Metropolitan Area Network covers a city or large campus.
  • WAN: Wide Area Network covers large geographical areas. The Internet is an example.

Digital-to-Analog Conversion

Digital-to-analog conversion changes digital data into analog signals for transmission over suitable communication channels.

  • ASK – Amplitude Shift Keying: Changes the amplitude of the carrier signal to represent digital data.
  • FSK – Frequency Shift Keying: Changes the frequency of the carrier signal.
  • PSK – Phase Shift Keying: Changes the phase of the carrier signal.

2. Analog Conversion and Physical Layer

Analog-to-Analog Conversion

Analog-to-analog conversion changes an analog signal into another analog signal suitable for transmission.

  • Amplitude Modulation (AM): Carrier amplitude changes according to the message signal.
  • Frequency Modulation (FM): Carrier frequency changes according to the message signal.
  • Phase Modulation (PM): Carrier phase changes according to the message signal.

Physical Layer

The physical layer is the lowest layer of the OSI model. It transmits raw bits over a communication medium.

Transmission Media

Transmission media are the paths through which data travels from sender to receiver.

Twisted Pair Cable

It consists of two insulated copper wires twisted together to reduce electromagnetic interference. It is commonly used in telephone and Ethernet networks.

  • UTP – Unshielded Twisted Pair
  • STP – Shielded Twisted Pair

Coaxial Cable

It contains a central copper conductor, insulation, metallic shielding and an outer protective cover. It is used in cable television and communication systems.

Optical Fiber

Optical fiber carries data as light signals through thin glass or plastic fibers. It supports high bandwidth and long-distance communication.

Wireless Transmission Media

  • Radio Waves: Used in radio broadcasting and wireless communication.
  • Microwaves: Used in satellite and point-to-point communication.
  • Infrared: Used for short-range communication, such as remote controls.

Switching

Switching is the process of transferring data from a source to a destination through network nodes.

Message Switching: The complete message is stored at an intermediate node and then forwarded to the next node.

Multiplexing

Multiplexing combines multiple signals and sends them through a shared communication channel.

  • FDM: Frequency Division Multiplexing divides the channel into frequency bands.
  • TDM: Time Division Multiplexing assigns different time slots to signals.
  • WDM: Wavelength Division Multiplexing carries multiple light wavelengths through optical fiber.

3. Data Link Layer and Network Layer

Data Link Layer

The data link layer provides node-to-node data delivery. It organizes bits into frames and detects transmission errors.

Data Link Layer Design Issues

  • Providing services to the network layer.
  • Framing the data.
  • Error control.
  • Flow control.
  • Managing access to a shared medium.

Error Detection

Error detection techniques help identify errors introduced during data transmission.

Single Parity Checking

A parity bit is added to data so that the total number of 1s becomes even or odd, according to the selected parity method.

Even parity example: Data = 1011 Number of 1s = 3 Parity bit = 1 Transmitted data = 10111

Checksum

Checksum is an error-detection method in which data units are added together and a complement of the sum is transmitted. The receiver checks the result.

Polynomial Codes – CRC

Cyclic Redundancy Check (CRC) uses binary polynomial division to calculate a remainder. The remainder is appended to the data before transmission.

Error Correction – Hamming Code

Hamming code adds redundant bits at specific positions to detect and correct certain transmission errors.

For m data bits and r parity bits: 2r ≥ m + r + 1

Elementary Data Link Protocols

  • Unrestricted Simplex Protocol: Assumes an ideal communication channel.
  • Simplex Stop-and-Wait: Sender waits for acknowledgement before sending the next frame.
  • Noisy Channel Protocol: Uses acknowledgements and retransmission to handle errors.

Sliding Window Protocols

Sliding window protocols allow multiple frames to be sent before acknowledgements are received.

  • Go-Back-N: Retransmits the frame with an error and subsequent frames.
  • Selective Repeat: Retransmits only the specific lost or damaged frames.

Network Layer

The network layer handles logical addressing, packet forwarding and routing between different networks.

Network Layer Design Issues

  • Logical addressing.
  • Routing and forwarding.
  • Internetworking.
  • Congestion control.
  • Packet fragmentation where required.

Routing Algorithms

Routing algorithms select paths through a network to deliver packets to their destinations.

Dijkstra's Shortest Path Algorithm

Dijkstra's algorithm finds the shortest path from a starting node to other nodes in a graph with non-negative edge weights.

  1. Set the source distance to zero.
  2. Set all other distances to infinity.
  3. Select the unvisited node with the smallest distance.
  4. Update the distances of its neighbouring nodes.
  5. Repeat until all reachable nodes are processed.

Flooding

In flooding, a router forwards an incoming packet through all outgoing links except the one on which it arrived, subject to controls such as hop count.

Distance Vector Routing

Each router shares routing information with its neighbouring routers and updates its routing table using distance information.

Hierarchical Routing

The network is divided into regions or areas. Routers maintain detailed routes within their area and summarized routes for other areas.

Link State Routing

Each router builds a map of network connectivity by sharing link-state information and calculates shortest paths.

Congestion Control

Congestion occurs when too much data enters a network, causing delays and packet loss.

  • Leaky Bucket Algorithm: Sends packets at a controlled, fixed rate.
  • Token Bucket Algorithm: Uses tokens to regulate traffic while allowing controlled bursts.
  • Admission Control: Decides whether a new traffic flow can be accepted.
  • Hop-by-Hop Choke Packets: Sends congestion notifications to upstream routers to reduce traffic.

4. Transport Layer and Application Layer

Transport Layer

The transport layer provides process-to-process communication between applications running on different computers.

Elements of Transport Service

  • Service-point addressing through port numbers.
  • Segmentation and reassembly.
  • Connection establishment and release.
  • Flow control and error control.
  • Reliable data transfer when required.

TCP – Transmission Control Protocol

TCP is a connection-oriented and reliable transport protocol. It uses acknowledgements, sequence numbers and retransmissions to support reliable delivery.

  • Connection-oriented.
  • Reliable and ordered delivery.
  • Flow and congestion control.
  • Used by applications such as web browsing and file transfer.

UDP – User Datagram Protocol

UDP is a connectionless transport protocol. It provides faster, low-overhead communication but does not guarantee delivery or ordering.

  • Connectionless.
  • Low overhead.
  • No built-in retransmission or ordering guarantee.
  • Used in real-time applications, streaming and DNS queries.

Application Layer

The application layer provides network services directly to user applications.

DNS – Domain Name System

DNS converts human-readable domain names into IP addresses. For example, it helps a browser find the server associated with a website name.

Electronic Mail

Electronic mail is a system used to send and receive digital messages over networks.

SMTP – Simple Mail Transfer Protocol

SMTP is used to send email from a client to a mail server and between mail servers.

POP3 – Post Office Protocol Version 3

POP3 is used by an email client to retrieve messages from a mail server, often downloading them to the local device.

SNMP – Simple Network Management Protocol

SNMP is used to monitor and manage network devices such as routers, switches and servers.

FTP – File Transfer Protocol

FTP is used to transfer files between a client and a server over a network.

TELNET

Telnet provides remote text-based access to another computer. It does not encrypt communication, so SSH is preferred for secure remote access.

World Wide Web (WWW)

The World Wide Web is a collection of linked web pages and resources accessed through the Internet using web browsers and web protocols.

Important: The Internet is the global network infrastructure. The World Wide Web is a service that operates over the Internet.
