Unit 1 – Introduction to Data Mining

1. Introduction to Data Science

Data Science is an interdisciplinary field that uses scientific methods, statistics, programming and analytical techniques to extract useful information from data.

Definition of Data

Data means raw facts and figures collected from different sources. Data can be numbers, text, images, videos or other information.

What is Data Mining?

Data Mining is the process of discovering useful patterns, relationships and knowledge from large amounts of data.

Examples

  • Online shopping websites recommending products.
  • Banks identifying suspicious transactions.
  • Hospitals analysing patient information.
  • Social media platforms suggesting content.
  • Supermarkets studying customer purchasing habits.

Advantages of Data Mining

  • Helps in better decision-making.
  • Identifies hidden patterns.
  • Improves business performance.
  • Helps predict future trends.
  • Finds unusual activities and possible fraud.

2. Knowledge Discovery in Databases (KDD)

KDD stands for Knowledge Discovery in Databases. It is the complete process of finding useful knowledge from large datasets.

Steps in KDD

  1. Data Cleaning: Removes incorrect, duplicate and incomplete data.
  2. Data Integration: Combines data from different sources.
  3. Data Selection: Selects relevant data for analysis.
  4. Data Transformation: Converts data into a suitable format.
  5. Data Mining: Applies algorithms to discover patterns.
  6. Pattern Evaluation: Identifies useful and meaningful patterns.
  7. Knowledge Presentation: Displays discovered knowledge using reports and visualizations.

KDD Process Example

Customer Data → Cleaning → Integration → Selection → Transformation → Data Mining → Pattern Evaluation → Knowledge

Difference Between KDD and Data Mining

KDDData Mining
Complete knowledge discovery process.One step of the KDD process.
Includes cleaning, selection and evaluation.Finds patterns using algorithms.
Broader process.Part of KDD.

3. Types of Data That Can Be Mined

Different types of data can be analysed using data mining techniques.

  • Relational Database: Data stored in tables with rows and columns.
  • Data Warehouse: Integrated data collected from multiple sources.
  • Transactional Data: Data related to purchases and transactions.
  • Time-Series Data: Data collected over time, such as daily temperatures.
  • Spatial Data: Geographical and location-related data.
  • Text Data: Emails, documents and social media posts.
  • Multimedia Data: Images, audio and videos.
  • Web Data: Website clicks, browsing history and online activity.

4. Data Mining Functionalities

Data mining functionalities describe the different types of knowledge that can be discovered from data.

1. Concept Description

Summarizes and describes the general characteristics of data.

2. Association Analysis

Finds relationships between items that frequently occur together.

Example: Customers who purchase bread may also purchase butter.

3. Classification

Places data into predefined categories.

Example: Classifying emails as spam or not spam.

4. Prediction

Uses existing data to estimate future values.

Example: Predicting next month's sales.

5. Clustering

Groups similar data objects without predefined labels.

Example: Grouping customers according to shopping behaviour.

6. Outlier Analysis

Identifies data objects that are significantly different from normal data.

Example: Detecting unusual bank transactions.

7. Evolution Analysis

Studies changes and trends in data over time.

5. Data Mining Techniques

  • Classification
  • Clustering
  • Association Rule Mining
  • Prediction
  • Regression
  • Outlier Detection
  • Sequential Pattern Mining
  • Summarization

Problems, Issues and Challenges

  • Data Quality: Incomplete or incorrect information.
  • Privacy: Protecting personal and confidential data.
  • Scalability: Processing very large datasets.
  • Data Integration: Combining data from different formats.
  • Security: Preventing unauthorized access.
  • Complexity: Selecting suitable algorithms.

Unit 2 – Data Warehouse and Frequent Pattern Mining

7. Data Warehouse

A Data Warehouse is a central storage system that collects and stores integrated historical data from different sources for analysis and decision-making.

Characteristics

  • Subject-Oriented: Organized around subjects such as sales or customers.
  • Integrated: Combines data from different sources.
  • Time-Variant: Stores historical data over time.
  • Non-Volatile: Data is mainly used for reading and analysis rather than frequent modification.

Advantages

  • Provides centralized data storage.
  • Supports business decisions.
  • Helps analyse historical information.
  • Improves reporting and analysis.

8. Three-Tier Data Warehouse Architecture

Three-tier architecture divides a data warehouse system into three layers.

1. Bottom Tier

Contains databases and data sources. Data is collected, cleaned and loaded into the warehouse.

2. Middle Tier

Contains the OLAP server, which processes analytical queries.

3. Top Tier

Contains front-end tools used for reporting, querying and data analysis.

Top Tier: Reports and Analysis Tools
↓
Middle Tier: OLAP Server
↓
Bottom Tier: Data Warehouse and Data Sources

9. Multidimensional Data Model

A multidimensional data model represents data using multiple dimensions for easy analysis.

Important Terms

  • Fact Table: Stores measurable business information such as sales amount.
  • Dimension Table: Stores descriptive information such as time, product and location.
  • Measures: Numerical values used for analysis.
  • Dimensions: Different perspectives used to analyse data.

Example

A sales data warehouse can analyse sales according to product, location and time.

DimensionExample
ProductMobile, Laptop
LocationMysuru, Bengaluru
TimeJanuary, February
MeasureTotal Sales

10. Schemas for Multidimensional Data Models

1. Star Schema

A central fact table is connected directly to multiple dimension tables. It has a star-like structure.

Advantage: Simple design and faster queries in many analytical situations.

2. Snowflake Schema

Dimension tables are divided into additional related tables. Its structure looks like a snowflake.

Advantage: Reduces repeated dimension data through normalization.

3. Fact Constellation Schema

Contains multiple fact tables that share dimension tables.

Advantage: Supports analysis of multiple related business processes.

Star SchemaSnowflake Schema
Simple structure.More complex structure.
Dimension tables are usually denormalized.Dimension tables are normalized.
Fewer joins are generally needed.More joins may be needed.

11. OLAP Operations

OLAP stands for Online Analytical Processing. It is used to analyse multidimensional data.

1. Roll-Up

Summarizes data by moving from detailed information to a higher level.

Example: Daily sales to monthly sales.

2. Drill-Down

Moves from summarized information to detailed information.

Example: Yearly sales to monthly sales.

3. Slice

Selects one particular value of a dimension.

Example: Viewing sales for the year 2026 only.

4. Dice

Selects a smaller portion of data using multiple dimension values.

5. Pivot

Rotates the data view to analyse information from a different perspective.

12. Data Preprocessing

Data preprocessing is the process of preparing raw data before applying data mining techniques.

1. Data Cleaning

Removes errors, duplicates and inconsistencies from data.

  • Handling missing values.
  • Removing duplicate records.
  • Handling noisy data.
  • Correcting inconsistent values.

Handling Missing Values

  • Ignore the incomplete record when appropriate.
  • Fill using a constant value.
  • Fill using mean, median or mode.
  • Estimate the value using a suitable model.

Handling Noisy Data

Noisy data contains random errors or unusual variations.

Methods include binning, regression and clustering-based methods.

13. Data Integration

Data integration combines information from multiple data sources into a single consistent dataset.

Challenges

  • Different data formats.
  • Duplicate records.
  • Different naming conventions.
  • Conflicting values.
  • Data redundancy.

Example

A college may combine student information from admission records, examination records and attendance systems.

14. Data Reduction

Data reduction reduces the size of data while maintaining important information needed for analysis.

Strategies

  • Data Cube Aggregation: Summarizes detailed data.
  • Dimensionality Reduction: Reduces the number of attributes.
  • Numerosity Reduction: Represents data using a smaller model.
  • Data Compression: Stores information in a compact form.
  • Discretization: Converts continuous values into intervals.

15. Data Transformation and Normalization

Data transformation converts data into a suitable format for mining and analysis.

Common Methods

  • Smoothing
  • Aggregation
  • Generalization
  • Normalization
  • Attribute construction

Min-Max Normalization

Converts values into a specified range.

New Value = (X - Minimum) / (Maximum - Minimum)

For a range from 0 to 1:

X = 50, Minimum = 0, Maximum = 100
Normalized Value = (50 - 0) / (100 - 0) = 0.5

Z-Score Normalization

Transforms data based on its mean and standard deviation.

Z = (X - Mean) / Standard Deviation

16. Frequent Pattern Mining

Frequent pattern mining identifies items, sequences or structures that occur frequently in a dataset.

Important Terms

  • Item: A single object, such as bread.
  • Itemset: A collection of one or more items.
  • Support: Frequency of an itemset in the transaction database.
  • Confidence: Strength of an association rule.
  • Frequent Itemset: An itemset whose support is greater than or equal to minimum support.
  • Maximal Frequent Itemset: A frequent itemset that has no frequent superset.
  • Closed Frequent Itemset: A frequent itemset with no superset having the same support.

Support Formula

Support(A) = Transactions containing A / Total Transactions

Confidence Formula

Confidence(A → B) = Support(A ∪ B) / Support(A)

17. Association Rule Mining

Association rule mining discovers relationships between items in large datasets.

Example: Customers who buy bread may also buy butter.

Bread → Butter

Applications

  • Market basket analysis.
  • Product recommendations.
  • Shopping behaviour analysis.
  • Website usage analysis.

18. Apriori Algorithm

The Apriori algorithm is used to discover frequent itemsets and association rules in transactional databases.

Apriori Principle

If an itemset is frequent, all its non-empty subsets must also be frequent. If an itemset is infrequent, its supersets cannot be frequent.

Steps

  1. Find frequent one-itemsets.
  2. Generate candidate two-itemsets.
  3. Calculate their support.
  4. Remove itemsets below minimum support.
  5. Generate larger candidate itemsets.
  6. Repeat until no more frequent itemsets are found.
  7. Generate association rules using confidence.

Example

Consider these transactions:

TransactionItems
T1Bread, Milk
T2Bread, Butter
T3Bread, Milk, Butter
T4Milk, Butter

If minimum support is 50%, the item Bread occurs in 3 out of 4 transactions.

Support(Bread) = 3/4 × 100 = 75%

Therefore, Bread is a frequent item.

Advantages

  • Easy to understand and implement.
  • Useful for market basket analysis.

Disadvantages

  • Generates many candidate itemsets.
  • Requires repeated database scans.
  • Can be slow for large datasets.

19. FP-Growth Algorithm

FP-Growth stands for Frequent Pattern Growth. It finds frequent itemsets without generating large candidate sets like Apriori.

Steps

  1. Scan the database and calculate item frequencies.
  2. Remove items below minimum support.
  3. Sort frequent items by descending support.
  4. Build an FP-Tree.
  5. Generate conditional pattern bases.
  6. Construct conditional FP-Trees.
  7. Discover frequent patterns.

Advantages

  • Avoids candidate generation.
  • Often faster than Apriori.
  • Uses a compact tree structure.

Difference Between Apriori and FP-Growth

AprioriFP-Growth
Generates candidate itemsets.Does not generate candidates in the same way.
Uses repeated database scans.Uses an FP-Tree structure.
May be slower for large datasets.Often more efficient for large datasets.

20. Vertical Data Format in Frequent Itemset Mining

In vertical data format, each item is stored with the list of transaction IDs in which it appears.

Example

MilkT1, T3, T4

To find the support of Bread and Milk together, intersect their transaction ID lists.

Bread = {T1, T2, T3}

Unit 3 – Classification and Prediction

21. Classification

Classification is a supervised learning technique that assigns data objects to predefined classes or categories.

Example

An email system classifies messages into:

  • Spam
  • Not Spam

Steps in Classification

  1. Collect training data.
  2. Prepare and clean the data.
  3. Build a classification model.
  4. Test the model using test data.
  5. Classify new records.

Applications

  • Spam detection.
  • Medical diagnosis.
  • Credit approval.
  • Fraud detection.

22. Decision Tree Induction

A decision tree is a tree-shaped model used for classification and prediction.

Main Components

  • Root Node: Starting point of the tree.
  • Internal Node: Represents a test on an attribute.
  • Branch: Represents the outcome of a test.
  • Leaf Node: Represents the final class or decision.

Example

Attribute Selection Measures

Attribute selection measures help choose the best attribute for splitting data.

  • Information Gain
  • Gain Ratio
  • Gini Index

Advantages

  • Easy to understand.
  • Simple to visualize.
  • Can handle different types of data.

Disadvantages

  • May overfit training data.
  • Small data changes may produce a different tree.

23. Bayes Classification Method

Bayesian classification is a statistical classification method based on Bayes' theorem.

Bayes' Theorem

P(A|B) = [P(B|A) × P(A)] / P(B)

Where:

  • P(A|B) = Probability of A given B.
  • P(B|A) = Probability of B given A.
  • P(A) = Prior probability of A.
  • P(B) = Probability of B.

Naive Bayes Classifier

Naive Bayes assumes that features are conditionally independent given the class.

Applications

  • Email spam filtering.
  • Text classification.
  • Sentiment analysis.
  • Medical prediction.

Advantages

  • Simple and fast.
  • Works well with many text classification tasks.
  • Requires relatively little training data.

24. Rule-Based Classification

Rule-based classification uses IF–THEN rules to assign data to classes.

Example

IF marks >= 35
THEN Result = Pass

IF marks < 35
THEN Result = Fail

Advantages

  • Easy to understand.
  • Rules can be interpreted by humans.
  • Useful for decision-making systems.

25. Lazy Learners and K-Nearest Neighbour

Lazy learners delay building a general model until a new record needs classification.

K-Nearest Neighbour (KNN)

KNN classifies a new data point based on the majority class among its K nearest neighbours.

Steps

  1. Choose the value of K.
  2. Calculate distances between the new point and training points.
  3. Find the K nearest points.
  4. Count the class labels of the neighbours.
  5. Assign the majority class.

Euclidean Distance Formula

d = √[(x2 - x1)² + (y2 - y1)²]

Advantages

  • Simple to understand.
  • No complex training phase.
  • Can be used for classification and regression.

Disadvantages

  • Can be slow on large datasets.
  • Choosing the correct K is important.
  • Can be affected by irrelevant features and different feature scales.

27. Confusion Matrix

A confusion matrix is a table used to evaluate the performance of a classification model.

Predicted PositivePredicted Negative
Actual PositiveTrue Positive (TP)False Negative (FN)
Actual NegativeFalse Positive (FP)True Negative (TN)
  • True Positive: Correctly predicted positive.
  • True Negative: Correctly predicted negative.
  • False Positive: Incorrectly predicted positive.
  • False Negative: Incorrectly predicted negative.

28. Accuracy, Precision and Recall

Accuracy

Measures the proportion of all predictions that are correct.

Accuracy = (TP + TN) / (TP + TN + FP + FN)

Precision

Measures how many predicted positive results are actually positive.

Precision = TP / (TP + FP)

Recall

Measures how many actual positive cases were correctly identified.

Recall = TP / (TP + FN)

Example

Suppose TP = 40, TN = 50, FP = 5 and FN = 5.

Accuracy = (40 + 50) / 100 = 90%
Precision = 40 / 45 = 88.89%
Recall = 40 / 45 = 88.89%

Unit 4 – Clustering

29. Clustering

Clustering is an unsupervised learning technique that groups similar data objects into clusters.

Example

A shopping company groups customers based on their purchasing behaviour.

Characteristics

  • Does not require predefined class labels.
  • Groups similar objects together.
  • Separates dissimilar objects.
  • Helps discover hidden structures.

Applications

  • Customer segmentation.
  • Image segmentation.
  • Document grouping.
  • Medical data analysis.
  • Social network analysis.

Classification vs Clustering

ClassificationClustering
Supervised learning.Unsupervised learning.
Uses labelled data.Uses unlabelled data.
Predicts predefined classes.Discovers groups in data.

30. Partitioning Methods

Partitioning methods divide a dataset into a fixed number of clusters.

1. K-Means Clustering

K-Means divides data into K clusters. Each cluster is represented by its centroid.

Steps

  1. Select the number of clusters K.
  2. Choose initial centroids.
  3. Assign each data point to its nearest centroid.
  4. Calculate new centroids.
  5. Repeat until assignments stop changing significantly.

Advantages

  • Simple and easy to implement.
  • Works well for many compact clusters.
  • Efficient for many datasets.

Disadvantages

  • K must be selected in advance.
  • Sensitive to initial centroids.
  • Can be affected by outliers.

2. K-Medoids

K-Medoids is a partitioning method where each cluster is represented by an actual data object called a medoid.

K-Means vs K-Medoids

K-MeansK-Medoids
Uses the mean as centroid.Uses an actual data point as medoid.
More sensitive to outliers.Generally more robust to outliers.
Often faster.Can be more computationally expensive.

31. Hierarchical Clustering

Hierarchical clustering creates a hierarchy of clusters. The results can be represented using a tree-like diagram called a dendrogram.

Types

1. Agglomerative Clustering

Bottom-up approach. Starts with each data point as an individual cluster and repeatedly merges the closest clusters.

2. Divisive Clustering

Top-down approach. Starts with all data points in one cluster and repeatedly divides them into smaller clusters.

Advantages

  • Produces a hierarchy of clusters.
  • Does not always require the number of clusters in advance.
  • Useful for exploring relationships.

Disadvantages

  • Can be computationally expensive.
  • Early merging or splitting decisions are difficult to reverse.

32. Probabilistic and Bayesian Methods

Probabilistic clustering uses probability distributions to represent data and estimate the likelihood that an object belongs to a cluster.

Bayesian Methods

Bayesian methods use probability and Bayes' theorem to estimate cluster membership and update beliefs when new data becomes available.

Uses

  • Handling uncertainty in data.
  • Modelling overlapping clusters.
  • Analysing complex datasets.

33. Density-Based Clustering

Density-based clustering forms clusters from areas containing many closely located data points and separates sparse areas as noise or outliers.

1. DBSCAN

DBSCAN stands for Density-Based Spatial Clustering of Applications with Noise.

Important Parameters

  • Epsilon (ε): Neighbourhood radius.
  • MinPts: Minimum number of points required to form a dense region.

Types of Points

  • Core Point: Has at least MinPts points within its neighbourhood.
  • Border Point: Lies within the neighbourhood of a core point but does not itself satisfy the core condition.
  • Noise Point: Does not belong to any cluster.

2. DENCLUE

DENCLUE stands for DENsity-based CLUstEring. It uses mathematical density functions to identify dense regions and clusters.

Advantages of Density-Based Methods

  • Can identify clusters with irregular shapes.
  • Can identify noise and outliers.
  • Does not always require the number of clusters in advance.

34. Grid-Based Clustering

Grid-based clustering divides the data space into a finite number of cells and performs clustering on those cells.

1. STING

STING stands for Statistical Information Grid. It uses statistical information stored in grid cells to perform clustering.

2. CLIQUE

CLIQUE stands for CLustering In QUEst. It is a grid-based and density-based method used for high-dimensional data.

Advantages

  • Can process large datasets efficiently.
  • Uses grid structures for analysis.
  • Useful for multidimensional datasets.

35. Dendrogram

A dendrogram is a tree-shaped diagram used to represent the merging or splitting of clusters in hierarchical clustering.

Uses

  • Shows relationships between clusters.
  • Helps select the number of clusters.
  • Displays the order in which clusters are combined.

36. Distance Measures in Clustering

Distance measures calculate how similar or different two data objects are.

1. Euclidean Distance

d = √Σ(xi - yi)²

Measures straight-line distance between two points.

2. Manhattan Distance

d = Σ|xi - yi|

Calculates distance by adding absolute differences across dimensions.

3. Minkowski Distance

d = (Σ|xi - yi|p)^(1/p)

A general distance measure that includes Euclidean and Manhattan distance as special cases.

37. Types of Linkage in Hierarchical Clustering

Linkage methods decide how the distance between two clusters is calculated.

1. Single Linkage

Uses the minimum distance between points in two clusters.

2. Complete Linkage

Uses the maximum distance between points in two clusters.

3. Average Linkage

Uses the average distance between points in two clusters.

4. Ward's Method

Merges clusters in a way that minimizes the increase in within-cluster variance.

38. Evaluation of Clustering

Clustering evaluation measures how well data objects have been grouped.

Important Measures

  • Silhouette Score: Measures how well an object fits within its cluster compared with other clusters.
  • Within-Cluster Sum of Squares: Measures how close data points are to their cluster centers.
  • Davies-Bouldin Index: Measures cluster similarity; lower values are generally better.
  • Dunn Index: Compares separation between clusters with their internal diameter; higher values are generally better.

Good Clustering Should Have

  • High similarity within the same cluster.
  • Low similarity between different clusters.
  • Well-separated clusters.
  • Meaningful groups.
