1. Introduction to Python

What is Python?

Python is a high-level, interpreted, general-purpose programming language. It was developed by Guido van Rossum and first released in 1991. Python is popular because its syntax is simple and easy to understand.

Features of Python

  • Easy to learn and use.
  • High-level programming language.
  • Interpreted language.
  • Supports object-oriented programming.
  • Portable across different operating systems.
  • Free and open-source.
  • Large collection of libraries.
  • Supports GUI and database programming.

Applications of Python

  • Web development
  • Artificial Intelligence and Machine Learning
  • Data Science and Data Analysis
  • Automation and scripting
  • Desktop applications
  • Scientific computing
  • Game development

Python Versions

Python 2 and Python 3 are major versions. Python 3 is the modern version used for current development. Python 2 is no longer officially supported.

Installing Python

  1. Visit the official Python website.
  2. Download the appropriate Python installer.
  3. Run the installer.
  4. Select the option to add Python to PATH when using Windows.
  5. Complete the installation.
  6. Open Command Prompt and type python --version to check installation.

Python Command Line Mode and IDE

Command Line Mode: Python statements are entered and executed directly in the Python interactive shell.

IDE: An Integrated Development Environment provides tools to write, edit, run and debug programs. Examples include IDLE, PyCharm and Visual Studio Code.

First Python Program

print("Hello, World!")

Output:

Hello, World!

2. Python Fundamentals

Identifiers

Identifiers are names given to variables, functions, classes and other objects in a Python program.

Rules:

  • An identifier can contain letters, digits and underscore.
  • It cannot start with a digit.
  • Spaces are not allowed.
  • Python keywords cannot be used as identifiers.
  • Identifiers are case-sensitive.

Keywords

Keywords are reserved words that have special meanings in Python.

Examples: if, else, elif, for, while, break, continue, def, class, return, try, except, True, False and None.

Variables

A variable is a named memory reference used to store data.

name = "Sanju"
age = 20
marks = 85.5

print(name)
print(age)
print(marks)

Statements and Expressions

Statement: An instruction executed by Python.

Expression: A combination of values, variables and operators that produces a result.

x = 10
y = 20
total = x + y
print(total)

Data Types

Data types specify the kind of value stored in a variable.

  • int – Integer values, such as 10.
  • float – Decimal values, such as 10.5.
  • complex – Complex numbers, such as 2+3j.
  • str – Text values, such as "Python".
  • bool – True or False.
  • list – Ordered and changeable collection.
  • tuple – Ordered and unchangeable collection.
  • set – Unordered collection of unique values.
  • dict – Key-value collection.

Checking Data Type

x = 25
print(type(x))

Output: <class 'int'>

Operators in Python

Operators are symbols used to perform operations on values and variables.

  • Arithmetic: +, -, *, /, //, %, **
  • Comparison: ==, !=, >, <, >=, <=
  • Assignment: =, +=, -=, *=, /=
  • Logical: and, or, not
  • Membership: in, not in
  • Identity: is, is not
  • Bitwise: &, |, ^, ~, <<, >>

Operator Precedence

Operator precedence determines which operation is performed first in an expression.

For example, multiplication is performed before addition.

result = 10 + 5 * 2
print(result)

Output: 20

Indentation

Indentation means spaces at the beginning of a line. Python uses indentation to identify blocks of code.

if 10 > 5:
    print("Ten is greater")

Comments

Comments are notes written in a program. Python does not execute comments.

# This is a single-line comment

print("Welcome")

Built-in Functions

Built-in functions are functions already available in Python.

  • print() – Displays output.
  • input() – Accepts user input.
  • len() – Returns length.
  • type() – Returns data type.
  • int() – Converts to integer.
  • float() – Converts to float.
  • str() – Converts to string.
  • range() – Generates a sequence of numbers.
  • max() – Returns the largest value.
  • min() – Returns the smallest value.

Input and Output

name = input("Enter your name: ")
print("Welcome", name)

Type Conversion

Type conversion means changing a value from one data type to another.

number = input("Enter a number: ")
number = int(number)

print(number + 10)

Python Libraries and Modules

A module is a Python file containing reusable code. A library is a collection of modules and related tools.

import math

print(math.sqrt(25))
print(math.factorial(5))

Output:

5.0
120

3. Conditional Statements and Loops

Conditional Statements

Conditional statements are used to execute different blocks of code depending on a condition.

if Statement

age = 20

if age >= 18:
    print("Eligible to vote")

if-else Statement

number = 7

if number % 2 == 0:
    print("Even")
else:
    print("Odd")

if-elif-else Statement

marks = 75

if marks >= 90:
    print("A Grade")
elif marks >= 60:
    print("B Grade")
elif marks >= 35:
    print("C Grade")
else:
    print("Fail")

Nested if Statement

A nested if is an if statement placed inside another if statement.

number = 15

if number > 0:
    if number % 2 == 0:
        print("Positive even number")
    else:
        print("Positive odd number")

match-case Statement

The match-case statement compares a value against different patterns. It is available in Python 3.10 and later.

day = 2

match day:
    case 1:
        print("Monday")
    case 2:
        print("Tuesday")
    case 3:
        print("Wednesday")
    case _:
        print("Other day")

Looping Statements

Loops are used to execute a block of code repeatedly.

for Loop

for i in range(1, 6):
    print(i)

Output: 1 2 3 4 5

while Loop

i = 1

while i <= 5:
    print(i)
    i += 1

Nested Loop

A loop inside another loop is called a nested loop.

for i in range(1, 4):
    for j in range(1, 3):
        print(i, j)

break Statement

The break statement immediately terminates a loop.

for i in range(1, 6):
    if i == 3:
        break
    print(i)

continue Statement

The continue statement skips the current iteration and moves to the next iteration.

for i in range(1, 6):
    if i == 3:
        continue
    print(i)

pass Statement

The pass statement does nothing. It is used as a placeholder where a statement is required.

for i in range(5):
    pass

4. Strings in Python

What is a String?

A string is a sequence of characters enclosed in single quotes, double quotes or triple quotes.

name = "Python"
print(name)

String Indexing

Each character in a string has an index. Positive indexing starts from zero, while negative indexing starts from -1.

word = "PYTHON"

print(word[0])
print(word[-1])

Output:

P
N

String Slicing

Slicing is used to access a part of a string.

word = "PYTHON"

print(word[0:3])
print(word[2:5])

String Operations

  • Concatenation – Joining strings using +.
  • Repetition – Repeating strings using *.
  • Membership – Checking using in and not in.
  • Slicing – Extracting a portion of a string.

Important String Methods

text = "hello python"

print(text.upper())
print(text.lower())
print(text.title())
print(text.capitalize())
print(text.replace("python", "world"))
print(text.find("python"))
print(text.count("o"))
print(text.split())
print(text.startswith("hello"))
print(text.endswith("python"))

String Immutability

Strings are immutable. This means that individual characters of an existing string cannot be changed directly. A new string must be created instead.

5. Lists, Tuples and Sets

Lists

A list is an ordered and changeable collection. It allows duplicate values and can store different data types.

numbers = [10, 20, 30, 40]

print(numbers)
print(numbers[0])

numbers.append(50)
numbers.remove(20)

print(numbers)

List Methods

  • append() – Adds an element at the end.
  • insert() – Adds an element at a specified position.
  • remove() – Removes a specified element.
  • pop() – Removes and returns an element.
  • sort() – Sorts the list.
  • reverse() – Reverses the list.
  • index() – Returns the position of an element.
  • count() – Counts occurrences of an element.
  • clear() – Removes all elements.

List Slicing

numbers = [10, 20, 30, 40, 50]

print(numbers[1:4])
print(numbers[:3])
print(numbers[::-1])

List Comprehension

List comprehension provides a short way to create a list.

squares = [x*x for x in range(1, 6)]
print(squares)

Output: [1, 4, 9, 16, 25]

Tuples

A tuple is an ordered and unchangeable collection. It allows duplicate values.

colors = ("red", "green", "blue")

print(colors)
print(colors[0])

Tuple Methods

  • count() – Counts occurrences of an element.
  • index() – Returns the position of an element.

Sets

A set is an unordered collection of unique elements. Duplicate values are automatically removed.

numbers = {10, 20, 20, 30}

print(numbers)

numbers.add(40)
numbers.remove(10)

print(numbers)

Set Operations

A = {1, 2, 3}
B = {3, 4, 5}

print(A.union(B))
print(A.intersection(B))
print(A.difference(B))

Difference Between List, Tuple and Set

  • List: Ordered, changeable and allows duplicates.
  • Tuple: Ordered, unchangeable and allows duplicates.
  • Set: Unordered, changeable and does not allow duplicates.

6. Dictionaries in Python

What is a Dictionary?

A dictionary is a collection of key-value pairs. Each key is unique and is used to access its corresponding value.

student = {
    "name": "Sanju",
    "age": 20,
    "course": "BCA"
}

print(student["name"])
print(student["course"])

Adding and Updating Elements

student = {"name": "Sanju", "age": 20}

student["marks"] = 85
student["age"] = 21

print(student)

Dictionary Methods

  • keys() – Returns all keys.
  • values() – Returns all values.
  • items() – Returns key-value pairs.
  • get() – Returns the value of a key.
  • update() – Updates dictionary elements.
  • pop() – Removes an item using its key.
  • clear() – Removes all items.

Traversing a Dictionary

student = {
    "name": "Sanju",
    "age": 20,
    "marks": 85
}

for key, value in student.items():
    print(key, ":", value)

Nested Dictionary

A dictionary containing another dictionary is called a nested dictionary.

students = {
    "student1": {
        "name": "Ravi",
        "marks": 80
    },
    "student2": {
        "name": "Asha",
        "marks": 90
    }
}

print(students["student1"]["name"])

7. Functions in Python

What is a Function?

A function is a reusable block of code designed to perform a specific task. Functions reduce repetition and make programs easier to understand.

Defining and Calling a Function

def greet():
    print("Welcome to Python")

greet()

Function with Parameters

def add(a, b):
    print("Sum =", a + b)

add(10, 20)

Function with Return Value

def square(number):
    return number * number

result = square(5)
print(result)

Types of Function Arguments

  • Positional arguments – Values are passed according to parameter position.
  • Keyword arguments – Values are passed using parameter names.
  • Default arguments – Parameters have default values.
  • Variable-length arguments – Functions accept a variable number of arguments using *args or **kwargs.

Default Argument Example

def greet(name="Student"):
    print("Hello", name)

greet()
greet("Sanju")

Variable-Length Arguments

def total(*numbers):
    print(sum(numbers))

total(10, 20, 30, 40)

Lambda Function

A lambda function is a small anonymous function written using the lambda keyword.

square = lambda x: x * x

print(square(5))

Recursion

Recursion is a process in which a function calls itself to solve a problem. A recursive function must have a stopping condition.

def factorial(n):
    if n == 0:
        return 1
    return n * factorial(n - 1)

print(factorial(5))

Output: 120

Scope of Variables

  • Local variable – Declared inside a function.
  • Global variable – Declared outside functions and accessible throughout the module.
x = 100

def display():
    y = 20
    print(x)
    print(y)

display()

9. Object-Oriented Programming in Python

What is OOP?

Object-Oriented Programming is a programming approach based on classes and objects. It helps organize programs and supports code reuse.

Class

A class is a blueprint or template used to create objects. It defines attributes and methods.

Object

An object is an instance of a class. It contains data and can use the methods defined by its class.

Class and Object Example

class Student:
    def display(self):
        print("Welcome Student")

s1 = Student()
s1.display()

Constructor

A constructor is a special method that is automatically called when an object is created. In Python, __init__() is commonly used as the constructor.

class Student:
    def __init__(self, name):
        self.name = name

    def display(self):
        print("Name:", self.name)

s1 = Student("Sanju")
s1.display()

self Keyword

The self parameter refers to the current object. It is used to access the attributes and methods of that object.

Inheritance

Inheritance allows one class to acquire the properties and methods of another class.

class Animal:
    def eat(self):
        print("Animal eats food")

class Dog(Animal):
    def bark(self):
        print("Dog barks")

d = Dog()
d.eat()
d.bark()

Types of Inheritance

  • Single inheritance – One child class inherits from one parent class.
  • Multiple inheritance – One child class inherits from multiple parent classes.
  • Multilevel inheritance – A class inherits from a child class in a chain.
  • Hierarchical inheritance – Multiple child classes inherit from one parent class.
  • Hybrid inheritance – Combination of different inheritance types.

Polymorphism

Polymorphism means one interface can be used with different forms of objects or behavior.

class Dog:
    def sound(self):
        print("Bark")

class Cat:
    def sound(self):
        print("Meow")

for animal in (Dog(), Cat()):
    animal.sound()

Method Overriding

Method overriding occurs when a child class provides its own implementation of a method already defined in its parent class.

class Parent:
    def show(self):
        print("Parent class")

class Child(Parent):
    def show(self):
        print("Child class")

obj = Child()
obj.show()

Encapsulation

Encapsulation means combining data and methods inside a class and controlling access to the data. Python uses naming conventions and name mangling for access control.

Abstraction

Abstraction means hiding implementation details and showing only essential features. Python supports abstraction using the abc module.

10. File Handling in Python

What is File Handling?

File handling is used to create, read, write and modify files using Python programs. It helps store information permanently.

Opening a File

The open() function is used to open a file.

file = open("sample.txt", "r")

File Opening Modes

  • r – Read mode.
  • w – Write mode; creates or overwrites a file.
  • a – Append mode; adds content at the end.
  • x – Creates a new file and fails if it already exists.
  • r+ – Read and write mode.
  • b – Binary mode modifier.
  • t – Text mode modifier.

Writing to a File

file = open("sample.txt", "w")
file.write("Welcome to Python")
file.close()

Reading from a File

file = open("sample.txt", "r")
data = file.read()
print(data)
file.close()

Appending to a File

file = open("sample.txt", "a")
file.write("\nLearning file handling")
file.close()

Using with Statement

The with statement automatically closes a file after the block is completed.

with open("sample.txt", "r") as file:
    data = file.read()
    print(data)

File Methods

  • read() – Reads the entire file or a specified number of characters.
  • readline() – Reads one line.
  • readlines() – Returns lines as a list.
  • write() – Writes text to a file.
  • writelines() – Writes a sequence of strings.
  • close() – Closes the file.

11. Exception Handling

What is an Exception?

An exception is an error that occurs while a program is running. Exception handling prevents a program from stopping unexpectedly.

Common Exceptions

  • ZeroDivisionError – Dividing by zero.
  • ValueError – Invalid value.
  • TypeError – Operation on an unsuitable data type.
  • IndexError – Accessing an invalid sequence index.
  • KeyError – Accessing a missing dictionary key.
  • FileNotFoundError – Requested file does not exist.

try and except

try:
    a = int(input("Enter first number: "))
    b = int(input("Enter second number: "))
    print(a / b)

except ZeroDivisionError:
    print("Cannot divide by zero")

except ValueError:
    print("Enter valid numbers")

else Block

The else block executes when no exception occurs in the try block.

try:
    number = int(input("Enter number: "))
except ValueError:
    print("Invalid input")
else:
    print("Number:", number)

finally Block

The finally block executes whether an exception occurs or not. It is commonly used for cleanup operations.

try:
    print("Try block")
finally:
    print("Finally block")

raise Keyword

The raise keyword is used to generate an exception manually.

age = 15

if age < 18:
    raise ValueError("Age must be 18 or above")

User-Defined Exceptions

Programmers can create their own exception classes by inheriting from the Exception class.

class InvalidAgeError(Exception):
    pass

age = 15

try:
    if age < 18:
        raise InvalidAgeError("Not eligible")
except InvalidAgeError as e:
    print(e)

12. GUI Programming Using Tkinter

What is GUI?

GUI stands for Graphical User Interface. It allows users to interact with applications through windows, buttons, text boxes and other graphical elements.

What is Tkinter?

Tkinter is Python's standard interface for creating graphical desktop applications using the Tk toolkit.

Creating a Simple Tkinter Window

import tkinter as tk

root = tk.Tk()
root.title("My First App")
root.geometry("300x200")

label = tk.Label(root, text="Welcome to Python")
label.pack()

root.mainloop()

Important Tkinter Widgets

  • Label – Displays text or images.
  • Button – Performs an action when clicked.
  • Entry – Accepts single-line input.
  • Text – Accepts multi-line text.
  • Checkbutton – Allows selection of options.
  • Radiobutton – Allows selection of one option from a group.
  • Listbox – Displays a list of items.
  • Frame – Groups other widgets.

Button Example

import tkinter as tk

def show_message():
    label.config(text="Button Clicked!")

root = tk.Tk()
root.title("Button Example")

label = tk.Label(root, text="Click the button")
label.pack()

button = tk.Button(root, text="Click Me",
                   command=show_message)
button.pack()

root.mainloop()

Geometry Managers

  • pack() – Arranges widgets in blocks.
  • grid() – Arranges widgets in rows and columns.
  • place() – Positions widgets using coordinates.

13. Database Connectivity Using Python

What is a Database?

A database is an organized collection of information that can be stored, accessed and managed electronically.

What is SQLite?

SQLite is a lightweight relational database engine. It stores data in a local database file and does not require a separate database server.

Python SQLite Connectivity

Python provides the sqlite3 module for working with SQLite databases.

Creating a Database and Table

import sqlite3

con = sqlite3.connect("college.db")
cur = con.cursor()

cur.execute("""
CREATE TABLE IF NOT EXISTS student(
    id INTEGER PRIMARY KEY,
    name TEXT,
    marks INTEGER
)
""")

con.commit()
con.close()

Inserting Records

import sqlite3

con = sqlite3.connect("college.db")
cur = con.cursor()

cur.execute(
    "INSERT INTO student(name, marks) VALUES (?, ?)",
    ("Sanju", 85)
)

con.commit()
con.close()

Displaying Records

import sqlite3

con = sqlite3.connect("college.db")
cur = con.cursor()

cur.execute("SELECT * FROM student")

for row in cur.fetchall():
    print(row)

con.close()

Updating Records

cur.execute(
    "UPDATE student SET marks=? WHERE name=?",
    (90, "Sanju")
)
con.commit()

Deleting Records

cur.execute(
    "DELETE FROM student WHERE name=?",
    ("Sanju",)
)
con.commit()
Always use parameterized SQL queries with placeholders such as ? when inserting user-provided values. This helps prevent SQL injection.

16. Data Analysis Using Pandas

import pandas as pd

17. Important Differences

Compiler vs Interpreter

  • Compiler: Translates the program into machine code before execution.
  • Interpreter: Executes program instructions through an interpreter at runtime.

List vs Tuple

  • List uses square brackets [ ].
  • Tuple uses parentheses ( ).
  • List is mutable.
  • Tuple is immutable.

break vs continue

  • break terminates the loop.
  • continue skips the current iteration.

Function vs Method

  • Function is a reusable block of code called independently.
  • Method is a function associated with an object or class.

Errors vs Exceptions

  • Errors are problems in a program that may prevent correct execution.
  • Exceptions are runtime events that can often be handled using try and except.

Series vs DataFrame

  • Series is one-dimensional.
  • DataFrame is two-dimensional.

2. Check Even or Odd

n = int(input("Enter a number: "))

if n % 2 == 0:
    print("Even number")
else:
    print("Odd number")

3. Find Largest of Three Numbers

a = int(input("Enter first number: "))
b = int(input("Enter second number: "))
c = int(input("Enter third number: "))

if a >= b and a >= c:
    print("Largest:", a)
elif b >= a and b >= c:
    print("Largest:", b)
else:
    print("Largest:", c)

4. Factorial of a Number

n = int(input("Enter a number: "))
fact = 1

for i in range(1, n + 1):
    fact *= i

print("Factorial:", fact)

5. Check Prime Number

n = int(input("Enter a number: "))

if n <= 1:
    print("Not Prime")
else:
    for i in range(2, n):
        if n % i == 0:
            print("Not Prime")
            break
    else:
        print("Prime")

6. Fibonacci Series

n = int(input("Enter number of terms: "))

a, b = 0, 1

for i in range(n):
    print(a, end=" ")
    a, b = b, a + b

text = input("Enter a string: ")
