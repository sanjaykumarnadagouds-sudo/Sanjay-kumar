UNIT 1 – INTRODUCTION TO JAVA

1. Introduction to Java

Definition

Java is a high-level, object-oriented, class-based programming language developed by Sun Microsystems. It is designed to be simple, secure, portable and platform independent.

History of Java

  • Java was developed by James Gosling and his team at Sun Microsystems.
  • Development started in 1991.
  • It was originally called Oak.
  • It was officially released in 1995 and renamed Java.
  • Oracle acquired Sun Microsystems in 2010.

Applications of Java

  • Desktop applications.
  • Web applications.
  • Enterprise applications.
  • Android application development.
  • Banking and financial software.
  • Cloud-based applications.

2. Features of Java

The important features of Java are:

  1. Simple: Java has an easy-to-understand syntax and removes many complex features of C++.
  2. Object-Oriented: Java uses classes and objects to organize programs.
  3. Platform Independent: Java bytecode can run on different operating systems using a compatible JVM.
  4. Secure: Java provides security features such as bytecode verification and controlled memory access.
  5. Robust: Java supports exception handling and automatic memory management.
  6. Multithreaded: Java supports running multiple tasks concurrently.
  7. Portable: Java programs can be moved between supported platforms.
  8. High Performance: The Just-In-Time compiler helps improve execution speed.
  9. Distributed: Java provides networking features for developing distributed applications.

3. Java Virtual Machine (JVM)

Definition

JVM stands for Java Virtual Machine. It is an abstract machine that executes Java bytecode and provides the runtime environment for Java programs.

Functions of JVM

  • Loads Java class files.
  • Verifies bytecode.
  • Executes bytecode.
  • Manages memory.
  • Performs garbage collection.
  • Provides runtime security.

Advantages of JVM

  • Supports platform independence.
  • Manages memory automatically.
  • Provides a secure execution environment.
  • Supports optimized program execution.

4. JDK, JRE and JVM

JDK – Java Development Kit

JDK is a software development kit used to develop, compile, debug and run Java programs. It includes development tools and the runtime environment.

JRE – Java Runtime Environment

JRE provides the environment and libraries required to run Java applications.

JVM – Java Virtual Machine

JVM executes Java bytecode and manages program execution.

Difference between JDK, JRE and JVM

  • JDK: Used to develop and run Java programs.
  • JRE: Used to run Java programs.
  • JVM: Executes Java bytecode.

5. Java Tokens

Definition

Tokens are the smallest individual elements of a Java program that have a specific meaning.

Types of Java Tokens

  1. Keywords: Reserved words with special meanings, such as class, int, public and static.
  2. Identifiers: Names given to classes, variables and methods.
  3. Literals: Constant values such as 10, 25.5, 'A' and "Hello".
  4. Operators: Symbols used to perform operations, such as +, -, * and /.
  5. Separators: Symbols used to separate program elements, such as semicolons, commas and brackets.

6. Data Types in Java

Definition

A data type specifies the type of value that a variable can store.

Types of Data Types

1. Primitive Data Types

  • byte – stores small integer values.
  • short – stores short integer values.
  • int – stores integer values.
  • long – stores large integer values.
  • float – stores decimal values.
  • double – stores larger precision decimal values.
  • char – stores a single character.
  • boolean – stores true or false.

2. Non-Primitive Data Types

  • String
  • Arrays
  • Classes
  • Interfaces

7. Operators in Java

Operators are special symbols used to perform operations on variables and values.

Types of Operators

  1. Arithmetic Operators: +, -, *, /, %
  2. Relational Operators: ==, !=, greater than, less than, greater than or equal to, less than or equal to.
  3. Logical Operators: &&, ||, !
  4. Assignment Operators: =, +=, -=, *=, /=
  5. Unary Operators: ++, --
  6. Conditional Operator: ? :
  7. Bitwise Operators: &, |, ^, ~

UNIT 2 – CLASSES, OBJECTS AND METHODS

8. Object-Oriented Programming

Definition

Object-Oriented Programming (OOP) is a programming approach based on classes and objects. It organizes programs into reusable and manageable components.

Main Principles of OOP

  1. Encapsulation: Wrapping data and methods into a single unit called a class.
  2. Inheritance: Acquiring the properties and methods of one class into another class.
  3. Polymorphism: One name or interface having multiple forms.
  4. Abstraction: Hiding implementation details and showing essential features.

Advantages of OOP

  • Code reusability.
  • Data security.
  • Easy maintenance.
  • Better program organization.
  • Reduced code duplication.

9. Class and Object

Class

A class is a blueprint or template used to create objects. It contains data members and methods.

Object

An object is an instance of a class. It represents a real-world entity and has state and behaviour.

Characteristics of an Object

  • Identity: Uniquely identifies an object.
  • State: Represents the data or properties of an object.
  • Behaviour: Represents the actions performed by an object.

Difference between Class and Object

  • Class is a blueprint; object is an instance of a class.
  • Class defines properties; object contains actual values.
  • A class is declared using the class keyword; objects are generally created using new.

10. Methods in Java

Definition

A method is a block of code that performs a specific task. It helps divide a program into smaller reusable parts.

Types of Methods

  1. Predefined Methods: Methods already provided by Java libraries, such as println() and sqrt().
  2. User-Defined Methods: Methods created by programmers according to their requirements.

Advantages of Methods

  • Code reusability.
  • Reduces code repetition.
  • Makes programs easier to understand.
  • Simplifies debugging and maintenance.

11. Constructors in Java

Definition

A constructor is a special member of a class that is called automatically when an object is created. It is mainly used to initialize objects.

Characteristics

  • The constructor name must be the same as the class name.
  • A constructor has no return type.
  • It is called automatically when an object is created.
  • Constructors can be overloaded.

Types of Constructors

  1. Default Constructor: A no-argument constructor supplied by the compiler when no constructor is declared.
  2. No-Argument Constructor: A constructor explicitly written without parameters.
  3. Parameterized Constructor: A constructor that accepts parameters to initialize an object.

12. Constructor Overloading

Definition

Constructor overloading means defining more than one constructor in the same class with different parameter lists.

Features

  • All constructors have the same class name.
  • They have different parameter lists.
  • They allow objects to be initialized in different ways.
  • The appropriate constructor is selected based on the arguments.

Advantages

  • Provides flexibility in object creation.
  • Supports different initialization methods.
  • Improves code readability.

13. Method Overloading

Definition

Method overloading is a feature in Java where multiple methods have the same name but different parameter lists.

Rules

  • Methods must have the same name.
  • Parameters must differ in number, type or order.
  • Changing only the return type does not create valid overloading.

Advantages

  • Improves readability.
  • Supports compile-time polymorphism.
  • Allows similar operations to use the same method name.

14. Static Members in Java

Definition

The static keyword is used to declare members that belong to the class rather than individual objects.

Types of Static Members

  • Static Variable: A variable shared by all objects of a class.
  • Static Method: A method that can be called using the class name.
  • Static Block: A block used to initialize static data when the class is initialized.

Advantages

  • Reduces repeated storage of shared data.
  • Can be accessed without creating an object in suitable cases.
  • Useful for common utility methods.

15. Encapsulation

Definition

Encapsulation is the process of combining data and methods into a single unit called a class and controlling access to that data.

How to Achieve Encapsulation

  1. Declare class variables as private.
  2. Provide public getter methods.
  3. Provide setter methods when modification is required.
  4. Access the data through these methods.

Advantages

  • Provides data protection.
  • Improves security.
  • Allows controlled access to data.
  • Makes code easier to maintain.

UNIT 3 – INHERITANCE AND POLYMORPHISM

16. Inheritance in Java

Definition

Inheritance is an OOP concept in which one class acquires the properties and methods of another class.

Important Terms

  • Superclass: The parent class whose properties are inherited.
  • Subclass: The child class that inherits from another class.
  • extends: The keyword used for class inheritance.

Types of Inheritance

  1. Single Inheritance: One child class inherits from one parent class.
  2. Multilevel Inheritance: A class inherits from a class that itself inherits from another class.
  3. Hierarchical Inheritance: Multiple child classes inherit from one parent class.
  4. Multiple Inheritance: A class inherits from multiple parents. Java does not support this through classes, but similar behaviour can be achieved using interfaces.
  5. Hybrid Inheritance: A combination of different inheritance types, which can be designed using interfaces.

Advantages

  • Code reusability.
  • Reduces duplication.
  • Supports method overriding.
  • Improves program organization.

17. Method Overriding

Definition

Method overriding occurs when a subclass provides its own implementation of an inherited method with a compatible method signature.

Rules

  • The method must be inherited from a parent class.
  • The method name and parameter list must match.
  • The return type must be compatible.
  • The access level cannot be more restrictive.
  • Static methods are hidden, not overridden.

Advantages

  • Supports runtime polymorphism.
  • Allows specialized behaviour in subclasses.
  • Improves flexibility.

18. Polymorphism

Definition

Polymorphism means one name or interface can represent many forms. It allows the same operation to behave differently in different situations.

Types of Polymorphism

1. Compile-Time Polymorphism

It is achieved mainly through method overloading. The compiler determines which method to call.

2. Runtime Polymorphism

It is achieved through method overriding. The actual method is selected at runtime based on the object.

Advantages

  • Improves flexibility.
  • Supports reusable code.
  • Allows one interface to work with different implementations.

19. Dynamic Method Dispatch

Definition

Dynamic method dispatch is the mechanism through which an overridden method call is resolved at runtime based on the actual object.

Characteristics

  • It is related to runtime polymorphism.
  • It involves inheritance and method overriding.
  • A parent class reference can refer to a child class object.
  • The overridden method of the actual object is executed.

Advantages

  • Provides runtime flexibility.
  • Supports extensible applications.
  • Reduces dependency on specific implementations.

20. Abstract Class and Abstract Method

Abstract Class

An abstract class is a class declared using the abstract keyword. It cannot be instantiated directly.

Abstract Method

An abstract method is a method declared without a method body. Its implementation is provided by a concrete subclass.

Features

  • An abstract class can contain abstract and concrete methods.
  • It can contain variables and constructors.
  • A subclass must implement inherited abstract methods unless it is also abstract.
  • An abstract class cannot be instantiated directly.

Advantages

  • Provides a common base for related classes.
  • Supports abstraction.
  • Encourages code reuse.

21. Interfaces in Java

Definition

An interface is a reference type in Java that defines a contract which implementing classes agree to follow.

Features

  • Declared using the interface keyword.
  • Implemented using the implements keyword.
  • Supports multiple inheritance of type.
  • Fields declared in an interface are public, static and final by default.
  • Methods can include abstract, default, static and private methods, subject to Java version rules.

Advantages

  • Supports abstraction.
  • Allows multiple interface implementation.
  • Promotes loose coupling.
  • Improves code flexibility.

22. Difference Between Abstract Class and Interface

  • Abstract Class: Declared using the abstract keyword.
  • Interface: Declared using the interface keyword.
  • Inheritance: A class can extend only one class.
  • Implementation: A class can implement multiple interfaces.
  • Constructors: Abstract classes can have constructors; interfaces cannot have constructors.
  • Variables: Abstract classes can have instance variables; interface fields are public, static and final by default.
  • Methods: Abstract classes can have abstract and concrete methods; interfaces can have abstract, default, static and private methods depending on Java version.

UNIT 4 – PACKAGES, EXCEPTIONS AND MULTITHREADING

23. Packages in Java

Definition

A package is a collection of related classes, interfaces and subpackages. It is used to organize Java programs.

Types of Packages

  1. Built-in Packages: Packages provided by Java, such as java.lang, java.util and java.io.
  2. User-Defined Packages: Packages created by programmers to organize their own classes.

Advantages

  • Organizes related classes.
  • Avoids naming conflicts.
  • Provides access control.
  • Supports code reuse.

24. Access Modifiers in Java

Definition

Access modifiers control the visibility and accessibility of classes, methods and variables.

Types of Access Modifiers

  1. Public: Accessible from anywhere, subject to class and module visibility.
  2. Private: Accessible only within the declaring top-level class or its enclosing nest.
  3. Protected: Accessible within the same package and through inheritance in other packages, subject to Java access rules.
  4. Default: When no modifier is specified, access is limited to the same package.

Importance

  • Provides data security.
  • Controls access to class members.
  • Supports encapsulation.

25. Exception Handling

Definition

Exception handling is a mechanism used to handle runtime errors so that a program can continue or terminate in a controlled manner.

Types of Exceptions

  1. Checked Exceptions: Exceptions checked by the compiler, such as IOException.
  2. Unchecked Exceptions: Runtime exceptions, such as ArithmeticException and NullPointerException.
  3. Errors: Serious problems, generally not intended to be handled by ordinary application code.

Exception Handling Keywords

  • try: Contains code that may cause an exception.
  • catch: Handles an exception.
  • finally: Contains cleanup code that normally executes after try/catch completion.
  • throw: Used to explicitly throw an exception.
  • throws: Declares exceptions that a method may pass to its caller.

Advantages

  • Prevents abnormal program termination in handled situations.
  • Separates error-handling code from normal code.
  • Improves program reliability.

26. User-Defined Exceptions

Definition

A user-defined exception is a custom exception created by a programmer to represent a specific application error.

Steps to Create

  1. Create a new exception class.
  2. Extend Exception for a checked exception or RuntimeException for an unchecked exception.
  3. Define a constructor to pass an error message.
  4. Use throw to raise the exception.
  5. Handle it using try-catch when appropriate.

Advantages

  • Handles application-specific errors.
  • Makes error messages meaningful.
  • Improves code readability.

27. Multithreading in Java

Definition

Multithreading is a Java feature that allows multiple threads to execute concurrently within a program.

Thread

A thread is a lightweight unit of execution within a process.

Ways to Create Threads

  1. Extending Thread Class: Create a class that extends Thread and override run().
  2. Implementing Runnable Interface: Create a class that implements Runnable and define run().

Important Thread Methods

  • start(): Starts a new thread and causes its run method to execute.
  • run(): Contains the task performed by the thread.
  • sleep(): Pauses the current thread temporarily.
  • join(): Waits for another thread to finish.
  • isAlive(): Checks whether a thread is still alive.

Advantages

  • Supports concurrent tasks.
  • Can improve responsiveness.
  • Useful for background operations.
  • Can make better use of processor resources.

28. Thread Life Cycle

Definition

The thread life cycle describes the different states through which a thread passes during execution.

Thread States in Java

  1. NEW: Thread object is created but not started.
  2. RUNNABLE: Thread is ready to run or running, as managed by the JVM and operating system.
  3. BLOCKED: Thread is waiting to acquire a monitor lock.
  4. WAITING: Thread is waiting indefinitely for another thread's action.
  5. TIMED_WAITING: Thread is waiting for a specified period.
  6. TERMINATED: Thread has completed execution.

29. Synchronization in Java

Definition

Synchronization is a mechanism used to control access to shared resources when multiple threads are working at the same time.

Need for Synchronization

  • Prevents unwanted interference between threads.
  • Helps protect shared data.
  • Controls access to critical sections.
  • Helps avoid certain race conditions.

Types

  • Synchronized Method: Synchronizes access to an instance method using the object's monitor.
  • Synchronized Block: Synchronizes only a selected block of code.
  • Static Synchronization: Synchronizes access using the class monitor.

30. Garbage Collection in Java

Definition

Garbage collection is the automatic process of identifying and reclaiming memory occupied by objects that are no longer reachable.

Features

  • Memory management is handled automatically by the JVM.
  • Unreachable objects may become eligible for garbage collection.
  • The programmer does not directly free object memory.
  • Garbage collection timing is not guaranteed.

Advantages

  • Reduces manual memory management.
  • Helps reclaim unused memory.
  • Reduces certain memory-related programming errors.
