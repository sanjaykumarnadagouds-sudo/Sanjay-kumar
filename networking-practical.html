PART A – Basic Networking Activities

1. Prepare Hardware and Software Specifications for a Basic Computer System and Networking

Aim

To identify the hardware and software requirements of a computer system used for networking.

Hardware Requirements

  • Desktop computer or laptop
  • Processor, motherboard and RAM
  • Network Interface Card (NIC)
  • Ethernet cable (RJ45)
  • Switch or router
  • Wireless network adapter

Software Requirements

  • Windows or Linux operating system
  • Network drivers
  • Web browser
  • Command Prompt or Terminal
  • Packet Tracer or another network simulator

Procedure

  1. Identify the processor, RAM and storage of the computer.
  2. Check whether a network adapter is available.
  3. Identify the operating system and network drivers.
  4. List the networking devices required for a basic LAN.
  5. Prepare a specification report.
Result: The hardware and software specifications required for a basic computer network were identified.

2. Study Different Types of Network Cables and Implement Cross-Wired and Straight-Through Cables

Aim

To study network cables and prepare straight-through and crossover cables using an RJ45 connector and crimping tool.

Types of Network Cables

  • Twisted Pair Cable – UTP and STP
  • Coaxial Cable
  • Optical Fibre Cable

RJ45 T568B Colour Sequence

1. White-Orange
2. Orange
3. White-Green
4. Blue
5. White-Blue
6. Green
7. White-Brown
8. Brown

RJ45 T568A Colour Sequence

1. White-Green
2. Green
3. White-Orange
4. Blue
5. White-Blue
6. Orange
7. White-Brown
8. Brown

Procedure – Straight-Through Cable

  1. Cut the required length of UTP cable.
  2. Remove the outer insulation carefully.
  3. Arrange the eight wires using T568B at both ends.
  4. Insert the wires into RJ45 connectors.
  5. Crimp both connectors using the crimping tool.
  6. Test the cable using a cable tester.

Procedure – Crossover Cable

  1. Prepare the cable as above.
  2. Arrange one end using T568A.
  3. Arrange the other end using T568B.
  4. Insert both ends into RJ45 connectors.
  5. Crimp and test the cable.

Note: Follow proper cable safety procedures and use a cable tester. Modern devices often support Auto-MDI-X, so crossover cables may not always be required.

Result: Straight-through and crossover cable arrangements were studied and tested.

3. Identify Networking Devices on a Network

Aim

To identify different networking devices and understand their functions.

Devices and Functions

  • Hub: Connects multiple computers and broadcasts incoming data to all ports.
  • Switch: Connects devices in a LAN and forwards frames using MAC addresses.
  • Router: Connects different networks and forwards packets using IP addresses.
  • Modem: Converts signals for communication over an internet connection.
  • Repeater: Regenerates signals to extend network distance.
  • Bridge: Connects and filters traffic between LAN segments.
  • Access Point: Provides wireless connectivity to network devices.
  • Network Interface Card: Enables a computer to connect to a network.

Procedure

  1. Observe the networking devices in the laboratory.
  2. Identify the ports, indicators and antennas.
  3. Read the device labels and model numbers.
  4. Record the function of each device.
Result: Different networking devices and their functions were identified.

4. Configure the IP Address of a Computer

Aim

To configure an IPv4 address on a computer.

Example Network Configuration

IP Address      : 192.168.1.10
Subnet Mask     : 255.255.255.0
Default Gateway : 192.168.1.1
DNS Server      : 8.8.8.8

Procedure – Windows

  1. Open Control Panel.
  2. Select Network and Internet.
  3. Open Network and Sharing Center.
  4. Select Change adapter settings.
  5. Right-click Ethernet and select Properties.
  6. Select Internet Protocol Version 4 (TCP/IPv4).
  7. Choose Use the following IP address.
  8. Enter the IP address, subnet mask and gateway.
  9. Click OK to save the configuration.

Verification Command

ipconfig
Result: The computer's IPv4 address was configured and verified.

5. Create a Basic Network and Share Files and Folders

Aim

To connect computers in a basic LAN and share files and folders.

Requirements

  • Two or more computers
  • Ethernet cables
  • Network switch or router

Example Network

Computer 1                 Computer 2
192.168.1.10               192.168.1.11
       |                         |
       +-------- Switch ---------+

Procedure

  1. Connect both computers to the same switch or router.
  2. Configure IP addresses in the same subnet.
  3. Enable network discovery and file sharing.
  4. Choose a folder to share.
  5. Open folder Properties and select Sharing.
  6. Configure the required sharing permissions.
  7. Access the shared folder from the other computer.

Test Connection

ping 192.168.1.11
Result: A basic LAN was created and file sharing was tested between computers.

6. Study Basic Network Commands and Network Configuration Commands

Aim

To study and execute commonly used network commands.

Basic Network Commands

ping 127.0.0.1
ping google.com
tracert google.com
nslookup google.com
hostname
netstat -an

Network Configuration Commands

ipconfig
ipconfig /all
ipconfig /release
ipconfig /renew
ipconfig /flushdns
getmac

Command Explanation

  • ping: Checks connectivity with another device.
  • tracert: Displays the route taken by packets.
  • nslookup: Finds DNS information for a domain.
  • hostname: Displays the computer name.
  • netstat: Displays network connections and statistics.
  • ipconfig: Displays IP configuration.
  • getmac: Displays the MAC address.

Procedure

  1. Open Command Prompt.
  2. Enter each command separately.
  3. Observe the output.
  4. Record the purpose and result of each command.
Result: Basic network and network configuration commands were executed and studied.

PART B – Network Simulation Activities

Aim

PC1: 192.168.1.2

Important Viva Questions

Networking Lab – Viva Preparation

  1. What is a computer network?

    A computer network is a group of connected devices that share data and resources.

  2. What is an IP address?

    An IP address identifies a device on an IP network.

  3. What is a MAC address?

    A MAC address is a hardware address associated with a network interface.

  4. What is a router?

    A router forwards packets between different networks.

  5. What is a switch?

    A switch connects devices in a LAN and forwards frames using MAC addresses.

  6. What is LAN?

    LAN stands for Local Area Network.

  7. What is WAN?

    WAN stands for Wide Area Network.

  8. What is DNS?

    DNS translates domain names into IP addresses.

  9. What is DHCP?

    DHCP automatically assigns IP configuration to network devices.

  10. What is ping?

    Ping is used to test network connectivity.

  11. What is FTP?

    FTP stands for File Transfer Protocol.

  12. What is TCP?

    TCP is a connection-oriented transport protocol that provides reliable data delivery.

  13. What is a network topology?

    It is the physical or logical arrangement of devices in a network.

  14. What is a crossover cable?

    It is a cable wired with different pinout standards at its two ends, traditionally used to connect similar Ethernet devices.

  15. What is a wireless LAN?

    A wireless LAN connects devices using wireless communication, usually Wi-Fi.
