1. Set Operations – Union, Intersection, Difference and Subset

Aim

To perform union, intersection, difference and subset operations on two sets using R.

Source Code

A <- c(1, 2, 3, 4)
B <- c(3, 4, 5, 6)

cat("Set A:", A, "\n")
cat("Set B:", B, "\n")

cat("Union:", union(A, B), "\n")
cat("Intersection:", intersect(A, B), "\n")
cat("Difference A-B:", setdiff(A, B), "\n")
cat("Difference B-A:", setdiff(B, A), "\n")

C <- c(1, 2)
cat("Is C a subset of A:", all(C %in% A), "\n")

Sample Output

Set A: 1 2 3 4
Set B: 3 4 5 6
Union: 1 2 3 4 5 6
Intersection: 3 4
Difference A-B: 1 2
Difference B-A: 5 6
Is C a subset of A: TRUE

Result

Thus, set operations are performed successfully using R.

5. Check Whether a Relation is Reflexive

Aim

To check whether a given relation is reflexive.

Source Code

A <- c(1, 2, 3)

# Relation R
R <- matrix(c(
  1, 1, 0,
  0, 1, 0,
  0, 0, 1
), nrow=3, byrow=TRUE)

print(R)

reflexive <- TRUE

for(i in 1:length(A)) {
  if(R[i,i] != 1) {
    reflexive <- FALSE
  }
}

if(reflexive) {
  cat("The relation is reflexive")
} else {
  cat("The relation is not reflexive")
}

Sample Output

[2,]    0    1    0
[3,]    0    0    1

Result

6. Check Whether a Relation is Transitive

Aim

To check whether a given relation is transitive.

Source Code

A <- 1:3

# Relation: (1,2), (2,3), (1,3)
R <- matrix(c(
  0, 1, 1,
  0, 0, 1,
  0, 0, 0
), nrow=3, byrow=TRUE)

print(R)

transitive <- TRUE

for(i in A) {
  for(j in A) {
    for(k in A) {
      if(R[i,j] == 1 && R[j,k] == 1 && R[i,k] != 1) {
        transitive <- FALSE
      }
    }
  }
}

if(transitive) {
  cat("The relation is transitive")
} else {
  cat("The relation is not transitive")
}

Sample Output

     [,1] [,2] [,3]
[1,]    0    1    1
[2,]    0    0    1
[3,]    0    0    0

The relation is transitive

Result

Thus, the given relation is checked for transitivity.

cat("B =", B, "\n")
cat("NOT A =", as.integer(NOT_A), "\n")

9. Calculate Mean, Median and Mode

Aim

To calculate the measures of central tendency: mean, median and mode.

Source Code

x <- c(10, 20, 20, 30, 40, 20, 50)

mean_value <- mean(x)
median_value <- median(x)

get_mode <- function(v) {
  values <- unique(v)
  frequencies <- tabulate(match(v, values))
  values[which.max(frequencies)]
}

mode_value <- get_mode(x)

cat("Data:", x, "\n")
cat("Mean:", mean_value, "\n")
cat("Median:", median_value, "\n")
cat("Mode:", mode_value, "\n")

Sample Output

Data: 10 20 20 30 40 20 50
Mean: 27.14286
Median: 20
Mode: 20

Result

Thus, mean, median and mode are calculated successfully.

PART B – PROGRAM 2

10. Calculate Variance and Standard Deviation for Discrete and Continuous Series

Aim

To calculate variance and standard deviation for discrete and continuous frequency distributions.

Source Code

# Discrete frequency distribution
x <- c(10, 20, 30)
f <- c(2, 3, 5)

N <- sum(f)
mean_d <- sum(x*f)/N
variance_d <- sum(f*(x-mean_d)^2)/N
sd_d <- sqrt(variance_d)

cat("Discrete Mean:", mean_d, "\n")
cat("Discrete Variance:", variance_d, "\n")
cat("Discrete SD:", sd_d, "\n\n")

# Continuous frequency distribution
lower <- c(0, 10, 20)
upper <- c(10, 20, 30)
mid <- (lower + upper)/2
fc <- c(2, 3, 5)

Nc <- sum(fc)
mean_c <- sum(mid*fc)/Nc
variance_c <- sum(fc*(mid-mean_c)^2)/Nc
sd_c <- sqrt(variance_c)

cat("Continuous Mean:", mean_c, "\n")
cat("Continuous Variance:", variance_c, "\n")
cat("Continuous SD:", sd_c)

Sample Output

Discrete Mean: 23
Discrete Variance: 61
Discrete SD: 7.81025

Continuous Mean: 18
Continuous Variance: 61
Continuous SD: 7.81025

Result

Thus, variance and standard deviation are calculated for both distributions. These calculations use population formulas, dividing by total frequency.

16. Simple Linear Regression

Aim

To perform simple linear regression and predict a value using R.

Source Code

# Independent variable
x <- c(1, 2, 3, 4, 5)

# Dependent variable
y <- c(2, 4, 5, 4, 5)

# Create data frame
data <- data.frame(x, y)

# Fit linear regression model
model <- lm(y ~ x, data=data)

cat("Regression Model:\n")
print(coef(model))

# Predict value for x = 6
new_data <- data.frame(x=6)
prediction <- predict(model, newdata=new_data)

cat("Predicted value for x=6:", prediction, "\n")

# Draw regression graph
plot(x, y, main="Simple Linear Regression",
     xlab="X Values", ylab="Y Values",
     pch=19, col="blue")
abline(model, col="red", lwd=2)

Sample Output

Regression Model:
(Intercept)           x
        2.2         0.6

Predicted value for x=6: 5.8

Result

Thus, simple linear regression is performed and a predicted value is obtained. The program also displays the regression graph.

Important R Programming Viva Questions

1. What is R?
R is a programming language used for statistical computing, data analysis and graphical representation.

2. What is RStudio?
RStudio is an integrated development environment (IDE) used to write and execute R programs.

3. What is a vector?
A vector is a one-dimensional data structure containing elements of the same basic type.

4. What is a matrix?
A matrix is a two-dimensional data structure containing elements of the same type.

5. What is a data frame?
A data frame is a table-like structure containing rows and columns.

6. What is mean?
Mean is the sum of observations divided by the number of observations.

7. What is median?
Median is the middle value of an ordered dataset.

8. What is mode?
Mode is the value that occurs most frequently in a dataset.

9. What is standard deviation?
Standard deviation measures the spread of values around the mean.

10. What is linear regression?
Linear regression is a statistical method used to model the relationship between variables using a straight line.

11. What does lm() do?
The lm() function fits linear models in R.

12. What does plot() do?
The plot() function creates graphical representations of data.
