UNIT 1 – INTRODUCTION TO PROGRAMMING

1. Program Development Life Cycle (PDLC)

The Program Development Life Cycle is a series of steps followed to develop a computer program.

  1. Problem Definition: Understand the problem.
  2. Analysis: Identify the inputs and outputs.
  3. Design: Prepare an algorithm or flowchart.
  4. Coding: Write the program using a programming language.
  5. Testing: Check and correct errors.
  6. Implementation: Run the program.
  7. Maintenance: Update the program when required.

2. Procedure-Oriented Programming (POP)

POP is a programming approach in which a program is divided into functions or procedures.

Features:

  • Focuses on functions.
  • Uses a top-down approach.
  • Data is often shared between functions.
  • Examples: C and Pascal.

3. Object-Oriented Programming (OOP)

OOP is a programming approach based on objects and classes. It combines data and functions into a single unit.

Basic concepts:

  • Class: A blueprint for creating objects.
  • Object: An instance of a class.
  • Encapsulation: Combining data and functions together.
  • Abstraction: Hiding unnecessary details.
  • Inheritance: Acquiring properties of another class.
  • Polymorphism: One name with different forms.

4. Benefits and Applications of OOP

Benefits:

  • Code reusability.
  • Easy maintenance.
  • Better data security.
  • Easy program development.

Applications: Banking software, games, mobile applications, business software and simulations.

5. Introduction to C++

C++ is a general-purpose programming language developed by Bjarne Stroustrup. It supports both procedural and object-oriented programming.

Features: Fast execution, reusable code, classes, objects and functions.

6. Structure of a C++ Program

#include <iostream>
using namespace std;

int main()
{
    cout << "Hello World";
    return 0;
}

Explanation:

  • #include <iostream>: Includes input-output facilities.
  • using namespace std: Allows standard names without writing std::.
  • int main(): Starting point of the program.
  • cout: Displays output.
  • return 0: Ends the program successfully.

7. Input and Output Statements

cin: Used to accept input from the user.

cout: Used to display output.

#include <iostream>
using namespace std;

int main()
{
    int age;
    cout << "Enter your age: ";
    cin >> age;
    cout << "Your age is " << age;
    return 0;
}

8. Keywords and Identifiers

Keywords: Reserved words with special meanings in C++.

Examples: int, float, if, else, return, class.

Identifiers: Names given to variables, functions and classes.

Examples: student, total, marks.

9. Constants and Variables

Variable: A named memory location whose value can change.

Example: int age = 20;

Constant: A fixed value that cannot be changed during program execution.

Example: const float PI = 3.14;

10. Data Types

Data types specify the kind of value a variable can store.

  • int: Whole numbers (10).
  • float: Decimal numbers (10.5).
  • double: Decimal numbers with greater precision.
  • char: A single character ('A').
  • bool: true or false.
  • void: No value.

11. Operators and Expressions

Operators are symbols used to perform operations on values.

  • Arithmetic: +, -, *, /, %
  • Relational: ==, !=, >, <, >=, <=
  • Logical: &&, ||, !
  • Assignment: =, +=, -=
  • Increment/Decrement: ++, --
  • Conditional: ?:

An expression is a combination of variables, constants and operators.

Example: total = a + b;

12. Operator Precedence

Operator precedence determines which operation is performed first in an expression.

Example: 5 + 2 * 3 = 11

Multiplication is performed before addition.

Parentheses can change the order: (5 + 2) * 3 = 21

13. Type Conversion

Type conversion means changing a value from one data type to another.

  • Implicit: Automatically performed by the compiler.
  • Explicit: Performed manually using type casting.
int a = 10;
float b = (float)a;

14. Storage Classes

Storage classes define the scope, lifetime and visibility of variables.

  • auto: Traditional default local variable storage class.
  • register: Historical hint to store a variable in a CPU register.
  • static: Retains its value between function calls.
  • extern: Refers to a variable defined elsewhere.

UNIT 2 – CONTROL STATEMENTS AND FUNCTIONS

1. Control Statements

Control statements are used to control the flow of execution in a program.

Types:

  • Decision-making statements
  • Looping statements
  • Jump statements

2. if Statement

The if statement executes a block of code when a condition is true.

int age = 20;

if (age >= 18)
{
    cout << "Eligible";
}

3. if-else Statement

It executes one block if the condition is true and another block if it is false.

int n = 5;

if (n % 2 == 0)
{
    cout << "Even";
}
else
{
    cout << "Odd";
}

4. Nested if Statement

A nested if means placing one if statement inside another if statement.

int n = 10;

if (n > 0)
{
    if (n < 100)
    {
        cout << "Number is between 1 and 99";
    }
}

5. switch Statement

The switch statement is used to select one option from multiple choices.

int choice = 2;

switch (choice)
{
    case 1:
        cout << "One";
        break;

    case 2:
        cout << "Two";
        break;

    default:
        cout << "Invalid choice";
}

6. Looping Statements

Loops are used to execute a block of code repeatedly.

Types of loops:

  • for loop
  • while loop
  • do-while loop

7. for Loop

A for loop is generally used when the number of repetitions is known.

for (int i = 1; i <= 5; i++)
{
    cout << i << endl;
}

Output: 1 2 3 4 5

8. while Loop

A while loop checks the condition before executing the loop body.

int i = 1;

while (i <= 5)
{
    cout << i << endl;
    i++;
}

9. do-while Loop

A do-while loop executes the body at least once before checking the condition.

int i = 1;

do
{
    cout << i << endl;
    i++;
}
while (i <= 5);

10. Jump Statements

  • break: Terminates a loop or switch statement.
  • continue: Skips the current iteration and moves to the next one.
  • goto: Transfers control to a labelled statement.
  • return: Exits a function and may return a value.

11. Functions in C++

A function is a block of code designed to perform a particular task.

Benefits:

  • Code reusability.
  • Reduces repetition.
  • Makes programs easier to understand.
  • Easy debugging and maintenance.

12. Function Declaration, Definition and Calling

#include <iostream>
using namespace std;

int add(int, int); // Declaration

int main()
{
    cout << add(10, 20); // Function call
    return 0;
}

int add(int a, int b) // Definition
{
    return a + b;
}
  • Declaration: Announces the function.
  • Definition: Contains the function body.
  • Calling: Executes the function.

13. Function Arguments and Return Values

Arguments are values passed to a function. A return value is the result sent back by the function.

int square(int n)
{
    return n * n;
}

Calling square(5) returns 25.

14. Call by Value and Call by Reference

Call by Value: A copy of the variable is passed. Changes do not affect the original variable.

Call by Reference: A reference to the original variable is passed. Changes can affect the original variable.

void change(int &x)
{
    x = 100;
}

15. Function Overloading

Function overloading means defining multiple functions with the same name but different parameter lists.

int add(int a, int b)
{
    return a + b;
}

float add(float a, float b)
{
    return a + b;
}

UNIT 3 – ARRAYS, STRINGS AND POINTERS

1. Arrays in C++

An array is a collection of elements of the same data type stored under one name.

int marks[5] = {80, 75, 90, 85, 70};

cout << marks[0];

Output: 80

Array indexing starts from 0.

2. Types of Arrays

  • One-dimensional array: Stores elements in a single list.
  • Two-dimensional array: Stores elements in rows and columns.
  • Multidimensional array: An array with more than two dimensions.

3. One-Dimensional Array

A one-dimensional array stores data in a single sequence.

int a[5] = {10, 20, 30, 40, 50};

for(int i = 0; i < 5; i++)
{
    cout << a[i] << endl;
}

4. Two-Dimensional Array

A two-dimensional array stores data in the form of rows and columns.

int a[2][2] = {
    {10, 20},
    {30, 40}
};

cout << a[1][0];

Output: 30

5. Array Operations

Common operations performed on arrays include:

  • Traversal: Visiting each element.
  • Insertion: Adding an element.
  • Deletion: Removing an element.
  • Searching: Finding an element.
  • Sorting: Arranging elements in order.

6. Strings in C++

A string is a sequence of characters used to store text.

#include <iostream>
#include <string>
using namespace std;

int main()
{
    string name = "Sanjay";
    cout << name;
    return 0;
}

7. String Functions

Common C++ string operations include:

  • length(): Returns the number of characters.
  • size(): Returns the string length.
  • append(): Adds text to the end.
  • substr(): Extracts part of a string.
  • find(): Searches for text.
string name = "Student";
cout << name.length();

Output: 7

8. Pointers in C++

A pointer is a variable that stores the memory address of another variable.

int a = 10;
int *p = &a;

cout << *p;

Output: 10

  • &: Address-of operator.
  • *: Dereference operator when used with a pointer.

9. Pointer Declaration and Initialization

A pointer is declared using the * symbol.

int number = 50;
int *ptr = &number;

cout << number << endl;
cout << ptr << endl;
cout << *ptr;

The pointer stores the address, while *ptr accesses the value at that address.

10. Pointer Arithmetic

Pointer arithmetic means performing arithmetic operations on pointers.

  • Increment (++).
  • Decrement (--).
  • Addition or subtraction of an integer.
  • Difference between pointers in the same array.

Moving a pointer by one position advances it by the size of its data type.

11. Relationship Between Arrays and Pointers

The array name can be used as a pointer to its first element in many expressions.

int a[3] = {10, 20, 30};

cout << *a;

Output: 10

UNIT 4 – CLASSES, OBJECTS AND INHERITANCE

1. Class

A class is a user-defined data type that combines data members and member functions into one unit.

class Student {
public:
    int rollNo;
    void display() {
        cout << rollNo;
    }
};

2. Object

An object is an instance of a class. It is used to access the members of a class.

Student s1;
s1.rollNo = 10;
s1.display();

3. Constructor

A constructor is a special member function that is automatically called when an object is created.

Types: Default constructor, parameterized constructor and copy constructor.

class Student {
public:
    Student() {
        cout << "Constructor called";
    }
};

4. Destructor

A destructor is a special member function called automatically when an object is destroyed.

class Student {
public:
    ~Student() {
        cout << "Object destroyed";
    }
};

5. Inheritance

Inheritance is a feature of OOP in which one class acquires the properties and functions of another class.

Types: Single, multiple, multilevel, hierarchical and hybrid inheritance.

class Animal {
public:
    void eat() {
        cout << "Eating";
    }
};

class Dog : public Animal {
};

6. Polymorphism

Polymorphism means one name having many forms.

Types: Compile-time polymorphism and run-time polymorphism.

  • Function overloading
  • Operator overloading
  • Function overriding using virtual functions
